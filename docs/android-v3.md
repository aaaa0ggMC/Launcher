# Android 客户端 v3.0

版本号为 `3.0.0`，versionCode 为 `3`。网页界面来自宿主，更新界面需要同时更新宿主；APK 更新提供原生侧体验改进。

- 连接页提供输入校验、加载反馈和触摸尺寸更大的控件。连接探测使用代号，旧请求不会覆盖新目标；重复点击同一目标不会重复探测。
- Android 11 及以上在键盘动画前应用最终布局，动画期间通过平移 WebView 衔接底边，结束时对齐系统 inset。较旧系统继续使用 `adjustResize`。
- Android 13 及以上接入系统返回回调，先收键盘、再关闭网页弹层、再返回页面。主题系统栏使用 MutationObserver 合并更新，并保留低频兜底同步。
- Activity 恢复时仍处理新深链接与分享；WebView 加载、网络错误和恢复过程显示原生加载指示。

已通过 Gradle `assembleDebug` 编译。移动网页在 400px 和 650px 视口进行验收。键盘动画、系统返回与设备旋转仍需要 Android 真机验证，浏览器验收无法替代这些设备行为。
