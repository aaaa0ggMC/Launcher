# 命令行 (cli)

Linux System Cockpit 内置的命令控制台（REPL）：在应用里输入命令并执行，与所有 UI 按钮共享同一套命令 handler（CLI-first）。

## 使用教程

### 打开命令行

在左侧边栏「工具」分组点击 **命令行**（侧栏图标为终端样式）。进入后会自动聚焦输入框，屏幕上方显示欢迎语：

```
Linux Cockpit CLI — 输入 help 查看命令, Tab 补全
```

### 输入命令

命令统一采用 `<能力>.<命令> --参数 值` 的形式。例如：

```
mirror.toggle --name USTC --enable true
background.list
config.set --patch {"theme":"pureblack"}
```

- `--参数 值`：成对出现；不带值的 `--参数` 等价于传 `true`
- 多个参数用空格分隔；结果以文本形式输出在输入框上方
- 命令不区分大小写（首个 token 会转小写）

### 内置命令

- `help` — 列出全部能力命令（按能力分组），以及应用类内置命令的说明
- `list` / `ls` — 列出应用注册表中的全部应用（别名 + 名称）
- `info <别名>` — 查看某个应用的详细信息（名称、别名、路径、执行类型、风险等级、标签、可执行动作）
- `launch <别名> [动作]` / `run <别名> [动作]` — 启动应用；给出动作名时执行该应用的对应动作
- **裸别名** — 直接输入应用别名或 id 即可启动它（如输入 `bili-viewer`），后跟动作名则执行对应动作

> 以上应用类命令由 apps 能力注入，其它能力可能注册自己的 CLI 扩展。

### Tab 补全

输入时按 `Tab` 会尝试补全：

- 候选项为 `help` / `list` / `info` / `launch` 四个内置命令 + 所有已注册应用的应用别名与 id
- 只有一个匹配时直接补全；多个匹配时补出最长公共前缀
- 公共前缀不增长时，会以可点击的标签（chips）形式列出全部候选，点选即可填入

### ↑↓ 历史

按 `↑` / `↓` 浏览当前会话输入过的命令历史，再按 `Enter` 重新执行。

### 导出会话记录

命令行页支持把当前会话记录导出为 Markdown（提示语加粗、输出原样保留）：点击顶栏应用栏的「复制当前页面为 Markdown」按钮（文档图标）即可复制到剪贴板。

## CLI 命令参考

命令行本身不注册命令；它只是命令注册表的前端。可用的命令来自各能力的 `commands.ts`（`help` 输出会列出全部）。应用相关内置命令如上节所述。

## 配置项

命令行能力无专属配置项。它的行为由全局配置 `~/.config/LinuxCockpit/config.json` 及具体能力决定：

- 终端相关：`runtime.terminal`（如 `["konsole", "--hold", "-e"]`）不作用于命令行页，命令行输出始终在应用内展示

## 常见问题

**提示「未知命令: xxx」**

输入了注册表中不存在的命令，且无法解析为应用别名。输入 `help` 查看全部命令；注意别名大小写（匹配时不区分大小写，但请确认拼写）。

**参数里带空格 / JSON 无法解析**

命令参数按空格切分。带空格的 JSON 值（如 `--patch` 或 `background.job --args`）需要保证整个 JSON 是一个连续 token（内部无空格），如：

```
background.job --name download --args {"url":"https://example.com/a.zip","out":"/tmp/a.zip"}
```

**想执行 shell 管道 / 系统命令？**

命令行不是系统 shell，只解释 Cockpit 注册的命令。想跑任意系统命令请用 apps 能力添加一个应用条目，或通过后台任务的进程任务方式启动。
