# 傅里叶变换（ft）

用旋转矢量（本轮，epicycle）复现任意闭合图形的画布可视化工具。任意一条闭合平面曲线都可以用一组按不同速度旋转的「圆环矢量」首尾相接精确描出——这就是傅里叶级数 / 离散傅里叶变换（DFT）的几何意义。本能力即一个 SimpleVectors 风格的 DFT 展示器：内置预设一键播放，支持逐矢量编辑、JSON 导入导出、2D/3D 两种视图与自由相机操作。

能力入口：侧栏「杂项」→「傅里叶变换」。默认加载 `circle` 预设并自动开始播放。

## 前置依赖

- 无。渲染使用纯 Canvas 2D（手工透视投影），**不依赖 GPU / WebGL**——这是刻意设计（此前基于 three.js/WebGL 的实现曾在内核 radeonsi 驱动上触发崩溃，导致整个 Wayland 会话挂死）。
- 跨平台，无发行版 / 桌面环境要求，无 polkit / root 权限要求。

## 界面导览

画布占主区域，左上角为浮动工具栏，右侧为可折叠控制面板：

- **左上角工具栏**：播放/暂停、重绘、重置视图、跟随笔尖、2D/3D 切换。
- **右侧面板**（四个可折叠分区）：信息 / 控制 / 矢量 / 示例。点击右上角箭头可整面板收起（收起后不遮挡画面中心）。

### 信息区

实时统计：状态（运行中/已暂停）、FPS（当前/峰值）、模拟时间、矢量数、轨迹点数（/上限）、笔尖坐标（2D 为 `(x, y)`，3D 为 `(x, y, z)`）、视图（2D/3D）、缩放倍数（×N）。

### 控制区

- **播放 / 暂停**：暂停后矢量静止，轨迹停止增长。
- **重绘**：模拟时间归零、清空轨迹、重新从起点描线（`repaint`）。
- **重置视图**：相机回到默认取景（自动框住整个图形、恢复初始角度与缩放）。
- **跟随笔尖**：开启后相机自动跟踪末端矢量（笔尖）移动，图形始终保持在视野内；此模式下平移被禁用。
- **霓虹轨迹**：开启后轨迹颜色随模拟时间按 HSL 色相流动（彩虹渐变），关闭则用主题色。
- **3D 视图**：切换 2D / 3D 透视视图。
- **显示开关**（复选）：矢量（每节矢量臂）、覆盖（矢量扫过的区域，3D 下是面）、坐标轴（2D 画 X/Y 轴，3D 增加 Z 轴）、轨迹（描迹线）、末向量（最后一节矢量到笔尖的连线 + 笔尖圆点）。
- **运行速度**：滑块 0.05–4.0×，模拟时间推进倍率。
- **轨迹点数上限**：滑块 200–8000（步进 200），轨迹环形缓冲长度，超出后丢弃最旧点。

### 示例（预设）

一键加载的预设列表（点击即切换，当前预设高亮）：

| 预设 | 说明 |
| --- | --- |
| 圆形 | 单矢量 · 经典圆周 |
| 3D 圆 | 垂直圆 · 仅极向旋转（YZ 平面） |
| 环面 | 双周期 · 3D 覆盖区域（开「覆盖」可见） |
| 利马曲线 | 两矢量 · 利马曲线 |
| 心形线 | 心形线 · DFT |
| 方形 | 方形 · 角点吉布斯振铃 |
| 五角星 | 五角星 · DFT |
| 爱心 | 爱心 · 极小矢量数 |
| 随机 | 随机矢量 · 手写涂鸦（每次加载生成一组新矢量） |

其中「心形线 / 方形 / 五角星 / 爱心」由内置 DFT 从采样曲线变换而来：越平滑的曲线所需矢量越少（如爱心仅需约 30 个矢量），带尖角的图形（方形、星形）在角点处可见典型的吉布斯振铃过冲。

## 矢量表编辑

「矢量」分区是矢量表的可视化编辑器。每行代表一个旋转矢量，用**球坐标**描述：

| 列 | 含义 |
| --- | --- |
| `#` | 矢量序号（0 起） |
| `\|v\|` | 矢量长度（3D 模长） |
| `T_θ` | 极向旋转周期（绕 X 轴旋转，改变纬度），秒/圈；0 = 不转 |
| `T_φ` | 方位向旋转周期（绕 Z 轴旋转，经典本轮周期），秒/圈；0 = 不转 |
| `θ₀` | 矢量在球面上的初始极角（从 +Z 起算，度） |
| `φ₀` | 矢量在球面上的初始方位角（XY 平面内，度） |

`θ₀`/`φ₀` 始终生效：它们直接决定了矢量的初始指向，即使某个旋转周期为 0，起始方向也不会漂移。默认 `T_θ = 0`（无极向旋转）即精确还原经典 2D XY 平面本轮：`(x·cosα − y·sinα, x·sinα + y·cosα)`，`α = 2π·t/T_φ`。

操作：

- **更新**：把表格当前值提交到画布（清空轨迹、重置模拟时间并重新取景）。
- **添加矢量**：追加一行默认值（长度 50、θ₀=90°、φ₀=0°、周期 1/0）。
- **删除该矢量**：行尾 × 按钮。
- **加载文件**：从本地 JSON 读取矢量集（见下「JSON 格式」）。
- **导出矢量**：把当前矢量集（含运行速度与轨迹上限）存为 JSON。

> 说明：只有 `z ≠ 0` 时才写入 `z` 字段、只有 `T_θ ≠ 0` 时才写入 `secperRoundX`，保证导出的纯 2D 文件保持最小结构。

### JSON 格式

支持两种顶层结构：

```jsonc
{
  "vectors": [
    { "x": 90, "y": 0, "secperRound": 1 },
    { "x": 45, "y": 0, "secperRound": 2 },
    { "x": 30, "y": 0, "z": 10, "secperRound": 0, "secperRoundX": 0.25 }
  ],
  "runSpeed": 1,
  "verticesLimit": 4096
}
```

或直接一个裸矢量数组：

```json
[
  { "x": 120, "y": 0, "secperRound": 1 }
]
```

每个矢量的字段：

| 字段 | 说明 |
| --- | --- |
| `x` / `y` | 矢量在球面上的初始位置分量（必填，默认 0） |
| `z` | 可选，默认 0 |
| `secperRound` | 方位向周期 T_φ，秒/圈；`0` = 不转（静态 DC 偏移） |
| `secperRoundX` | 可选，极向周期 T_θ，秒/圈；`0`/缺省 = 无极向旋转 |

旧版 `orot` / `orotX`（初始相位角，度）字段兼容导入：会被烘焙进初始方向 `(x, y, z)`，老文件起点朝向不变。

能力自带示例文件位于 `src/abilities/ft/examples/`（`cardioid`、`circle`、`heart`、`limacon`、`line`、`square`、`star`、`triangle` 等），可直接用「加载文件」打开参考。

## 2D / 3D 相机操作

在画布上操作：

| 输入 | 行为 |
| --- | --- |
| 滚轮 | 缩放（以图形中心为基准，支持 0.3×–40×） |
| 左键拖动 | 平移 —— 沿相机视线平面移动画面（2D 与 3D 均可用；开启「跟随笔尖」时禁用） |
| 右键拖动 | 旋转视角 / 轨道环绕（仅 3D，2D 下无视角旋转） |

- 轨道灵敏度按视口与当前缩放标定：缩放越深、旋转越慢，便于放大后精细观察。
- 「重置视图」随时一键回到默认取景。

## 画布配色跟随主题

画布配色**不硬编码 hex**，而是读取当前主题（配色方案）的 Vuetify 语义色 token，由能力自行决定哪个角色映射到哪个 token：

| 角色 | 主题 token |
| --- | --- |
| X 轴 / Y 轴 / Z 轴 | `accent-1` / `accent-2` / `accent-3` |
| 网格细线 / 网格中心线 | `surface-variant` / `secondary-container` |
| 覆盖区域 | `on-surface-variant` |
| 矢量臂 | `accent-4` |
| 轨迹 | `on-surface` |
| 末向量 | `accent-5` |
| 笔尖 | `primary` |

切换主题（设置页或全局）即时生效，无需重启页面。

## CLI 命令参考

所有操作都是注册命令，可在内置 CLI REPL（`cli` 能力）中使用：

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `ft.presets` | 列出全部预设（名称 + 描述） | `ft.presets` |
| `ft.load` | 加载预设矢量集（`--name` 必填，`--mode 2d\|3d` 可选） | `ft.load --name heart` / `ft.load --name random --mode 3d` |
| `ft.load-file` | 从 JSON 文件加载矢量（`--path` 必填） | `ft.load-file --path /abs/vectors.json` |
| `ft.export` | 导出矢量到 JSON 文件（`--path` 与 `--data` 必填） | `ft.export --path /abs/vectors.json --data '{"vectors":[{"x":120,"y":0,"secperRound":1}]}'` |

返回值说明：

- `ft.presets` → `[{ name, description }]`。
- `ft.load` → 成功返回 `{ name, vectors, runSpeed, verticesLimit? }`；未知预设返回 `{ ok: false, error: '未知预设: <name>' }`。
- `ft.load-file` → 成功 `{ ok: true, vectors, runSpeed?, verticesLimit? }`；失败 `{ ok: false, error }`。
- `ft.export` → `{ ok, error? }`；缺 `--path` 时返回 `{ ok: false, error: '需要 --path' }`。

UI 按钮与 CLI 共享同一命令处理器（CLI-first）：界面上「加载预设 / 加载文件 / 导出」底层即调用 `ft.load` / `ft.load-file` / `ft.export`。

## 配置与存储

- **无配置文件**：ft 不写 `~/.config/LinuxCockpit/ft/`，也没有独立设置项。
- 当前矢量集、运行速度等是页面内存态，**切页/退出后不保留**；如需保存请用「导出矢量」写 JSON，之后用「加载文件」或 `ft.load-file` 恢复。

## 常见问题 / 已知局限

- **画面长时间停留后卡住（空白、无报错）**：某些 Wayland/Electron 环境下窗口被遮挡或闲置过久，`requestAnimationFrame` 可能被节流到停摆。内置看门狗定时器会在 rAF 停摆时以约 30fps 兜底续帧，窗口恢复可见后自动接回——若仍异常，切走再切回页面（keep-alive 会重建引擎）通常即可恢复。
- **随机预设每次都不同**：`random` 每次加载都会重新生成一组随机矢量，属预期行为；想要固定图形请用其它预设或自行编辑/导出。
- **2D 视图不显示 z**：2D 模式沿用经典 XY 平面投影，`z` 分量不参与绘制；要看到立体结构请切到 3D 视图（「环面」预设配合「覆盖」最适合演示）。
- **矢量表列多、面板窄**：编辑区表格在面板内横向滚动，拖动滚动条查看右侧列。
- **轨迹上限设置**：超过上限时最旧的轨迹点被丢弃（环形缓冲），长时间播放会看到旧轨迹逐渐消隐属正常。
