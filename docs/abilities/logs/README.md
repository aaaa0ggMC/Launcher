# 日志 (logs)

Linux System Cockpit 的日志查看器：实时查看当前会话的全部日志，支持按级别过滤、逐行虚拟滚动、向后翻页加载更早日志，并导出当前会话到文件。

## 使用教程

### 打开日志页

在左侧边栏「系统」分组点击 **日志**。页面顶部为工具栏，下方为日志列表。

### 界面元素

- **标题栏右侧**：显示当前已加载日志条数（`共 N 条`）
- **忽略 logs 自身日志**（开关，默认开启）：隐藏日志能力自身产生的记录（scope 为 `logs` 或 scope 为 `ipc` 且消息以 `logs.` 开头）。开启时仅界面上不显示，磁盘上的日志文件仍完整保留这些记录以便审计。该偏好会记住（localStorage），下次进入仍生效
- **级别（下拉框）**：按级别过滤——`全部` / `DEBUG` / `INFO` / `WARN` / `ERROR`，切换后立即重新加载列表
- **导出** 按钮：把当前会话日志保存为文件

### 浏览与实时尾随

- 列表使用**虚拟滚动**，任意规模下都流畅；每一行显示 `时间 · 级别 · 作用域(scope) · 消息`，WARN / ERROR 行有底色区分，重复合并的条目会显示 `*N` 标记
- 列表默认停在**最新日志**并实时尾随——应用运行中产生的新日志会自动追加到尾部（经 `cockpit:log` 事件广播）
- 需要回看更早内容：向上滚动到顶部会**自动加载更早一页**（每页 300 条），或点击顶部「加载更早日志」按钮
- 日志页每次进入都会重新加载（不缓存），因此切换页面再回来即是最新会话内容

### 导出当前会话

点击「导出」→ 选择保存位置（默认文件名 `cockpit-session-YYYY-MM-DD-HH-mm-ss.log`）→ 导出完成后提示「已导出 N 条日志」。导出的文件内容包含完整时间戳、级别、作用域与消息，重复条目为 `*N` 计数。

## CLI 命令参考

日志能力注册了 3 个命令，均可从命令行页直接执行：

### `logs.query`
查询当前会话日志（从内存环形缓冲读取，不读磁盘文件）。

```
logs.query [--level <debug|info|warn|error>] [--before <id>] [--limit <n>] [--scope <scope>] [--exclude-scopes a,b] [--exclude-self]
```

- `--level`：只返回指定级别（省略 = 全部）
- `--before <id>`：只返回日志序号小于该 id 的条目（用于向后翻页；id 单调递增）
- `--limit <n>`：最多返回条数（默认 500，上限 5000）
- `--scope <scope>`：只保留指定作用域的日志
- `--exclude-scopes a,b`：排除这些作用域
- `--exclude-self`：隐藏日志能力自身的记录（scope `logs` 或 `ipc` 下 `logs.*`）

返回值含 `entries`（由新到旧的列表）与 `total`（过滤后总条数）。

### `logs.export`
把当前会话日志（可选过滤级别）导出到指定文件。

```
logs.export --path /abs/session.log [--level info]
```

`--path` 为必填绝对路径；返回 `{ ok, count }`，失败时返回 `{ ok: false, error }`。

### `logs.post`
向日志管道提交一条日志（供调试 / 外部集成用）。

```
logs.post --level error --scope renderer --message "boom" [--data {"k":"v"}]
```

- `--level`：级别（默认 `info`）
- `--scope`：作用域（默认 `renderer`）
- `--message`：消息正文
- `--data`：可选，JSON 附加数据

## 配置项

日志文件位置：**`~/.config/LinuxCockpit/logs/cockpit-YYYY-MM-DD.log`**（按天轮转）。

- 每天一个文件，日期后缀格式 `YYYY-MM-DD`
- 单文件上限 **10 MB**，超过即轮转
- 保留 **14 天**，过期自动删除
- 历史文件归档为 **.gz** 压缩包
- 除磁盘文件外，主进程还维护**当前会话**的内存环形缓冲（最多 **20000** 条），`logs.query` / 日志页查询的就是这份缓冲；因此日志页只显示本次运行的日志
- 相同级别 + 作用域 + 消息在 **5 秒**内重复出现的条目会合并（计数 `*N`）；磁盘文件仍逐条完整记录
- 渲染端（页面代码）的 `console.warn/error` 与未捕获错误也会通过 `logs.post` 转发进日志管道

## 常见问题

**为什么我看不到上一次运行的历史日志？**

日志页查询的是"当前会话"内存缓冲，只覆盖本次启动后的记录。完整历史请直接查看 `~/.config/LinuxCockpit/logs/` 下的按天日志文件，或使用「导出」保存当前会话。

**「忽略 logs 自身日志」开关有什么用？**

日志能力自己的操作（如导出、查询）也会写日志。开启后界面不再显示这些"日志的日志"，避免干扰排查；磁盘文件始终保留。

**导出的日志里 `*12` 是什么意思？**

该条目在 5 秒合并窗口内重复出现了 12 次（合并后的 `count`）。磁盘文件里是逐条的原始记录。
