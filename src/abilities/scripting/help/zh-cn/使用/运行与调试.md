# 运行、调试与后台作业

> 最后更新：2026-10-01

本页讲运行时的细节：控制台每一类输出代表什么、失败时怎么定位、以及怎么把耗时较长的脚本
转交后台作业继续跑。

## 前台运行与后台运行

页面上的 **运行** 是**前台执行**：输出实时打到本页控制台，切到别的能力页面后脚本仍在主进程跑完，
但回来时控制台不会补显中途输出（日志推送只发给已订阅的页面）。

如果任务可能跑几分钟（大批量转换、轮询、长下载），在脚本里转交后台作业：

```ts
const task = await cockpit.job('script-run', {
  code: 'await cockpit.sh("sleep 60")',
  language: 'ts'
})
cockpit.log('后台任务已启动', task)
```

- 转交后即可离开页面，任务在侧栏「后台任务」面板里继续跑，进度与日志都在那里。
- 面板上可随时 **停止**；脚本里 `cockpit.signal` 触发，`await` 中的调用会抛错中断。
- 前台 **停止** 只影响当前这次前台执行，不会动已经转交出去的后台任务。

## 控制台输出的含义

每行输出由 `时间 [类型] 内容` 组成，颜色随类型变化：

| 类型     | 来源                                     | 颜色倾向 |
| -------- | ---------------------------------------- | -------- |
| `system` | 运行器自身：启动、执行完成、进度、中止   | 主色     |
| `log`    | `cockpit.log(…)`                         | 正文     |
| `info`   | `cockpit.info(…)`                        | info     |
| `warn`   | `cockpit.warn(…)` 或模板里的降级分支     | 警告色   |
| `error`  | `cockpit.error(…)` 或抛出的异常          | 错误色   |
| `stdout` | `cockpit.exec` / `cockpit.sh` 的标准输出 | 正文     |
| `stderr` | 子进程的标准错误                         | 错误色   |
| `result` | 脚本顶层 `return` 的非 undefined 值      | 成功色   |

顶栏还会显示：状态胶囊（就绪 / 运行中 / 执行成功 / 执行失败 / 已中止）、
`耗时: x.xs`（运行中实时跳动）、日志行数。下方进度条在 `cockpit.progress(pct)` 有具体百分比时
是确定长度，否则是 indeterminate 的等待动画。

## 常见错误怎么读

- **命令不存在**：`cockpit.command('xxx')` 抛错说命令未注册。先 `cockpit.listCommands()`
  看真实命令名；也可能是该命令所在能力被平台过滤或依赖缺失。
- **命令执行失败**：多数命令返回 `{ ok: false, error: '…' }` 而不是抛错，脚本里要自己判断。
- **TypeScript 报错**：编译阶段就失败，控制台只出现 `[system] 执行失败`，错误文本里带行列号。
- **退出码非 0**：`cockpit.sh` 会把 stderr 或 `Exit code N` 作为错误抛出，
  需要容忍失败时改用 `cockpit.exec`，自己检查 `code`。
- **取消**：脚本被停止时报 `Script execution cancelled`，这不是 bug。

## 排错小技巧

- 在关键步骤前后各打一条 `cockpit.info('步骤名')`，出错时能直接定位到哪一步。
- 想验证返回值结构，用 `cockpit.log(JSON.stringify(res, null, 2))`。
- 临时禁用某段逻辑，用参数面板的开关比删代码更快。
- 排查完记得把脚本 **保存**（Ctrl+S）；未保存时文件名后有一个 `•`。

## 快捷键

| 按键                | 作用                    |
| ------------------- | ----------------------- |
| Ctrl+Enter          | 运行                    |
| Ctrl+S              | 保存                    |
| Ctrl+F              | 查找                    |
| Ctrl+H              | 查找并替换              |
| Enter / Shift+Enter | 搜索结果下一个 / 上一个 |
| Esc                 | 关闭搜索框              |
| Tab                 | 插入两个空格缩进        |

> 切到其他能力再回来，页面状态（脚本内容、参数值、控制台）会保留；本能力是 keepAlive 页面。
