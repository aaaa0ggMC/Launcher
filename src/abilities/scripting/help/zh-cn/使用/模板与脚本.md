# 内置模板与脚本写法

> 最后更新：2026-10-01

本页逐个介绍顶部 **模板** 菜单里的五个预设，以及脚本里可以使用的 `cockpit.*` API。
它们同时也是一批可抄的范例：每个模板都演示了「声明参数 → 调命令 → 上报进度 → 返回结果」的完整套路。

## 内置模板

### Cockpit IPC 快速上手

演示如何声明配置参数、调用 Cockpit 命令、执行 Shell 与上报进度。参数有 `greeting`（字符串）、
`showStats`（开关）、`concurrency`（滑块）。脚本会先 `cockpit.listCommands()` 打印系统里
已注册的命令数，再调 `dashboard.stats` 取系统状态，然后跑一次 `uname -a`，最后返回一个
含命令数、问候语与执行时间的对象。**第一次用建议从这个模板开始。**

### 系统健康巡检报告

综合巡检系统统计、GPU 负载、Docker 容器与 systemd 服务状态。三个开关分别控制是否检查
GPU、Docker、systemd。每步都有 try/catch：缺对应能力或服务时只打一条 warn 并继续，
最后把汇总结果作为返回值输出。failed 的 systemd 单元会用 `cockpit.error` 标红列出。

### Arch 镜像源测速与分析

通过 `mirror.get` 与 `mirror.test` 命令自动测试并列出最佳镜像源。参数 `topCount` 控制
列出前 N 个最优源；结果按延迟升序排，超时的显示「连接超时」，并标注是否已启用。
失败会抛出错误，控制台显示具体原因。

### 壁纸随机轮换工作流

扫描指定目录中的壁纸文件，并随机应用一张到桌面。参数有 `wallpaperDir`（路径，默认取
`$HOME/Pictures`）和 `autoNotify`（切换后是否发通知）。先 `display.wallpapers` 列出候选，
随机选一张后 `display.wallpaper` 应用；目录里没有图片时返回 `{ status: 'no_wallpapers_found' }`。

### 数据管道与本地归档

抓取外部接口/系统日志，清洗转换并保存至本地存储。参数有 `logLimit`（抓取日志条数）与
`archiveName`（归档文件名前缀）。脚本读 `logs.query`、统计 info/warn/error 分布，
写到 `~/.config/LinuxCockpit/<前缀>-<时间戳>.json`，并发一条系统通知。

## cockpit API 一览

脚本里可用的全局对象是 `cockpit`：

| API                                                                          | 作用                                                       |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `cockpit.command(name, args?)`                                               | 调用任意已注册的 Cockpit 命令，返回命令结果                |
| `cockpit.listCommands()`                                                     | 列出所有命令的 name / description / usage                  |
| `cockpit.exec(cmd, args?, opts?)`                                            | spawn 一个程序，返回 `{ stdout, stderr, code }`            |
| `cockpit.sh(script, opts?)`                                                  | 跑一段 bash，返回 stdout；退出码非 0 会抛错                |
| `cockpit.job(name, args?)`                                                   | 启动一个已注册的后台作业，返回 task 信息                   |
| `cockpit.log / info / warn / error(…)`                                       | 打印不同级别的日志行                                       |
| `cockpit.progress(pct, message?)`                                            | 更新进度条与进度文案                                       |
| `cockpit.sleep(ms)`                                                          | 可取消的延时                                               |
| `cockpit.fetch(url, opts?)`                                                  | 带取消信号的网络请求                                       |
| `cockpit.notify(title, body?)`                                               | 发一条系统通知                                             |
| `cockpit.fs.readFile / writeFile / readdir / exists / mkdir / stat / unlink` | 本地文件操作                                               |
| `cockpit.storage.get / set / delete / all`                                   | 存在 `~/.config/LinuxCockpit/scripting/storage.json` 的 KV |
| `cockpit.env`                                                                | 主进程环境变量                                             |
| `cockpit.signal`                                                             | 取消信号（停止时触发）                                     |
| `cockpit.config`                                                             | 右侧参数面板里当前填的值                                   |

补充说明：

- TypeScript 与 JavaScript 都能跑：TS 由 esbuild 转译，`async/await`、顶层 `return` 都可用。
- `export const …` 会被去掉再包进 async 函数，所以写模块写法也不会报错。
- 停止脚本时 `cockpit.signal` 触发，正在 `await` 的 `command` / `sh` / `sleep` / `fetch` 会抛错中断。
- 输出是批量推送的：高频 `cockpit.log` 会合并后一次送达界面，不会卡死。

## 声明参数的完整字段

```ts
export const config = {
  key: {
    type: 'string' | 'number' | 'boolean' | 'select' | 'slider' | 'secret' | 'path',
    label: '面板上显示的标题',
    description: '标题下方的小字说明（可选）',
    default: '默认值',
    options: [{ label: '显示名', value: '实际值' }], // 仅 select
    min: 1, // number / slider
    max: 10,
    step: 1, // number / slider
    placeholder: '输入框占位符（可选）'
  }
}
```

- 面板会把 `default` 预填进表单，脚本里读到的就是面板当前的值。
- `secret` 是密码框；`path` 带选择按钮；`slider` 用 min/max/step。
- 每次改代码，面板约 0.25 秒后重新解析，改字段名或删字段都会同步。
