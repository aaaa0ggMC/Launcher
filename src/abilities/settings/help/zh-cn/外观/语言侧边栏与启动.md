# 语言、侧边栏与启动

> 最后更新：2026-10-01

本页对应 **设置 → 外观** 分类下的 **语言**、**侧边栏**、**启动** 三张卡片。

## 语言

**语言** 卡片（标题「语言 / Language」）是一组单选：

- **中文**
- **English (US)**

点选后立即写入配置。卡片下方的小字提示「切换语言后需重载页面才能生效」——
界面多数文案会即时切换；若发现个别文本没跟着变，重启应用即可全部统一。
帮助浮窗也会按新语言自动重新加载目录树。

## 侧边栏

**侧边栏** 卡片（标题「侧边栏排序」）管侧栏条目的排列规则。卡片顶部小字说明：
使用频次与最近使用来自 `apps.csv`，**点开侧栏条目或启动应用都会累加**。

### 排序规则（单选）

| 选项       | 行为                                     |
| ---------- | ---------------------------------------- |
| 字母序     | 按侧栏分类分组、组内按名称字母序（默认） |
| 使用频次   | 按 `apps.csv` 里的打开次数，常用的排前面 |
| 最近使用   | 按最近一次打开的时间，刚用过的排前面     |
| 自定义排序 | 完全按你拖出来的顺序                     |

### 自定义排序

选 **自定义排序** 后展开一张卡片网格，每个能力一张卡（图标、名称、分类、
序号）：

- **拖拽排序**：按住卡片右侧的拖动把手（或卡片任意处）上下拖动；
- **按钮排序**：每张卡右侧有 ↑ ↓ 两个小按钮，点一下移动一位；
- 新加入的能力会自动排在列表末尾；
- 点右上角 **重置为字母序** 一键还原。

顺序保存在 `~/.config/LinuxCockpit/sidebar-order.json`，改动即时广播，
侧栏立刻按新顺序排列。

### 清空使用记录

卡片底部的红色文字按钮 **清空使用记录**：把 `apps.csv` 的所有计数归零，
**立即生效**（点下去会转一小会儿圈）。之后「使用频次 / 最近使用」两种排序
从零开始重新累计。

## 启动

**启动** 卡片只有一个开关：**所有启动前都需确认**（默认开启）。关闭后从应用页
启动条目时不再弹确认框。配置写入即时持久化，下次启动仍然是关闭状态。

> 注意：应用页遇到**中 / 高风险**条目时仍会弹安全确认（带「知道了，以后不再提醒」选项），
> 这是另一套按条目风险控制的机制，不受本开关影响。

## 初始页面不在这页

「启动后默认打开哪个能力」（`config.json` 的 `sidebar.default`，默认 `cli`）
**没有界面开关**，只能用命令行改：

```bash
config.get                                          # 查看 sidebar.default
config.set --patch '{"sidebar":{"default":"apps"}}'  # 改成应用页
```

填不存在的能力 id 时会自动回落到排序后的第一个能力。

## 相关命令

```bash
config.get                                            # 读取 language / sidebar / runtime
config.set --patch '{"language":"en-US"}'             # 切换语言
config.set --patch '{"sidebar":{"sort":"frequency"}}' # 排序改使用频次
sidebar.order.get                                     # 查看自定义排序
sidebar.order.set --order '["apps","aidj"]'           # 覆写自定义排序
stats.list                                            # 查看使用统计
stats.clear                                           # 清空使用记录
```
