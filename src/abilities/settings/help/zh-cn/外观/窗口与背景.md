# 窗口与背景

> 最后更新：2026-10-01

本页对应 **设置 → 外观 → 窗口**（整行大卡）。这张卡管三件事：窗口边框与圆角、
背景来源、以及盖在背景之上的 Fuse 蒙层。

> 生效时机先记住：**无边框 / 圆角下次启动生效；背景与 Fuse 即时生效。**
> （卡片底部的小字说明也是这么写的。）

## 无边框与圆角

卡片最上面两个开关：

- **无边框窗口**：去掉系统标题栏，改用界面自绘的顶栏。**下次启动生效。**
- **圆角窗口**：无边框状态下的窗口圆角。**下次启动生效。** 打开后下方多出
  **圆角半径** 滑块（0–40px、步长 1px、默认 12），松手即应用——调的当时
  就能看到窗口圆角变化，弹窗的遮罩也会跟着用同一个圆角。

## 背景

**背景** 下拉框有三个选项，选中项的作用显示在下方的灰色小字里：

| 选项     | 行为                                     | 生效时机 |
| -------- | ---------------------------------------- | -------- |
| 透明     | 不绘制背景，仅由 Fuse 半透明蒙层提供底色 | 即时     |
| 图片     | 使用你指定的本地图片，可高斯模糊         | 即时     |
| 桌面壁纸 | 自动读取 KDE 桌面壁纸，可高斯模糊        | 即时     |

选 **图片** 时会多出一行 **图片路径**：

- 直接输入框填路径（如 `/home/user/Pictures/wall.jpg`），失焦即保存；
- 或点输入框右侧的文件夹图标按钮（悬停显示「选择背景图片」），在文件选择窗里
  挑一张，支持 png / jpg / jpeg / webp / bmp / svg / gif / avif。

## Fuse 蒙层

Fuse 是盖在背景之上、内容之下的半透明蒙层，决定「背景透出多少」：

- **Fuse 蒙层不透明度**（0–100%）：蒙层浓度，拖动即时生效。拉到 100% 时背景
  被完全盖住；调低才能透出背景。
- **背景图片不透明度**（0–100%）：只在背景选了 **图片** 或 **桌面壁纸** 时
  出现，控制图片本身的浓淡。
- **背景模糊**（0–60px）：对背景做高斯模糊，松手应用。

图层关系（卡片底部小字原文）：`Background(底) → Fuse(中) → Data(顶)`。
图片的实际可见度 = **背景图片不透明度 × (1 − Fuse 蒙层不透明度)**——两个都别
拉满，否则互相抵消。

### 两个常用配方

- **干净纯色界面**：背景 = 透明，Fuse 蒙层不透明度拉高（80% 以上）。
- **壁纸若隐若现**：背景 = 桌面壁纸，Fuse 蒙层不透明度调到 30–60%，
  背景模糊按喜好（10–30px 比较耐看），必要时再降一点背景图片不透明度。

## 相关命令

```bash
config.get     # 查看 window（frameless / rounded / background / fuse*）
config.set --patch '{"window":{"background":"wallpaper","fuseAlpha":0.45,"fuseBlur":20}}'
config.set --patch '{"window":{"frameless":false}}'    # 改回系统边框（下次启动）
config.set --patch '{"window":{"rounded":true,"radius":16}}'
```
