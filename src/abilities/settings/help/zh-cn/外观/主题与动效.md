# 主题与动效

> 最后更新：2026-10-01

本页对应 **设置 → 外观** 分类下的四张卡片：**主题**、**界面缩放**、**字体**、
**界面动画**。除特别说明外，全部即时生效，不用重启。

## 主题

「外观」分类的第一张卡就是 **主题**：一张网格，每套配色一张小卡片，上方是色板
预览（背景色 + 主色与三个强调色的圆点），下方是主题名。当前选中的主题有主色
描边，右上角还有一枚对勾。**点一下就切换**，配置立即写入 `config.json` 的
`theme`。

| 界面名称          | 配置值      | 风格                        |
| ----------------- | ----------- | --------------------------- |
| 深色 (Material 3) | `dark`      | 默认配色                    |
| 亮色 (Material 3) | `light`     | 浅色背景，白天用            |
| 纯黑              | `pureblack` | 纯黑底，OLED 屏省电、对比强 |
| 月光 (靛蓝)       | `moonlight` | 靛蓝冷色，护眼              |
| 森林 (墨绿)       | `forest`    | 墨绿基调                    |
| 极光 (紫罗兰)     | `aurora`    | 紫罗兰色                    |
| 玫瑰 (暖粉)       | `rosy`      | 暖粉色调                    |
| 羊皮纸 (暖色)     | `sepia`     | 暖色纸感，久读不累          |
| 石板 (冷灰)       | `slate`     | 冷灰中性                    |
| 跟随系统          | `system`    | 跟随操作系统亮 / 暗         |

- **跟随系统**固定排在网格最后一张，卡片是虚线边框加一枚魔术棒图标；系统在亮 /
  暗之间切换时，界面会实时跟着变。
- 配置文件里出现未知的主题 id 会自动回落到 `dark`，不会把界面弄坏。

### 切换动效（波纹揭示）

换主题时有没有动画，由 **界面动画** 卡片里的 **现代动效** 总开关决定：

- **开**：新主题从一个起点以波纹揭示的方式扩散到全屏；起点在 **主题切换动画**
  里选（**左上角扩散** / **鼠标处扩散**，越靠近起点越先变色）。
- **关**：主题即时切换，没有任何动画（连悬停浮起之类的微动效也会一起停掉）。

## 界面缩放

第二张卡 **界面缩放**：一条 **缩放比例** 滑块，范围 0.8–1.8、步长 0.05，
拖动时右侧显示百分比，两端标注 **小 / 默认 / 大**。

- **松手**的那一刻才真正应用缩放并写入配置；拖动过程中界面不会变，
  方便你先看好数值再定。
- 缩放是真正的等比缩放（图标、间距、文字一起变），不是只改字号。
- 默认值 1.1（110%）。

## 字体

第三张卡 **字体**：三个单选。

| 选项                | 说明                                     |
| ------------------- | ---------------------------------------- |
| 默认 (Noto Sans SC) | 使用内置 Noto Sans CJK 字体栈            |
| 跟随系统            | 取当前平台的界面字体（`system-ui` 一类） |
| 自定义字体          | 填写系统里已安装的字体族名               |

- 选 **自定义字体** 后会多出一个 **字体族名** 输入框（占位示例
  `Noto Serif CJK SC / LXGW WenKai`）；**失焦或按回车**即保存。
- 自定义字体名留空会回退到默认字体栈，不会把界面变成「默认浏览器字体」。
- 改动即时生效，作用于全局界面（等宽字体栈不受影响）。

## 界面动画

第四张卡 **界面动画**（卡内标题为「界面切换动画」），从上到下四组控件：

1. **现代动效**——总开关。
   - 开：主题切换有波纹揭示动画，并启用页面切换动画。
   - 关：所有动效关闭，主题即时切换（界面会加上 `motion-off`，
     悬停、抽屉、Vuetify 内部过渡全部停止）。
2. **启用切换动画**——切换能力页面时的过渡总开关；**现代动效** 关闭时它不可调。
3. **切换样式**——五种过渡（同样受上面两个开关约束，任一关闭就不可调）：

   | 选项     | 效果               |
   | -------- | ------------------ |
   | 淡入淡出 | 透明度渐变（默认） |
   | 左右滑动 | 横向推入           |
   | 上滑     | 从下方滑入         |
   | 缩放     | 缩放淡入           |
   | 翻转     | 3D 翻转            |

4. **主题切换动画**——新主题从哪儿开始扩散：**左上角扩散** 或 **鼠标处扩散**
   （以切换瞬间鼠标位置为起点）。**现代动效** 关闭时不可调。

以上每一项都是点选 / 拨动后立即保存生效，无需重启。

## 相关命令

```bash
config.get                                  # 查看当前 theme / uiScale / font / animations
config.set --patch '{"theme":"forest"}'     # 直接换主题
config.set --patch '{"uiScale":1.4}'        # 设置缩放
config.set --patch '{"font":{"mode":"system","family":""}}'
config.set --patch '{"animations":{"modernMotion":false,"enabled":false,"pageTransition":"slide","themeTransition":"cursor"}}'
```

返回 [设置](../main.md)。
