# 能力开关

> 最后更新：2026-10-01

位置：**设置 → 能力 → 能力开关**（整行大卡）。这里可以在运行时临时启用 / 禁用
任何能力，不用改文件、不用重启。

## 界面长什么样

卡片里按能力 id 字母序列出所有能力，每行从左到右是：拼图图标、能力名称、
灰色的能力 id、一个开关。已被禁用的能力整行变淡（约 55% 不透明度）。

## 开关的行为

1. 拨动某个能力的开关，页面顶部弹出提示条：
   - 关：「{名称} 已禁用（侧边栏与命令即时隐藏）」
   - 开：「{名称} 已启用」
2. **禁用是即时的**：该能力的侧栏条目立刻消失，它的命令也像「没注册过」一样
   调不出来（界面按钮、CLI、AI 调用全部失效）。
3. **不持久化**：这只是当前这一次运行的状态，**重启应用后全部恢复**。
4. 如果你正停在被禁用能力的页面上，界面会自动跳回侧栏第一个能力。
5. 重新拨开开关立即恢复，侧栏条目与命令一起回来。

## 受保护的能力

有两个能力不能禁用（外壳依赖它们），尝试关闭会弹出橙色提示
「{名称} 无法禁用（受保护）」，开关也会留在开启状态：

- **设置**（本页面自己，禁了就再也打不开）
- **后台任务**（多个能力依赖它提供的能力）

## 什么时候用得上

- 某个实验能力碍事，又不想卸载或改代码；
- 想临时收起身为开发者装的内部能力，给截图 / 演示一个干净界面；
- 排查「是不是某个能力在捣乱」：关掉它，问题消失就找到了。

## 相关命令

```bash
ability.list                                        # 列出各能力及其启用状态
ability.set-enabled --id display --enabled false    # 运行时禁用
ability.set-enabled --id display --enabled true     # 重新启用
ability.describe --id settings                      # 看某能力的命令/作业/帮助清单
```
