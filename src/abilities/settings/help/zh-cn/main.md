# 设置

> 最后更新：2026-10-01

设置是 Linux 系统控制中心的统一配置入口：外壳的外观、窗口、动画、语言、侧边栏，
以及每个能力注入给自己的设置项，全部汇总在这一页。大部分改动**即时生效**，
少数（无边框、圆角）要下次启动。所有配置写入 `~/.config/LinuxCockpit/config.json`，
每次写入前会自动留一份 `config.json.bak` 备份。

> 一句话上手：点侧边栏「系统」分组里的 **设置** → 左栏选 **外观** → 点 **主题** 卡片
> 立即换配色；拖 **界面缩放** 滑块，**松手**才应用。

## 能做什么

- 换配色：10 套主题（含跟随系统亮 / 暗），切换时还可配波纹揭示动效。
- 界面缩放与全局字体：高分屏、视力适配，一站调好。
- 窗口形态：无边框、圆角与半径、背景（透明 / 图片 / 桌面壁纸）与 Fuse 蒙层。
- 动效：现代动效总开关、页面切换过渡样式、主题切换扩散起点。
- 界面语言：中文 / English 即时切换。
- 侧边栏：字母序 / 使用频次 / 最近使用 / 自定义拖拽排序，一键清空使用记录。
- 能力开关：运行时临时启用 / 禁用某个能力（不持久化，重启恢复）。
- 汇总所有能力注入的设置（余额、AI DJ、歌词、播放器、旅行记录、应用、总览、
  AI 与远程……），不用去记忆每个能力把配置藏在哪里。

## 界面速览

「主从布局」：左边分类导航，右边当前分类的设置卡片。

| 区域       | 位置                         | 说明                                                               |
| ---------- | ---------------------------- | ------------------------------------------------------------------ |
| 页头       | 内容区顶部（窄屏隐藏）       | 「设置」标题 + 副标题「各能力注入的设置 · 可搜索分类与具体设置项」 |
| 搜索框     | 左栏顶部；窄屏时在顶部工具条 | 占位文字「搜索设置…」，右侧 × 一键清空                             |
| 分类导航   | 左栏（宽约 200px，自己滚动） | 「通用」组在最上（外壳自己的设置），其余按能力分类分组             |
| 设置项卡片 | 右侧内容区（自己滚动）       | 每项一张卡，默认两列；窗口 / 侧边栏 / 能力开关占整行               |
| 分类下拉   | 窄屏顶部工具条               | 「设置分类」下拉，按分组小标题排列                                 |

几个值得知道的行为：

- **窄屏自适应**：容器宽度小于 620px 时，左侧导航收起成顶部的「搜索框 + 分类下拉」，
  不出横向滚动条。
- **搜索**：输入即过滤。左侧导航只留命中的分类，右侧直接列出所有命中的设置项，
  顶部显示「{n} 项设置」；搜索范围包括分类名、能力名、描述与关键词。
  没有命中时显示空状态「没有匹配的设置 / 换个关键词试试，可搜索分类名或具体设置内容」。
- **位置记忆**：设置页不常驻内存（切走会销毁），但同一次运行内记得你上次打开的
  分类与滚动位置；重启应用后回到默认分类。
- **从别的能力跳进来**：其他能力页面里的「去设置」入口会跳到本页并定位到它的分类；
  指定到具体设置项时，会滚动到位并高亮约 1.6 秒。
- **复制页面**：侧栏底部的文档图标按钮（悬停显示「复制当前页面为 Markdown」）会把
  所有设置分类连同**当前配置值**导出成 Markdown，方便贴给 AI 或存档。
- 侧栏底部的「?」按钮（悬停显示「当前功能的使用帮助」）打开本帮助浮窗。

### 各能力注入的设置

本页只收录**外壳设置 + 各能力自己注入的条目**。注入后自动出现在左栏对应能力
分类下（没有侧栏页面的后端能力也会出现，例如 AI 与远程）。常见的有：

| 能力      | 设置分类    | 典型内容                              |
| --------- | ----------- | ------------------------------------- |
| 余额      | 余额设置    | 平台凭据、自动轮询                    |
| AI DJ     | AI DJ 配置  | API 密钥、模型、播放偏好              |
| 歌词      | AIDJ Lyrics | 卡拉OK / 滚动、字号行高排版           |
| 播放器    | 播放器      | 淡入淡出、EQ、倍速、局域网遥控        |
| 旅行记录  | 旅行记录    | 图库目录、航线目录、地图图源与偏好    |
| 应用      | 应用        | 应用扫描根目录                        |
| 总览      | 总览        | 重置总览页卡片排版                    |
| AI 与远程 | AI 与远程   | MCP / Remote 开关、访问令牌、隐私策略 |

## 常见操作

### 换一套配色

1. 左栏选 **外观**，点 **主题** 卡片网格里的任意一张。
2. 当前主题有主色描边和右上角对勾；点另一张即切换，无需重启。

详见 [外观 → 主题与动效](外观/主题与动效.md)。

### 界面太大或太小

1. 左栏选 **外观**，找到 **界面缩放** 卡片。
2. 拖 **缩放比例** 滑块（0.8–1.8），右侧实时显示百分比。
3. **松手**的那一刻才会应用并写入配置——拖动过程中界面不会变。

### 窗口「方角」难看 / 想露出桌面壁纸

1. 左栏选 **外观**，找到 **窗口** 卡片。
2. 开 **圆角窗口** 后可拖 **圆角半径**（0–40px）。
3. 背景选 **桌面壁纸** 或 **图片**，再调低 **Fuse 蒙层不透明度** 让背景透出来。

详见 [外观 → 窗口与背景](外观/窗口与背景.md)。

### 切换页面时动画太「晃」

1. 左栏选 **外观**，找到 **界面动画** 卡片。
2. 关掉 **现代动效** 总开关：所有动效立即关闭，主题也改为即时切换。
3. 只想换风格：保留现代动效，在 **切换样式** 里选 淡入淡出 / 左右滑动 / 上滑 /
   缩放 / 翻转。

### 换成 English

1. 左栏选 **外观**，找到 **语言** 卡片，点 **English (US)**。
2. 配置立即保存。卡片下方提示「切换语言后需重载页面才能生效」——多数文案会
   即时切换，如发现个别文本没变，重启应用即可全部统一。

### 侧边栏顺序不合习惯

1. 左栏选 **外观**，找到 **侧边栏** 卡片。
2. 选 **自定义排序**，在展开的卡片网格里拖拽（每张卡右侧有拖动把手，
   也可用卡上的 ↑ ↓ 按钮），或点 **重置为字母序** 一键还原。
3. 排序变化即时反映到侧栏。

### 某个能力暂时不想用

1. 左栏选 **能力**，在 **能力开关** 卡片里找到该能力。
2. 关掉它的开关：侧栏入口与命令**即时隐藏**，顶部弹出提示。
3. 重新打开即可恢复；重启应用也会全部恢复。

详见 [能力 → 能力开关](能力/能力开关.md)。

### 启动应用前不想再被确认

1. 左栏选 **外观**，找到 **启动** 卡片。
2. 关掉 **所有启动前都需确认**（默认开启）。配置写入即时持久化。

### 查看版本与技术栈

左栏选 **外观** → **关于** 卡片：显示「Linux System Cockpit · Electron + Vue 3 +
Vuetify 3 (Material 3)」与一句配置目录说明。

## 设置存到哪

| 文件                                          | 内容                                       |
| --------------------------------------------- | ------------------------------------------ |
| `~/.config/LinuxCockpit/config.json`          | 全局外壳配置（本页大部分开关）             |
| `~/.config/LinuxCockpit/config.json.bak`      | 每次写入前自动保留的上一版                 |
| `~/.config/LinuxCockpit/sidebar-order.json`   | 侧边栏自定义排序                           |
| `~/.config/LinuxCockpit/apps.csv`             | 使用频次 / 最近使用统计                    |
| `~/.config/LinuxCockpit/<能力id>/config.json` | 各能力自己的配置（aidj、balance、yarj 等） |

几点说明：

- 写入是「读 → 合并 → 临时文件原子替换」；**如果现有配置读不出来，设置会拒绝保存
  而不是用空配置覆盖**，你的配置不会因此丢失。
- 首次启动会生成一份默认配置（主题 dark、语言 zh、缩放 1.1、动效全开、
  侧栏初始页面 cli、字母序）。
- **初始页面**（启动时默认打开哪个能力，`sidebar.default`，默认 `cli`）不在本页
  提供开关，只能用命令行改：`config.set --patch '{"sidebar":{"default":"apps"}}'`。
- 「AI 与远程」相关配置只有你本人能改：AI 无法通过命令修改 `agent.*`，防止它
  给自己授权。

## 命令行

设置页的每个开关背后都是一条命令，CLI 里同样可用：

```bash
config.get                                    # 读取全局配置（config.json 原文）
config.set --patch '{"theme":"pureblack"}'    # 修改任意配置项，立即广播生效
sidebar.order.get                             # 读取侧边栏自定义排序
sidebar.order.set --order '["apps","aidj"]'   # 覆写侧边栏自定义排序
stats.record --id apps                        # 手动记一次使用
stats.list                                    # 查看使用频次统计
stats.clear                                   # 清空使用记录（计数归零）
ability.set-enabled --id display --enabled false  # 运行时禁用指定能力
ability.list                                  # 列出各能力及其启用状态
ability.describe --id settings                # 生成某能力的命令/作业/帮助清单
ability.describe --id settings --format md    # 同上，输出 Markdown
```

## 常见问题

**改了设置没生效？** 主题、背景、缩放、动效、语言都是即时的；**无边框与圆角要
下次启动**才生效（窗口卡片底部的说明也写了这句）。

**缩放拉到最大还是太小？** 0.8–1.8 是当前支持范围；需要更大可以调系统的 DPI /
显示缩放。

**侧边栏选了「使用频次」却没变化？** 只有点开侧栏条目、或从应用页启动应用才会
累计计数；想重新累计可以先点 **清空使用记录**。

**能力被禁用后找不到了？** 到 **能力 → 能力开关** 里重新打开，或直接重启应用
（禁用状态不持久化）。

**搜索想要的设置搜不到？** 搜索匹配分类名、能力名、描述与关键词；换个更短的关键词
（如「壁纸」「缩放」「排序」）试试。
