# image 分组 · 能力边界

本页记录 image 工具**没有实现 / 有意不做**的能力，避免误以为等价于专业软件或 AI 服务。
所有条目都是本地确定性计算：不联网、不调用任何模型、不读写用户文件。

## 明确不做（不是"以后会做"，而是产品定位不做）

- **AI 相关全部缺席**：没有人像抠图、发丝级蒙版、超分辨率、老照片修复、风格迁移、
  以图生图、AI 上色、智能扩图。`image-filter` 的「漫画风」只是本地色阶 + 对比度 +
  饱和度滤镜组合，效果确定可复现，与 AI 生成无关。
- **`image-background` 只处理纯色背景**：从四边种子做容差连通填充，适用证件照式
  的均匀底色。渐变、阴影、复杂背景、半透明边缘一律无效。
- **`image-montage` 只是 alpha 叠加**：定点叠加 / 整幅混合 / 角标三种模式，不含人脸
  检测、换脸、五官对齐或风格融合。
- **`image-watermark` 输出 SVG**：水印文字用本地字体栈渲染，不加载也不打包字体文件，
  因此**中文显示依赖查看环境**是否装有中文字体；批量盲水印、隐形水印（DCT/频域）
  均未实现。
- **`word-cloud` 使用本机 Intl.Segmenter 分词**（不可用时按单字计数），同义词、词组合并、停用词扩展都不做；排布是固定参数的螺旋避让，宁可
  跳过也不重叠，因此不保证所有词都放得下。
- **`image-ico` 只生成、不解析多个受信格式**：可输出标准 ICO（PNG 条目，256 及以下
  8 个尺寸）；`image-base64` 解码 ICO 时只取内嵌 PNG 条目，BMP 条目的旧式 ICO 不解析。
- **本包不含娱乐向拼图**：emoji 马赛克、文字像素画等按产品决策移出本包范围。

## 依赖与格式限制（Jimp v1 解码能力决定）

- 输入支持：PNG / JPEG / GIF（首帧）/ BMP。**TIFF、WebP、AVIF、HEIC、SVG 位图化
  均不支持**，传入这些格式会返回「无法解析图片」。
- 体积上限：base64 ≤ 32MB，单边 ≤ 8192px，总像素 ≤ 1600 万；在解码前检查尺寸，超出即报错，不静默截断。
- GIF 动画只有第一帧参与处理，输出不再是动画。
- JPEG 输出不支持透明：`image-compress` 选 JPEG 时会用指定底色压平。
- Jimp 自带位图字体（`jimp/fonts`，仅 ASCII）未用于水印：一是中文必然乱码，二是打包后
  字体文件不在产物里。因此水印统一走 SVG。

## 输出说明

- 所有图片结果都以 `ToolFile`（name/mime/base64）返回，保存动作由外层 `toolbox.export`
  统一完成；本分组不自行落盘、不产生磁盘路径，文件名只做字符净化。
- 词云 / 水印的 SVG 画布为固定尺寸（词云 1024×640），水印按原图尺寸；SVG 内不引用
  任何外部资源（图片一律内嵌 base64，文字已 XML 转义）。
