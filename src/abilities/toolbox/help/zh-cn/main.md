# 工具箱

> 最后更新：2026-10-01

工具箱把 80 个常用小工具收在一个页面里：日期时间、开发、文字便民、图片、文档与媒体、效率。
全部在本机计算，不发送任何网络请求、不调用在线 API，也不保存你的输入和结果——
只记住你收藏了哪些工具、最近用过哪些，以及番茄钟完成了几轮。

> 一句话上手：在页面搜索框里输关键词（如 epoch、JSON、二维码）回车打开第一个匹配工具 →
> 填「输入与选项」→ 点 **开始处理** → 在下方「处理结果」区复制、保存或下载文件。

## 能做什么

- 时间与日期：时间戳互转、批量转换、日期差与加减、日历区间、时长、特殊格式、世界时钟、汇率换算（需联网）。
- 开发：JSON / 代码 / CSS / HTML / SQL 格式化与压缩、配置格式互转、正则、UUID、Mock 数据、
  Cron、Markdown、Base64、URL、哈希、进制、颜色、Linux 命令词典。
- 文字便民：字符统计、文本对比与清理、拼音、分词、简繁转换、艺术字、人民币大写、随机选择、
  二维码、密码生成、亲戚称谓、签名 / 印章 / 图标 SVG。
- 图片：压缩、裁剪旋转、滤镜、纯色去底、Base64、ICO、切图、字符画、水印、词云、叠加。
- 文档与媒体：Word / HTML / Markdown / 接口文档互转、表格转换与合并、图片转 PDF、PDF 合并拆分
  加解密与转文本 / 图片 / HTML、Office 转换、音视频转码、视频转 GIF、GIF 抽帧压缩、媒体信息、
  视频区域修补、OCR。
- 效率：本地番茄钟。

## 常见操作

### 打开一个工具

三种方式，效果相同：

1. 在工具箱页面点工具卡片，或用键盘 Tab 聚焦后按回车 / 空格。
2. 在搜索框输关键词，回车直接打开排在第一个的工具。
3. 在顶栏（应用栏）的全局搜索里直接搜工具名或关键词，点结果进入对应工具。

### 用工具处理内容

1. 在「输入与选项」区填字段：必填项没填时点 **开始处理** 会提示缺哪一项。
2. 文本类字段是多行输入框，下拉按枚举选择，文件字段是一个选择框
   （标注了接受的格式；单文件最多 64 MiB，一次最多 128 MiB）。
3. 点 **开始处理**，按钮进入 loading；完成后下方出现「处理结果」。
4. 结果区按工具不同：文本 / JSON 直接显示，图片与 SVG 会画出来，音频视频可播放；
   每个附件下面都有 **下载文件** 按钮，文本还能 **复制结果** 或 **保存文本**。
5. **重置** 清空表单与结果，恢复各字段默认值。

### 文件类工具（文档与媒体这一组）

点 **开始处理** 后会转成后台任务：

- 工具页上的按钮变成 loading，并出现 **停止任务** 按钮可随时中断。
- 侧栏「后台任务」面板同步多出一条以工具名命名的任务，可跨页面查看与停止；
  后台只显示工具名与通用状态，不显示你的文件内容。
- 切走再回到工具页，上一次的结果会自动恢复显示。
- 同一时间最多两个转换任务并行，第三个要等前面的结束。

### 番茄钟

打开后是进度环加开始 / 暂停 / 继续 / 重置按钮，可设专注分钟（默认 25）与休息分钟（默认 5）。
计时按「专注 → 休息」循环，完成一轮专注计数加一。**离开页面会自动暂停**（不在后台空转），
只保存完成次数，不保存其他任何内容。

## 隐私与安全

- 输入、输出与错误信息都标记为敏感内容，AI 快照与截图会脱敏。
- 密码输入框是 AI 禁区；哈希摘要、PDF 加密 / 解密、密码生成四个工具禁止 AI 调用，
  密码生成的结果按凭据对待。
- 外部转换在随机临时目录内以固定参数数组执行；PDF 密码经 stdin 传给 qpdf，
  不进命令行参数、不写日志；Office 文件打开前会检查宏与外部引用。
- 收藏的只是工具 ID，最近使用的也只是工具 ID；输入与结果不落日志、不落盘
  （临时文件在任务结束后清理）。

## 命令行

每个工具都有一条命令，界面与命令行共用同一套处理逻辑：

```bash
toolbox.list                                                    # 列出全部工具与输入字段
toolbox.epoch-converter --timestamp 1700000000 --unit s --zone Asia/Shanghai
toolbox.hash --input hello --algorithm sha256                    # 摘要（agent 禁止调用）
toolbox.start --tool pdf-merge --args '{"files":[…]}'            # 文件类工具转后台任务
toolbox.task --id <任务id>                                       # 读取任务状态与结果（仅内存）
toolbox.cancel --id <任务id>                                     # 取消文件任务
toolbox.export --path /abs/out.png --base64 <base64>             # 保存附件
```

## 常见问题

**报「处理失败，请检查输入和本机依赖」？** 先看工具卡片或详情页是否标了 **需要本机安装**：
ffmpeg、qpdf、LibreOffice、poppler-utils、tesseract 缺哪个就装哪个；不带依赖的工具则是输入
格式不对，错误提示会说明原因。

**结果里的图片看不到？** 结果区只直接渲染 SVG 与 PNG/JPEG/GIF/WebP；其他格式一律走
**下载文件** 存到本地再看。

**上传文件没反应或报太大？** 单个文件上限 64 MiB、一次总计 128 MiB，超限会被拒绝；
重新选择更小的文件即可。

**切页面后任务去哪了？** 文件类任务在侧栏「后台任务」里继续跑，回到工具页结果会自动恢复；
非文件工具是即时计算，没有后台任务。
