# 接口调试

> 最后更新：2026-10-01

接口调试（界面标题为 Provider Playground）是一个面向 API 的请求试验台：把请求写成**模板**，
模板里的 `{变量}` 自动生成表单，发出去的响应还能按 **JSON 路径** 抽取成文本、图片、音频、视频，
或交给后台任务轮询。所有模板、变量与历史都保存在本机浏览器存储里，可整包导出成 JSON 备份。

> 一句话上手：右侧「Provider」面板点 **新建** → 填 **URL 模板** 和请求体 → 在下方「填写变量」
> 区填值 → 点 **发送请求** → 在「响应」区看结果。

## 能做什么

- 用模板反复调同一个接口：URL、请求头、请求体都能写变量占位，换参数不用改文本。
- 变量自动变成表单：数字区间变滑块、枚举变下拉、长文本变多行输入框，还能给默认值。
- 发送请求并查看响应：JSON 自动渲染成可折叠的树，也能切到原始文本、复制或下载。
- 用「响应变换」把响应里的正文、图片链接、base64 音频、视频 URL 直接抽出来播放或下载。
- 异步任务（先生成任务 ID、再轮询结果）交给后台任务跑，切页面也不中断。
- 整套配置（模板 + 全局变量 + 已填值 + 历史）导出为 JSON，换机器一键导入。

## 界面速览

| 区域         | 位置         | 说明                                                             |
| ------------ | ------------ | ---------------------------------------------------------------- |
| 页面工具栏   | 页面顶部一行 | **导出配置**、**导入配置**                                       |
| 主列         | 页面左侧主体 | 依次是模板编辑、填写变量、最终响应、响应                         |
| 右侧浮动面板 | 页面右侧常驻 | 标题「Provider」，含 **全局变量** 与模板列表，可折叠成一个小按钮 |
| 删除确认弹窗 | 屏幕中间     | 删除模板前的二次确认，不可撤销                                   |

**主列从上到下的四块**：

1. **模板编辑**：模板名称输入框、方法下拉、**删除模板** 按钮、「从其他模板复制」一行、
   「URL 模板 / 请求头 / 请求体」三块输入、**响应变换** 区，以及自动识别出来的变量徽章。
2. **填写变量**：按模板里的变量生成表单，右上角有 **历史 (n)** 与 **清空**，
   最下面是通栏的 **发送请求**（发送中显示「发送中…」）。
3. **最终响应**：响应变换的结果（文本 / 图片 / 音频 / 视频），标题行可点击折叠。
4. **响应**：原始响应，带状态码与耗时，可切换 **树** / **原始**、复制、下载、清空。

**右侧浮动面板**：面板头右侧的箭头按钮可把整块折叠成右上角一个收起按钮（悬停显示 **展开全部** /
**收起**）；展开时上方是 **全局变量**（默认收起，点标题行展开），下方是模板列表，
右上角 **新建** 新建模板。没有选中任何模板时，主列只显示「请选择或新建一个请求模板」。

## 常见操作

### 新建、切换与删除模板

1. 在右侧模板列表点 **新建**，主列立即出现一份空白模板并自动选中。
2. 在「模板名称」输入框起个名字，用方法下拉选 GET / POST / PUT / DELETE / PATCH。
3. 点列表里任意模板即可切换；切走时当前填写的变量值会被记住，切回来自动带回。
4. 删除：点模板编辑里的 **删除模板**，弹窗里确认 **删除**；弹窗有 **取消** 可反悔。
   删除模板会同时删掉它的发送历史。

### 填写变量并发送请求

1. 模板里每写一个 `{名字}`，下方「填写变量」就多一个输入项；带约束的会显示提示
   （如 `(256 – 1024)`、`(min 1)`）。
2. 按提示填值，点通栏的 **发送请求**。
3. 发送过程中按钮进入 loading，响应到达后「响应」区显示状态码（小于 400 为绿色、其余红色）
   与耗时毫秒数；失败时红色等宽字体显示错误信息。
4. 同一个模板的每次发送都会记入 **历史 (n)**，点历史条目可以把当时的一组值填回表单。

### 查看响应

- **树 / 原始**：响应是 JSON 时出现两个切换按钮。树视图按层级折叠，超过 80 字符的字符串
  收成一行，点它旁边「〔点击展开〕」看全文；非 JSON 响应只显示一个 **原始** 展开开关。
- **复制**：把原始响应文本写进剪贴板。
- **下载**： JSON 存为 `response.json`，其余存为 `response.txt`，位置在保存对话框里选。
- **清空**：清掉当前响应与变换结果，方便发下一次。

### 从其他模板复制

模板编辑里「从其他模板复制」一行（有其他模板时才出现）：先在**选择源模板**下拉里选一个模板，
再点 **全部** / **请求头** / **请求体** / **变换**，把对应部分覆盖到当前模板。

### 导出与导入配置

- **导出配置**：弹出保存对话框（默认文件名 `playground-<时间戳>.json`），
  写入模板、全局变量、已填值与历史；成功后顶部提示「已导出 n 个模板」。
- **导入配置**：选择之前导出的 JSON，四类数据整体替换当前值，提示「已导入 n 个模板」；
  文件格式不对时提示「导入失败：…」，当前数据不受影响。

> 导出文件是明文 JSON，包含全局变量的值。要备份或分享前，先把带密钥的全局变量删掉。

### 把整页复制成 Markdown

顶栏（应用栏）的「复制当前页面为 Markdown」图标按钮会把模板列表、当前模板、已填变量、
全局变量、原始响应与最终响应拼成一份 Markdown。标记为密码的全局变量只输出 `••••••`。

## 隐私与安全

- 全局变量行内的值可以点眼睛图标切成密码显示；复制整页为 Markdown 时这类值会被遮成 `••••••`，
  不会连密钥一起进剪贴板。
- 请求由界面直接发出，等于在浏览器里打开这个地址：跨域接口受 CORS 限制，
  需要直连的场景请改用命令行或脚本。
- 导出的 JSON 是明文，谁拿到文件就能看到里面的密钥，请按机密文件对待。

## 命令行

界面里的导入导出与远程下载都走这三条命令（其余功能都是纯界面）：

```bash
playground.export --path /abs/playground.json --data {"data":{...}}   # 导出配置到指定文件
playground.import --path /abs/playground.json                        # 读取配置文件
playground.download-url --url https://... --path /abs/file.jpg       # 下载远程图片/音视频到本地
playground.download-url --text "内容" --path /abs/out.txt            # 或把一段文本写到本地
```

## 常见问题

**发送请求失败，控制台报跨域错误？** 请求是从界面发出的，目标服务器没有放行跨域就会被拦。
可以先 `curl` 验证接口本身没问题，再确认是否需要代理或改用命令行发送。

**某个变量没有出现在表单里？** 三种可能：它的名字在右侧「全局变量」里定义过（全局变量自动注入，
不显示为表单字段）；变量名含有数字以外的特殊字符；三个输入框（URL/请求头/请求体）里都没有再写它。

**发送出去的文本里还留着 `{xxx}`？** 说明这个变量没有填值、也没有配默认值，界面会原样留下占位符。
在变量写法末尾加 `default(值)` 就能兜底。
