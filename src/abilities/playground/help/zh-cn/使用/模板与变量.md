# 模板与变量

> 最后更新：2026-10-01

模板由四段文本组成：**URL 模板**、**请求头**、**请求体**，加上一段 **响应变换**。
前三段里写的 `{变量}` 会被自动收集，生成下方「填写变量」表单；发送时再用你填的值替换。
本页讲变量写法、表单生成规则和数据存放位置。

## 变量写法

变量必须写在花括号里，名字只能是英文字母、数字和下划线且不能以数字开头。
写在 `{ }` 里的普通 JSON 大括号对象不会被当成变量。

| 写法                    | 效果                                                 |
| ----------------------- | ---------------------------------------------------- |
| `{name}`                | 单行文本输入                                         |
| `{name:string}`         | 单行文本输入（显式声明）                             |
| `{name:number}`         | 数字输入；带 `range` 约束时变成滑块                  |
| `{name:textarea}`       | 多行输入框                                           |
| `{name:bool}`           | 复选框                                               |
| `{name:select}`         | 下拉选择（选项来自约束）                             |
| `{name:range(1,100)}`   | 自动按数字处理：滑块 + 数字输入，两端标出最小/最大值 |
| `{name:options(a,b)}`   | 自动按下拉处理，选项为 a / b                         |
| `{name:min(1)}`         | 数字输入，提示 `(min 1)`                             |
| `{name:max(10)}`        | 数字输入，提示 `(max 10)`                            |
| `{name:...:default(v)}` | 预填默认值 v；发送时若留空也用这个值兜底             |

几点说明：

- 约束和默认值要写在类型后面，用冒号分隔，例如 `{width:number:range(256,1024)}`。
- `default(值)` 可以出现在约束串的末尾；值两侧的引号会被去掉。
- 类型写错或不认识时按单行文本处理，不会报错。
- 同一个变量名在多处出现只算一个，表单里也只有一项（以最先出现的写法为准）。
- 变量徽章：模板编辑底部会把识别出的变量按「全局（自动填充）」和「表单字段」分组显示成小标签，
  标签后半段的灰色小字是类型、区间与默认值，例如 `number 256-1024 =1024`。

## 表单怎么生成

「填写变量」区按变量声明渲染不同控件：

| 变量声明              | 控件                                   |
| --------------------- | -------------------------------------- |
| `bool`                | 复选框                                 |
| `select` 或带 options | 下拉选择                               |
| `textarea`            | 多行输入框                             |
| `number` + `range`    | 滑块，下方左右是 min / max，中间可输入 |
| `number`（无 range）  | 数字输入框                             |
| 其余                  | 单行输入框                             |

进入页面或切换模板时，表单会用「默认值 + 上次保存的值」预填；点 **历史 (n)** 里的某条记录，
会把那次发送用的一组值整套填回表单。**清空** 只清当前模板的历史记录。

## 请求是怎么拼出来的

发送时按下面的顺序合并成最终值：**变量默认值 → 全局变量 → 你在表单里填的值**。
表单里留空的变量会退回默认值；两者都没有时，占位符原样留在请求里。

- **请求头**：按行解析，每行写成 `Key: value`；没有冒号或冒号在第一位的行被忽略。
- **请求体**：类型为 `string` / `textarea` 的值会先做 JSON 转义（反斜杠、双引号、换行、
  制表符），所以多行文本可以直接塞进 JSON 字符串。
- **GET 请求**：即使填了请求体也不会发送。
- **变量替换是纯文本替换**：URL 里写 `{model:string}`，填 `gpt-4o` 就得到 `.../v1/gpt-4o`。

## 全局变量

右侧「Provider」面板顶部的 **全局变量** 用来放跨模板共用的值（API Key、模型名等）：

- 点标题行展开 / 收起，标题右侧的数字是当前条数。
- **添加变量** 新增一行，左边填名字、右边填值；眼睛图标在明文与密码显示之间切换。
- 在这里定义过的名字不会出现在表单里，而是在发送时自动注入；
  模板编辑的变量徽章里它们归在「全局（自动填充）」一组。
- 名字可以和模板变量重名——重名时全局变量会被表单的值覆盖。

## 从其他模板复制

模板编辑里「从其他模板复制」一行：选好源模板后可点 **全部**（URL + 请求头 + 请求体 + 变换）、
**请求头**、**请求体** 或 **变换**，把对应内容覆盖到当前模板，省得重复粘贴。
复制只是覆盖这几段文本，不会改动模板名称与方法。

## 数据存在哪里

全部存在浏览器 localStorage，按应用启动时读取，关掉窗口也保留：

| 键                   | 内容                                     |
| -------------------- | ---------------------------------------- |
| `rp_templates`       | 模板列表                                 |
| `rp_globals`         | 全局变量                                 |
| `rp_values`          | 每个模板已填写的变量值                   |
| `rp_history`         | 发送历史（时间、耗时、是否出错、那组值） |
| `rp_active`          | 上次打开的模板 id                        |
| `rp_panel_collapsed` | 右侧「Provider」面板是否折叠             |

首次进入会自带一份名为 Example API 的示例模板（指向 httpbin.org），可以直接发送试手。
想搬到另一台机器或备份，用顶部 **导出配置** / **导入配置**。
