# 软件源

> 最后更新：2026-10-01

「软件源」管理 Arch Linux 的 pacman 镜像源文件 `/etc/pacman.d/mirrorlist`。它用一套自定义的
`[MIRROR]` 注释格式给每个源起名字，页面上一个源一张卡片、一个开关；测速、禁用、启用都是即时操作。
改这个文件需要 root 权限，所以每次写入都会走系统提权（pkexec）——这是它和别的页面最不一样的地方。

> 一句话上手：点页面右上角 **测速** 看看哪个源快 → 把想要的源卡片下的开关拨到 **已启用**。

## 能做什么

- 列出 mirrorlist 里所有镜像源及其启用状态，卡片按「已启用优先、延迟低的靠前」排序。
- 一个开关启用 / 禁用单个源，pacman 天生支持多源同时启用，勾几个随你。
- **测速**：对每个源各下载一个小文件，给出延迟（ms）与速度（MB/s）。
- 旧格式（裸 `Server =` 行）文件直接就能读，不用先手工转换。
- 失败的提权 / 写入不会碰坏原文件，页面顶部会给出错误提示。

## 界面速览

| 区域       | 位置       | 说明                                                                           |
| ---------- | ---------- | ------------------------------------------------------------------------------ |
| 标题行     | 页面最上方 | 「软件源」标题 + 副标题「Arch Linux 镜像源 · 已启用 N 个」；右侧 **测速** 按钮 |
| 错误提示   | 标题行下方 | 上次操作失败时的红色 alert（如取消授权、写入失败）                             |
| 镜像源卡片 | 页面主体   | 网格排布：名称、URL、测速结果；底部是启用开关                                  |

每张卡片：左侧状态图标（已启用 = 绿色对勾，未启用 = 灰色地球）、**源名称**，测速后在名称右侧
出现延迟 chip（<300ms 绿色、<800ms 橙色、更慢红色，失败显示红色 **超时** chip）；下方是源的
URL 小字；测速成功的还会多一行下载图标加速度。已启用的卡片带一圈淡绿边框。卡片底部就是这次的
开关，文字显示当前状态（**已启用** / **已禁用**），操作中会转圈。

## 常见操作

### 启用 / 禁用镜像源

点卡片底部的开关即可。拨动的背后发生这些事：

1. 只改目标源那一行 `Server` 的注释前缀（禁用加 `# `，启用去掉 `# `），**文件里其它行原样不动**。
2. 新内容先写到临时文件，再经 pkexec 提权、由 helper 脚本用 `mv` **原子替换**原文件。
3. 所有读取和开关操作串行排队，快速连点也不会写花。

提权框弹出时输密码即可；**取消或输错**，本次写入作废，原文件保持原样，页面顶部提示
`pkexec 失败: ...`。装过本项目自带的 polkit 规则后，授权一次约 5 分钟内再操作不再重复弹密码。

### 测速

点右上角 **测速**，按钮进入加载状态；完成后每张卡片显示延迟与速度，并重新排序（快的在前）。
测速只是下载每个源的 `core` 仓库索引文件试水，最多拉 512KB、10 秒超时——**不会安装或修改任何包**。

### 换成另一批源

页面上只能开关 mirrorlist 里已有的源。想加新源，两种办法：

- 在 `~/.config/LinuxCockpit/mirror/config.json` 里预置（见[镜像源格式](软件源/镜像源格式.md)），
  之后它会以「已禁用」状态出现在页面上，拨下开关即写入 mirrorlist。
- 或者直接手工编辑 `/etc/pacman.d/mirrorlist`，按 `[MIRROR]` 格式写好后刷新页面。

## 命令行

```bash
mirror.get                                  # 当前镜像源列表与状态
mirror.toggle --name USTC --enable true     # 启用镜像源（--enable false 为禁用，需 pkexec 提权）
mirror.test                                 # 测试所有镜像源连通性与速度
```

## 常见问题

**点了开关弹密码框？** 写 `/etc/pacman.d/mirrorlist` 需要 root，这是正常的。取消就什么都不改。
想免重复输入密码，安装项目自带 polkit 规则（`scripts/49-cockpit-pkexec.rules` → `/usr/share/polkit-1/rules.d/`）。

**报 `pkexec 失败` 怎么办？** 密码输错、授权被拒或 helper 脚本不可执行都会这样。原文件没有被动过，
重新拨一次开关即可；页面顶部的红色提示里有具体原因。

**写坏了能恢复吗？** 每次成功写入前，helper 会把原文件备份到 `/etc/pacman.d/mirrorlist.cockpit.bak`，
需要时拷回去即可。

**toggle 之后文件里怎么多了一块？** 旧格式（裸 `Server =` 行）的文件第一次开关时，Cockpit 会按
`[MIRROR]` 格式把该源追加到文件末尾，原来的裸行保持原样。可能出现同一个 URL 出现两次的情况
（pacman 多源下会被访问两遍），建议顺手把旧行删掉。细节见[镜像源格式](软件源/镜像源格式.md)。

**可以同时启用多个源吗？** 可以，pacman 原生支持多源，且不要求排序——卡片顺序只是展示顺序。

**测速全超时？** 检查网络 / 代理，或源站本身不可达；失败的源会显示红色 **超时** chip，不影响开关。
