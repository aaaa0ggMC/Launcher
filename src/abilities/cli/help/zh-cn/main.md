# 命令行

> 最后更新：2026-10-01

命令行页是一个内嵌的 REPL（交互式命令行）。侧栏各能力的按钮背后都是一个个注册命令，
这里可以直接敲命令名调用它们——包括界面上没有暴露的操作，也是排查「按钮点了没反应」时
最快的验证方式。打开即用，无需登录。

> 一句话上手：输入 `help` 回车看全部命令；输入 `mirror.list` 这类
> `<能力>.<命令>` 直接执行；**Tab 补全**、**↑↓ 翻历史**。

## 能做什么

- 执行任何已注册的能力命令：`<能力>.<命令> --参数 值`。
- 输入 `help` 列出全部命令（按能力分组），等于一份活的命令词典。
- 应用相关快捷命令：`list` / `ls`、`info <别名>`、`launch <别名> [操作]`。
- 直接敲应用别名启动应用（如 `steam`），别名后加一个词执行它的附加操作。
- **Tab 补全**（内置命令 + 全部应用别名 / id）、**↑ / ↓** 翻历史命令。
- 命令错误以红字显示，不会中断会话，可以接着敲下一条。

## 界面速览

| 区域       | 位置           | 说明                                                       |
| ---------- | -------------- | ---------------------------------------------------------- |
| 页面标题   | 顶部           | 「命令行」+ 副标题「别名启动 · 标签补全 · info <alias>」   |
| 输出区     | 标题下方大卡片 | 你输入的命令（❯ 开头，主题色）与输出 / 错误混显，自动滚底  |
| 输入行     | 输出卡片最底部 | ❯ 提示符 + 输入框，占位提示「输入命令，Tab 补全，↑↓ 历史」 |
| 补全提示   | 输入行上方     | 多个候选时出现的 chip，点一下直接填入                      |
| 运行中提示 | 输出末尾       | 命令执行期间显示「运行中…」                                |

输出区是会话式的：每条输入的命令原样回显（❯ 开头），随后是它的输出；
出错时错误文本以红色显示。输入框始终自动获得焦点，敲完直接回车。

## 常见操作

### 执行一条命令

1. 点一下输入框（打开页面时已自动聚焦）。
2. 输入命令名，如 `system.stats`，回车。
3. 输出以文本形式追加到上方：对象是缩进 JSON，数组一行一条，
   空结果固定显示 `(无结果)` 或 `(空)`（这两处文案不随界面语言变化）。

参数写法：`--参数名 值`，例如：

```text
docker.action --name my-container --action restart
logs.query --level warn --limit 50
ft.load --name heart
```

- `--开关` 后面不跟值时为布尔 `true`（如 `--exclude-self`）。
- 多数命令读 `--` 参数；位置参数（不加 `--` 的词）会原样传入，少数命令不用。
- 执行期间输入框上方显示「运行中…」，完成后焦点回到输入框。

### 查全部命令

输入 `help` 回车。输出分两部分：顶部是应用类命令速查（来自 apps 能力），
下面按能力分组列出每条命令的用法与说明，例如 `[dashboard]`、`[logs]`、`[ft]`。
拿不准某个能力有哪些命令时，先 `help` 再照着敲。

### 补全与历史

- **Tab**：对「内置命令 + 全部应用别名 / id」补全。只有一个候选时直接补全；
  有多个候选时先补到最长公共前缀，再按一次列出候选 chip，点 chip 填入。
- **↑**：翻出上一条历史（更早）；**↓**：翻回更新的；到最新后清空输入框。
- 历史只在当前会话内存里，重启应用清空。

### 启动应用

- `list` 或 `ls`：列出全部应用（别名 + 名称），没有应用时输出 `(空 — 没有找到应用)`。
- `info <别名>`：查看应用详情——名称、别名、路径、类型与命令、风险等级、标签、
  附加操作列表。别名可以是应用的 alias、id 或标签。
- `launch <别名> [操作]` 或 `run <别名> [操作]`：启动应用 / 执行它的附加操作。
- 直接敲 `<别名>` 等价于 `launch <别名>`；`<别名> <操作>` 执行附加操作。
- 启动成功输出「已启动 <名称> (pid N)」，失败输出具体错误原因。

### 输错了怎么办

- 命令名不存在：输出 `未知命令: xxx (输入 help 查看全部命令)`（红色），会话继续。
- 命令执行中抛错：输出 `错误: <原因>`，例如缺 `--name` 时 docker.action 会提示
  `需要 --name`。
- 命令存在但当前被平台 / 模式过滤不可用：同样按未知命令处理。
- 输错了改完再回车即可，没有「撤销」概念，也不会写坏任何配置。

## 深入阅读

- 「CLI-first」是本项目的核心设计：界面按钮与这里的命令走同一个注册表，
  所以任何按钮能做的事，都能在这里原样重放，也方便写脚本 / issue 复现步骤。
- 提权命令（如 `hardware.pm-toggle`、镜像源切换）执行时会弹系统 polkit 密码框；
  安装过 polkit 规则后 wheel 组用户 5 分钟内免重复输密码（见 AGENTS.md §3.1）。
- 隐私：命令行来源的调用照常执行；AI / 远程来源调用的命令才受隐私 SDK 拦截授权。

## 命令行

本页就是命令行，以下是最常用的几条：

```bash
help                                        # 列出全部命令（按能力分组）
list                                        # 列出全部应用（ls 等效）
info steam                                  # 查看应用详情
launch steam                                # 启动应用（run / 直接敲别名等效）
system.stats                                # 执行总览的采集命令
logs.query --level error --limit 20         # 直接查最近 20 条错误日志
mirror.toggle --name USTC --enable true     # 启用一个镜像源
```

## 常见问题

**Tab 没反应？** 当前输入没有以它为前缀的候选（内置命令或应用别名）时补全不动作；
先敲几个字母再按 Tab。

**怎么清空输出区？** 目前没有内置 `clear` / `quit` 命令，输出会一直累积；
重启应用即清空（会话记录不落盘）。

**别名和 id 都能用吗？** 都能。别名解析同时匹配应用的 alias、id 和标签，且大小写不敏感；
`launch` 只接受单个词，名字带空格的应用请用它的别名。

**命令输出一大段 JSON 怎么看？** 对象按缩进 JSON 显示，数组一行一条；
想结构化查看可以回到对应能力的界面（同一命令的结果）。

**历史能保存吗？** 不能，历史仅在当前会话内存中，刷新 / 重启即丢失。
