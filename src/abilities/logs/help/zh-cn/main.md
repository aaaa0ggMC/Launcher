# 日志

> 最后更新：2026-10-01

日志页是 Cockpit 的「黑匣子」窗口：主进程各模块和渲染端转发的告警 / 错误都汇入同一条管道，
按级别着色、实时滚动，可以从当前会话里翻页回看，也能一键导出。
日志同时按天落盘到 `~/.config/LinuxCockpit/logs/cockpit-YYYY-MM-DD.log`，
本页面默认展示的是**本次运行（当前会话）**的内容。

> 一句话上手：打开「日志」页即自动定位到最新一条并开始实时滚动；
> 顶部 **级别** 下拉框选 ERROR 只看错误，点 **导出** 保存当前会话。

## 能做什么

- 实时查看主进程与渲染端的全部日志：时间、级别、来源模块（scope）、消息四列。
- 按级别过滤：全部 / DEBUG / INFO / WARN / ERROR，选完从头加载最新一页。
- 翻页回看：虚拟滚动，每页 300 条，往上滚自动加载更早的记录。
- 实时尾部：新日志到达时若你停在底部就自动跟随；往上翻了就停在那儿不打扰。
- 5 秒内重复的同类日志合并成一条并显示 `*N`，避免轮询类噪声刷屏（磁盘文件仍保留全部原始行）。
- 导出当前会话为 `.log` 文件，便于贴 issue 或留档。
- 顶栏「复制当前页面为 Markdown」可把当前可见记录复制成文本。

## 日志从哪来

- **主进程**：各模块通过框架日志器（scope 如 `mirror`、`dashboard`、`apps-cli`）写入，
  同时进三个地方——控制台、按天轮转的日志文件、内存环形缓冲（上限 20000 条）。
- **渲染端**：界面里的 `console.warn` / `console.error` 与未捕获异常会转发成
  scope 为 `renderer` 的日志（`logs.post`）。
- **实时推送**：新日志通过广播推送给所有窗口，日志页收到就追加、按级别筛选后显示。

## 界面速览

| 区域           | 位置           | 说明                                                     |
| -------------- | -------------- | -------------------------------------------------------- |
| 页面标题       | 左上           | 「日志」+ 副标题「当前会话日志 · 按级别过滤 · 实时滚动」 |
| 条数           | 标题行右侧     | 「共 N 条」= 当前筛选条件下会话内的总条数                |
| 忽略 logs 自身 | 条数右侧开关   | 隐藏日志能力自己产生的记录（默认开，选择会被记住）       |
| 级别           | 开关右侧下拉框 | 全部 / DEBUG / INFO / WARN / ERROR                       |
| 导出           | 最右侧按钮     | 导出当前会话日志到文件                                   |
| 加载更早日志   | 列表上方居中   | 还有更早记录时才出现，点它手动再翻一页                   |
| 日志列表       | 页面主体       | 虚拟滚动，每行固定高 28px                                |

每一行的四列：**时间**（时:分:秒.毫秒）、**级别**、**来源**（模块名）、**消息**；
鼠标悬停某行可看到完整消息（超长会在行内省略）。WARN 行带浅橙底色，ERROR 行带浅红底色，
级别文字也按级别着色；合并过的行尾有 `*N` 计数。

## 常见操作

### 只看错误

点顶部 **级别** 下拉框选 **ERROR**，列表立即按该级别重新加载（仍从最新一页开始）。
选 **全部** 恢复。切换级别会保留「忽略 logs 自身日志」的开关状态。

### 翻更早的记录

- 列表上方出现 **加载更早日志** 按钮说明还有更早记录；往下滚动到底看到的是最新一页。
- 两种翻页方式：直接点 **加载更早日志**，或把列表往上滚到顶（自动触发加载上一页）。
- 每页 300 条；翻到底后按钮消失，条数显示即为当前会话的总量。

### 实时尾部怎么用

- 打开页面就在底部，新日志到达后自动滚到最新（不用手动操作）。
- 一旦往上翻（离开底部超过约 24px），自动跟随暂停，新记录仍会追加但不会打断你的阅读。
- 想看实时，滚回底部即可恢复跟随。

### 忽略日志能力自己的噪声

「忽略 logs 自身日志」开关默认开启，隐藏 scope 为 `logs` 的记录和 ipc 里以 `logs.` 开头的
调用行——也就是查日志这个动作本身产生的日志。磁盘文件始终完整保留它们。
开关状态记住在浏览器 localStorage（键 `cockpit-logs-ignore-self`），关掉后可排查
「日志页自己出了什么问题」。

### 导出当前会话

1. 点顶部 **导出** 按钮。
2. 在系统保存对话框里选位置（默认文件名形如
   `cockpit-session-2026-10-01-12-30-00.log`）。
3. 导出成功后顶部弹出绿色提示「已导出 N 条日志」。

导出的是**当前会话内存缓冲**里的记录（默认不限级别，最多 20000 条），
与屏幕上是否过滤无关——命令级导出可用 `--level` 指定级别。
需要按月 / 跨会话的历史，请直接复制 `~/.config/LinuxCockpit/logs/` 下的日志文件。

## 深入阅读

- 日志文件轮转规则：按天切分 `cockpit-YYYY-MM-DD.log`，单文件 10MB 上限、
  保留 14 天、超期归档为 `.gz`。目录下文件可直接用文本编辑器打开。
- 与后台任务的关系：后台任务的输出显示在「后台任务」面板，不一定写进这里；
  本页聚焦框架级日志。

## 命令行

日志查询与导出同样是命令：

```bash
logs.query --level warn --limit 200 --exclude-self   # 查询会话日志（可加 --scope / --exclude-scopes / --before）
logs.export --path /abs/session.log --level info     # 导出当前会话到文件，可按级别
logs.post --level error --scope renderer --message "boom"   # 手动提交一条日志
```

## 常见问题

**切到别的能力再回来，记录没了？** 日志页不缓存页面状态（keepAlive 关闭），
每次进入都从最新一页重新加载；更早记录仍在，往上翻即可。

**没有搜索框，怎么找关键字？** 当前界面只支持按级别过滤与翻页，没有关键字搜索。
可按 scope 过滤的命令行走 `logs.query --scope <模块名>`，
或导出文件后用文本编辑器搜索。

**「共 N 条」和页面看到的对不上？** 条数是当前级别 / 忽略自身条件下的会话总量；
页面默认只加载最新 300 条，更早的记录要往上翻才会一页页加载进来。

**重启后日志全空了？** 页面展示的是本次运行的内存缓冲，重启即从零开始；
历史请去 `~/.config/LinuxCockpit/logs/` 按日期找文件。

**同一条消息反复出现？** 5 秒内的同类重复会合并为一条并显示 `*N` 计数，
这是降噪设计；磁盘文件里每次都是独立一行。
