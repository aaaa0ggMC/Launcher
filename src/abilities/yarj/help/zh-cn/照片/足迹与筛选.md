# 照片、足迹与筛选

> 最后更新：2026-10-01

这一页讲照片侧的所有功能：位置照片抽屉、全屏查看器、编辑与补坐标、
「我的探索」旅途漫游、搜索语法与高级筛选规则。

## 位置照片抽屉

在地图上点聚合圆圈或单个圆点，屏幕右侧滑出「位置照片」抽屉（宽 420px）：

- **标题栏**：显示「位置照片 (N)」与该处坐标；若抽屉内用了过滤，显示「过滤后 / 总数」。
- **平移图标**（悬停显示「整体平移这组照片的 GPS 定位」）：整组平移到新位置，保留各照片相对间距；进入多选并勾选后，只平移勾选的照片（图标上带数量徽标）。
- **我的探索** 按钮：以这组照片开启旅途探索回放。
- **过滤框**：只过滤当前列表（文件名、标签、备注…），旁边「?」按钮打开高级语法指南。
- **加载更多照片 (当前/总数)**：列表到底部自动续页，也可点按钮手动加载；每页数量在设置里调。
- 底部 **多选** 开关：打开后点卡片勾选，底部出现 **全选 / 全不选** 与 **平移所选**。

## 照片卡片

每张照片一张卡，自上而下：

- 缩略图：点一下全屏查看；多选模式下点一下勾选。左上角有勾选框（多选时常驻）。
  视频文件右下角有摄像机图标。
- 文件名与拍摄时间；地址框（逆地理编码结果）、**GPS 已纠正** 框（含偏移距离与原因）、
  **大致 GPS 猜测** 框（见下文）；备注与标签 chips（没有时点「添加标签/备注」）。
- 底部图标从左到右（悬停显示名称）：

| 图标         | 作用                                       |
| ------------ | ------------------------------------------ |
| 铅笔         | 编辑坐标、标签与备注                       |
| 花括号       | 展开 / 收起完整数据库元数据（JSON 树）     |
| 地图标记半径 | 解析详细地名地址（逆地理编码，需已有 GPS） |
| 标记加号     | 在地图上点击拾取 / 更改坐标                |
| 准星         | 定位到地图中心                             |
| 复制         | 复制文件路径                               |

最右下角是 **在文件夹中显示**。

## 全屏查看器与快捷键

点缩略图进入全屏查看器：中间是照片 / 视频，右侧是详细信息栏（默认展开），
底部有上一张 / 计数 / 下一张。

| 按键         | 作用                             |
| ------------ | -------------------------------- |
| Esc          | 返回地图                         |
| ← / →        | 上一张 / 下一张                  |
| + / =        | 放大                             |
| - / _        | 缩小                             |
| 0            | 复位缩放与旋转                   |
| R            | 顺时针旋转 90°                   |
| Shift+R 或 L | 逆时针旋转 90°                   |
| I            | 显示 / 隐藏右侧详细信息          |
| 滚轮 / 双击  | 缩放 / 双击在 2.5 倍与原大间切换 |
| 左键拖拽     | 放大后平移画面                   |

顶部工具栏从左到右：返回地图、序号、放大、缩小、复位、逆时针旋转、顺时针旋转、
详细信息、在文件夹中打开、关闭。点黑色背景区域也可退出。

视频用内嵌播放器播放；遇到 HEVC / H.265 10-bit 等解码不了的格式，会给出
**在系统播放器中打开** 的降级卡片。

右侧信息栏包含：媒体类型与分辨率、拍摄设备与镜头、拍摄参数（时间 / 快门 / 光圈 /
ISO / 焦距）、地理位置（坐标 + 海拔、纠正结果、猜测结果）、**解析详细地址**、
**加为地名标签**、标签与备注编辑、完整 JSON 元数据，以及系统播放器 / 文件夹入口。

## 补坐标：拾取、猜测与固化

- **在地图上拾取**：照片卡片或信息栏点标记加号图标 → 顶部出现提示条「正在拾取位置」，
  右上角有该照片的待定位预览（悬停放大）→ 点地图选点 → 弹窗显示新 / 原经纬度，
  可顺带 **解析地名地址 (可选)**，**确认更新** 保存。提示条上的 **取消** 或 Esc 放弃。
- **大致 GPS 猜测**：没有 EXIF GPS、但拍摄时间夹在两张有坐标照片之间的照片，会自动
  推算中点位置，卡片上以黄色「大致 GPS 猜测」框展示（含推测距离与用时）。
  确认无误就点 **固化此位置** 写成正式坐标；也可 **选择正确地址** 自己拾取。
  顶部菜单 **足迹构建 → 重算未定位照片中点猜测** 可全量重算。
- **批量平移**：抽屉顶部的平移图标，整组（或勾选的一组）平移到新中心，保留相对间距，
  弹窗里会显示原中心、新中心与位移距离，**确认平移** 生效。

## 我的探索（旅途漫游）

点右下角罗盘图标、顶部菜单 **我的探索**，或照片抽屉里的 **我的探索** 按钮进入。
界面变化：底部出现控制面板，顶部 HUD 胶囊显示当前站点的日期与时间。

控制面板两行：

- 第一行：**第 X / Y 站** chips（点它可输入站点编号快速跳转，也有首站 / 25% / 50% / 75% / 末站捷径）、
  当前站点标题与时间段、交通方式 chips（飞机飞行 / 高铁动车 / 公路自驾 / 漫步骑行 /
  游轮轮渡 / 驻留探索，附距离与估算速度）、右上角 **退出探索**。
- 第二行：**粒度** 步进器（五档预设，下拉里可选 **自定义总站数...** 把海量照片聚合成指定站数，
  也能 **恢复预设**）、**跳转站点**、聚焦视距图标（前后 3 / 5 / 8 站或全部显示，
  远距离站点自动淡化）、**本站照片 (N)**、上一站 / 下一站、**自动巡航 / 暂停**。

- 按 **空格** 也可播放 / 暂停巡航。
- 巡航节奏（单站驻留时间、相机飞行跃迁快慢）、是否进入即自动播放、是否自动展开照片抽屉，
  都在 **设置 → 旅行记录 → 偏好与行为设置 → 旅途漫游与时空穿梭** 调。
- 漫游中照片点与探索区域图层暂时隐藏，专注看站点与航段；退出后恢复。

## 照片搜索语法

顶部菜单 **照片搜索** 输入关键词即可模糊搜索文件名、标签、地名、相机与备注；
回车后点 **在右侧抽屉展示全部匹配照片** 可用抽屉浏览。输入框右上角「?」是完整语法指南：

| 语法                                           | 说明                                  |
| ---------------------------------------------- | ------------------------------------- |
| `:has_gps` / `:no_gps`                         | 仅要带真实 GPS / 无定位也无猜测的照片 |
| `:guess_gps`                                   | 处于时空推测中点阶段的照片            |
| `:corrected_gps`                               | 被时空速度分析纠正过漂移的照片        |
| `:gps(经度, 纬度, km)`                         | 指定经纬度半径内的照片                |
| `:city("北京" or "上海")`                      | 拍摄城市，支持布尔组合                |
| `:country("日本")`                             | 拍摄国家 / 地区                       |
| `:tags("风景" and "夜景")`                     | 标签筛选，支持 and / or / not         |
| `:comment("暑假" and not "作业")`              | 备注检索                              |
| `:appendix(key, value)`                        | 自定义扩展元数据精确查询              |
| `:camera("Sony" and "A7M4")`                   | 相机品牌与型号                        |
| `:lens("24-70" or "50mm")`                     | 镜头型号                              |
| `:iso(> 800)` / `:f(<= 2.8)` / `:focal(>= 50)` | ISO / 光圈 / 焦距数值比较             |
| `:year(2024 or 2025)`                          | 拍摄年份                              |
| `:date(2024-06-01..2024-08-31)`                | 拍摄日期区间                          |
| `"text and love"`                              | 双引号划定精确词组，可布尔组合        |
| `:has_gps and not :video`                      | 排除视频，只留照片                    |

## 照片高级筛选规则（Filter）

**设置 → 旅行记录 → 偏好与行为设置 → 照片展示高级筛选规则 (Photo Filters)**。
规则会同时作用于地图打点与照片列表，用来隐藏文档、截图之类不想看的图：

1. 点 **添加筛选条件**，默认新建一条「AI 识别类型 不属于 `["Document","Blackboard"]`」的规则。
2. 每条规则 = 字段 + 运算符 + 目标值。字段可从下拉选（AI 识别类型 / 简述 / OCR 文字、
   相机厂商 / 型号、拍摄时间、标签、备注、路径、文件大小、GPS 经纬度），也可直接输入任意元数据键。
3. 运算符：属于 / 不属于 / 包含 / 不包含 / 等于 / 不等于 / 非空 / 为空 / 大于 / 小于。
   选「为空 / 非空」时目标值输入框禁用。
4. 目标值填 JSON 列表（如 `["Document", "Blackboard"]`）或逗号分隔的文本。
5. 当字段是 AI 识别类型且运算符为「属于 / 不属于」时，下方出现一排分类 chips
   （Document、Blackboard、Screenshot、Portrait、Scenery、Food…），点一下即加入集合。
6. 每条规则左侧开关可临时停用，垃圾桶图标删除；空列表时地图呈现全部照片。

## 相关命令

```bash
yarj.photos --has-gps true            # 查询带 GPS 的照片
yarj.photos --q "东京"                # 关键词查询
yarj.update-photo --path /a.jpg --patch '{"tags":["夜景"]}'  # 改标签
yarj.reverse-geocode --lat 35.68 --lon 139.76 --lang zh-CN    # 逆地理编码
yarj.recompute-guesses                # 重算无定位照片的中点猜测
yarj.batch-update-gps --updates '[{"path":"/a.jpg","lat":35.1,"lon":139.2}]'
```
