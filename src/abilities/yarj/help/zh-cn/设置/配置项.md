# 设置项详解

> 最后更新：2026-10-01

旅行记录在设置页注入四个分区：**图库目录**、**运动航线目录**、**地图图源与配置**、
**偏好与行为设置**。绝大多数选项改动即自动保存（右下角弹出「偏好设置已更新并保存」）。

## 图库目录

照片元数据的数据源。扫描器从这些目录收集照片并解析 EXIF（含 GPS）。

- **目录 {n}**：只读路径框；右侧 **上移 / 下移** 调整顺序（越靠上优先级越高），垃圾桶图标 **移除该目录**。
- 底部输入框：粘贴路径或点右侧文件夹图标选目录，点 **添加**。
- 未配置时显示「未配置」。加完后记得回页面点顶部菜单的 **扫描**，否则地图上不会打点。

## 运动航线目录

GPX / KML 轨迹的来源，界面与图库目录一致（添加 / 上移 / 下移 / 移除），另有两个动作：

- **扫描全部目录**：后台扫描，同名 `.json` 作为伴随元数据（心率区间等）解析，
  没有对应 GPX 的独立 JSON 按室内运动导入；扫描结束自动清理磁盘上已删除的航线记录。
- **导入单个 GPX 文件**：手动选一个 `.gpx` / `.kml` 导入。
- 标题栏 chips 显示「已入库 N 条轨迹」，右上角刷新图标重新读取。

## 地图图源与配置

分四张卡片。

### 当前地图图源

- **当前地图图源**（下拉）：选应用主界面使用的底图，chips 标出家族（GOOGLE / AMAP /
  TENCENT / CARTO / ARCGIS / OSM / TIANDITU / TILES API / MBTILES），GCJ-02 图源额外带黄色标记；
  选中火星坐标系图源时下方弹出警告说明偏移影响。
- **地图注记语言**：跟随 Cockpit 界面语言（自动）/ 简体中文 / 繁体中文 / 英语 / 日语 /
  韩语 / 当地原生语言。语言独立缓存，切换无需重复下载瓦片。

### API 密钥与在线模版

- **Google Maps API Key**：用于 Google 卫星 / 混合 / 街道 / 地形图（每月 100,000 次免费瓦片请求）。
  输入框可点眼睛图标显示 / 隐藏，失焦即保存。
- **天地图 API Key (Token)**：天地图卫星与街道矢量图必需。
- **自定义 XYZ 瓦片 URL 模版**：自建瓦片服务，支持占位符
  `{z}` `{x}` `{y}` `{-y}` `{s}` `{r}` `{apiKey}`。
- **保存配置** 按钮手动保存全部密钥与模版。

### 瓦片本地磁盘缓存

- **启用磁盘缓存**（开关）：浏览过的在线瓦片自动落盘，离线可看、不重复消耗 API 配额。
- 右侧 chips 显示总缓存占用与瓦片数；**清空全部缓存** 一键清掉。
- **缓存上限配额**：500 MB / 1 GB（默认）/ 2 GB / 5 GB / 10 GB / 无限制；
  超限自动按 LRU 淘汰旧瓦片，占用 progress 超过 90% 变黄。
- **图源缓存分区**：按图源列出各自占用，每行右侧垃圾桶图标可单独清空该图源缓存。

### 离线 MBTiles 地图

- **添加 MBTiles 文件**：选择 `.mbtiles` 文件；无效或已添加会提示。
- 列表每行：可用级别（z0–z18 等，读取失败显示红色「读取失败」）、文件路径、
  **默认缩放**（− / + 在文件自身级别范围内调整）、垃圾桶图标移除。
- 添加后在页面顶部菜单 **图源切换** 里选用。

## 偏好与行为设置

分七组，改完即时生效并保存。

### 1. 地图与视图交互偏好

| 选项             | 取值                                                           |
| ---------------- | -------------------------------------------------------------- |
| 默认投影模式     | 记忆上次退出状态（推荐）/ 3D 地球仪 / 2D 平面地图              |
| 启动视角聚焦规则 | 自动全景聚焦全部照片（默认）/ 恢复上次浏览的中心位置与层级     |
| 地名注记语言偏好 | 自动跟随系统语言（默认）/ 简中 / 繁中 / English / 当地原生语言 |
| 双击地图行为     | 平滑放大并居中点击处（默认）/ 无操作（防止误触）               |
| 滚轮缩放灵敏度   | 0.5x–2.0x 滑块                                                 |

### 2. 旅途漫游与时空穿梭

| 选项                           | 说明                                                                 |
| ------------------------------ | -------------------------------------------------------------------- |
| 相机飞行跃迁节奏               | 标准平滑 1.5s（推荐）/ 舒缓电影感 2.5s / 疾速跃迁 0.8s / 瞬间直达 0s |
| 漫游默认聚焦视距               | 前后 3 站 / 5 站（推荐）/ 8 站 / 全部显示                            |
| 自动巡航单站驻留时间           | 1.0–6.0 秒滑块                                                       |
| 开启探索漫游时自动播放巡航     | 开关                                                                 |
| 巡航漫游时自动展开本站照片抽屉 | 开关                                                                 |

### 3. 战争迷雾与足迹渲染

控制「探索区域」（走过的路）这层多边形的观感：半径越大，足迹覆盖越宽。

| 选项                   | 范围 / 取值                                                  |
| ---------------------- | ------------------------------------------------------------ |
| 默认时空聚合粒度       | 精细漫步 / 标准一日游 / 全日自驾远足 / 跨日大区域 / 广域探索 |
| 默认探索足迹半径       | 30–300 m 滑块                                                |
| 探索多边形填充不透明度 | 20%–90% 滑块                                                 |
| 照片标记点图层默认显示 | 开关                                                         |
| 探索区域图层默认显示   | 开关                                                         |

### 4. 界面与性能调优

| 选项                           | 取值                                                       |
| ------------------------------ | ---------------------------------------------------------- |
| 照片侧栏抽屉每次滑动加载数量   | 20 / 30（推荐）/ 50 / 100 张                               |
| 顶部时空穿梭 HUD 风格          | 醒目高光霓虹 HUD（推荐）/ 极简纯净半透                     |
| 照片打点聚合密度               | 密集聚合（35px）/ 标准聚合（50px，推荐）/ 稀疏聚合（70px） |
| 启动时在后台静默增量扫描新照片 | 开关                                                       |

### 5. 航线回放与轨迹平滑

| 选项                                      | 说明                                              |
| ----------------------------------------- | ------------------------------------------------- |
| 启用航线轨迹平滑滤波（去除 GPS 高频抖动） | 过滤轨迹微观锯齿                                  |
| 启用镜头跟随平滑缓冲（云台级防抖阻尼）    | 播放时相机更稳                                    |
| 轨迹平滑窗口强度                          | 3–15 点（高斯核邻近采样），仅在开启平滑滤波时显示 |

### 6. 照片展示高级筛选规则 (Photo Filters)

字段 + 运算符 + 目标值的通用过滤，作用于地图打点与照片列表；详见
[照片、足迹与筛选](../照片/足迹与筛选.md)。

### 7. GPS 坐标生效优先级

一张照片可能同时有多种来源的坐标，系统自上而下取第一个有效的：

| 优先级 | 来源                           | 产生方式                            |
| ------ | ------------------------------ | ----------------------------------- |
| 1      | 运动航线插值 (GPX Track)       | 轨迹贴合，精确落在骑行 / 跑步路径上 |
| 2      | 时空异常纠正 (Drift Corrected) | GPS 漂移纠正结果                    |
| 3      | 智能邻近推算 (Smart Guess)     | 相邻照片中点推测                    |
| 4      | 数据库固化坐标 (Database)      | 你手工拾取 / 保存 / 固化的坐标      |
| 5      | 照片原始定位 (EXIF GPS)        | 拍摄设备写入照片的经纬度            |

每行右侧 **上移 / 下移** 调整顺序（改动即时保存），标题栏 **恢复默认顺序** 一键还原。

分区底部还有 **恢复全部偏好默认值** 按钮（红色），把以上所有偏好重置。

## 相关命令

```bash
yarj.config                                  # 读取当前配置
yarj.save-config --patch '{"exploredRadiusM":120}'  # 改单个偏好
yarj.add-root --path ~/Pictures              # 添加图库目录
yarj.move-root --path ~/Pictures --dir 1     # 调整目录顺序
yarj.set-map-zoom --id <mapId> --zoom 4      # 设置 MBTiles 默认缩放
yarj.set-gps-priority --priority '["track","corrected","guess","db","exif"]'
```
