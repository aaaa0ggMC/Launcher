# 旅行记录

> 最后更新：2026-10-01

旅行记录把你的照片库变成一张「足迹地图」：扫描图库目录、解析 EXIF 里的 GPS 坐标，
在地图上打点，并按时间与距离把去过的地画成一片片探索区域。支持 MBTiles 离线地图与
Google / CartoDB / ArcGIS / 天地图等在线底图，还能把跑步、骑行导出的 GPX / KML
轨迹变成「运动航线」，沿着轨迹回放整段行程。

照片元数据存放在 `~/.config/LinuxCockpit/yarj/metadata.db`，偏好与图库目录等配置在
`~/.config/LinuxCockpit/yarj/config.json`；原图仍在你的硬盘上，不会被复制或修改。

> 一句话上手：**设置 → 旅行记录 → 图库目录** 添加照片文件夹 → 回到本页，点顶部下拉菜单的
> **扫描** → 带 GPS 的照片就会自动打在地图上。

## 能做什么

- 照片足迹地图：EXIF GPS 自动打点，同地点连拍自动聚合成圈，点开就是一整组照片。
- 探索区域：把散落的照片点连成「走过的路」，五档粒度对应散步、一日游、自驾到跨周广域。
- 我的探索（旅途漫游）：按时间把照片编排成站点，自动飞览 + 时空穿梭 HUD，可自动巡航。
- 运动航线：GPX / KML 轨迹目录或单文件导入，航线图层、详情看板、逐公里配速与行程回放。
- 进阶定位：轨迹贴合照片、GPS 漂移时空纠正、无定位照片的中点猜测与一键固化。
- 离线可用：MBTiles 本地图源 + 瓦片磁盘缓存，断网也能回看走过的路。

### 顶部下拉菜单里有什么

点顶部把手展开主菜单，共 11 项：

| 菜单项             | 作用                                                                |
| ------------------ | ------------------------------------------------------------------- |
| **我的探索**       | 进入旅途漫游，把全部照片按时间编排成站点依次飞览                    |
| **照片搜索**       | 按文件名 / 标签 / 地名 / 相机 / 备注搜索，右上角「?」是高级语法指南 |
| **运动航线**       | 打开右侧运动航线抽屉                                                |
| **地名搜索与跳转** | 输入地名（如「东京铁塔」）搜索并飞往该位置                          |
| **图源切换**       | 切换底图；chips 里显示当前图源名，GCJ-02 图源带火星坐标系标记       |
| **扫描**           | 重新扫描所有图库目录并重建元数据，扫描中图标会转圈                  |
| **数据统计**       | 照片总数 / 含 GPS / 无定位 / 已接入目录、最近扫描历史、瓦片缓存占用 |
| **探索区域与粒度** | 探索区域图层开关 + 五档聚合粒度                                     |
| **图层**           | 照片点 / 探索区域 / 运动航线 三个图层开关                           |
| **足迹构建**       | 三个进阶定位工具入口（见下文「常见操作」）                          |
| **清理失效记录**   | 把磁盘上已删除的照片元数据从数据库中注销                            |

## 常见操作

### 首次使用：添加图库目录并扫描

1. 点顶栏右侧的齿轮图标进入 **设置 → 旅行记录 → 图库目录**。
2. 在输入框粘贴照片文件夹路径（如 `/home/user/Pictures`），或点输入框右侧文件夹图标选择目录，点 **添加**。
   可以添加多个目录，用 **上移 / 下移** 调整顺序，垃圾桶图标移除。
3. 回到旅行记录页，点顶部下拉菜单的 **扫描**。扫描在后台任务里跑，进度看侧栏的后台任务面板。
4. 扫描完成后，带 GPS 的照片自动打点；同时会自动给无 GPS 的照片做「中点猜测」（见[照片与足迹](照片/足迹与筛选.md)）。

> 只加了目录但没扫描，地图上不会有任何照片点。

### 看某处拍的照片

1. **拖拽**平移地图，**滚轮**缩放。
2. 照片点会自动聚合：圆圈里的数字是该处的照片张数，**点圆圈**会稍微放大一级，同时在右侧展开这一组的照片（单次最多 100 张）。
3. 放大到单点后 **点圆点**，右侧「位置照片」抽屉列出这个坐标（含完全重叠）的所有照片。
4. 点抽屉里照片的缩略图，进入全屏查看器；点照片卡片上的准星图标（悬停显示「定位到地图中心」）可把地图飞回该照片位置。

### 给照片补坐标、标签与备注

- 在抽屉的照片卡片上点铅笔图标（悬停显示「编辑坐标、标签与备注」），可改经纬度、标签、备注，也能 **在地图上点击拾取坐标**。
- 有 GPS 的照片点「解析详细地名地址」按钮做逆地理编码，地址可一键 **加为地名标签**。
- 一整组照片拍在了错误的位置？抽屉顶部的平移图标（徽标显示已选张数）可以整组平移，保留相对间距。

### 切换底图

顶部菜单 **图源切换** → 点想要的底图即可。天地图需要先在设置里填 API Key；
Google 官方 Tiles API 图源按量计费。国内图源（高德 / 腾讯 / Google 国内节点）是
GCJ-02 火星坐标系，与 WGS-84 有数百米偏移，界面上会有黄色提示 chips。

### 切换地球 / 平面

点右下角按钮阵列的地球 / 地图图标（悬停显示「切换地球/平面」），在 3D 地球仪与
2D 平面地图之间切换；准星图标（「复位视图」）一键回到全部照片的全景视野。

### 一键巡航漫游

点右下角罗盘图标或顶部菜单 **我的探索**，进入旅途漫游：底部弹出控制面板，
顶部 HUD 显示当前站点时间。按 **自动巡航** 自动逐站飞览，空格键也能播放 / 暂停。
详见[照片与足迹](照片/足迹与筛选.md)。

### 播放运动航线

顶部菜单 **运动航线** → 在右侧抽屉点航线卡片上的图表图标打开详情看板 →
**播放行程**，沿轨迹回放整段运动，可调 1x–60x 倍速。详见[运动航线](航线/轨迹航线.md)。

## 隐私与安全

- 照片 GPS、运动航线、旅途站点与地址属于**敏感（sensitive）**隐私区：AI 快照、截图与远程访问会按此范围脱敏，地图与抽屉界面已整体打标。
- 需要时可以向 AI 申请查看该范围的明文（由你本人在授权窗口批准）。
- 逆地理编码、地名搜索会把坐标 / 地名发送给第三方地理编码服务（填了 Google Key 走 Google，
  否则回退 OpenStreetMap Nominatim）；纯本地行为（MBTiles、数据库查询）不产生外网请求。

## 命令行

界面上的每一步都有对应命令，可在 CLI REPL 里执行：

```bash
yarj.scan                                  # 扫描图库目录，构建元数据
yarj.scan-status                           # 照片总数 / 含定位 / 最近扫描记录
yarj.add-root --path /home/user/Pictures   # 添加图库目录
yarj.maps                                  # 列出 MBTiles 地图文件
yarj.set-active-provider --id google-hybrid # 切换底图
yarj.geocode --query "东京铁塔" --lang zh-CN  # 地名 -> 经纬度
yarj.photos --has-gps true                 # 查询带 GPS 的照片
yarj.update-photo --path /a.jpg --lat 35.68 --lon 139.76  # 更新照片坐标
```

## 常见问题

**地图上只有「暂无照片」？** 说明还没有配置图库目录或还没扫描。到
**设置 → 旅行记录 → 图库目录** 添加目录，回页面点顶部菜单的 **扫描**。
若提示「已索引 N 张照片，但均未包含 GPS」，说明这些照片没有地理位置信息，
可以先用「足迹构建」里的工具补坐标。

**底图加载失败 / 地图区域空白？** 地图顶部会出现错误提示。在线图源请检查网络与
API Key（Google 官方图源、天地图必须填 Key）；也可以改用其他图源，或添加
MBTiles 离线地图。

**照片位置和实际差了几百米？** 你当前用的是 GCJ-02 火星坐标系图源（高德 / 腾讯 /
Google 国内节点）。在此类图源下拾取或微调的坐标已内建该偏移，用于和国内路网对齐；
切到 WGS-84 图源（如 ArcGIS / OSM）看就会略有偏差。
