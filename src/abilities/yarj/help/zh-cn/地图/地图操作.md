# 地图操作与图源

> 最后更新：2026-10-01

这一页讲地图本身怎么用：平移缩放、三个图层、投影切换、底图切换与搜索定位，
以及 MBTiles 离线地图和瓦片缓存。

## 基本操作

| 操作            | 效果                                                           |
| --------------- | -------------------------------------------------------------- |
| 左键拖拽        | 平移地图（任何模式下都可用，跟随镜头播放时拖拽即切回手动视角） |
| 滚轮            | 以指针为中心缩放；设置里有 0.5x–2.0x 的灵敏度选项              |
| 双击            | 平滑放大并居中点击处（可在设置里改为「无操作」防误触）         |
| 点聚合圆圈      | 展开该处照片到右侧抽屉（单次最多 100 张），并平滑放大一级      |
| 点单个圆点      | 展开该坐标（含重叠照片）到右侧抽屉                             |
| 悬停圆点 / 圆圈 | 指针变为手型；正在拾取坐标时变为图钉样式                       |

右下角竖排按钮阵列（悬停显示名称）自上而下：

| 按钮        | 作用                                                                                    |
| ----------- | --------------------------------------------------------------------------------------- |
| 罗盘        | 进入 / 退出「我的探索」旅途漫游（行程播放中会禁用）                                     |
| **+** 放大  | 放大一级；行程播放且跟随镜头时调整播放相机缩放                                          |
| **-** 缩小  | 缩小一级                                                                                |
| 地球 / 地图 | 切换 3D 地球仪 ↔ 2D 平面地图                                                            |
| 准星        | 复位视图：本地 MBTiles 时回到该图覆盖范围；否则全景聚焦全部照片，没有照片时回到默认中心 |

投影的初始行为、双击行为都可以在
**设置 → 旅行记录 → 偏好与行为设置** 里改（见[设置项详解](../设置/配置项.md)）。

## 三个图层

顶部菜单 **图层**（或 **探索区域与粒度**）里控制：

| 图层     | 内容                                        |
| -------- | ------------------------------------------- |
| 照片点   | 带 GPS 照片的聚合圆点，颜色跟随主题色       |
| 探索区域 | 由照片点缓冲连成的半透明发光多边形 + 轮廓线 |
| 运动航线 | GPX / KML 轨迹线条、光晕与轨迹点            |

旅途漫游进行时，「探索区域」和「照片点」会暂时隐藏，只显示当前站点与航段，退出后恢复。

## 探索区域与粒度

顶部菜单 **探索区域与粒度**：顶部开关控制探索区域图层显隐；下方五档粒度，
当前档右侧有对勾。每档显示「时差 ≤ Xh · 距离 ≤ Ykm」，粒度越大，越能把整趟行程
聚合成连贯的一片：

| 粒度         | 时差窗口   | 连通距离 | 适合场景           |
| ------------ | ---------- | -------- | ------------------ |
| 精细漫步     | ≤ 2 小时   | ≤ 400 m  | 市区散步、citywalk |
| 标准一日游   | ≤ 8 小时   | ≤ 1.2 km | 一天的出游         |
| 全日自驾远足 | ≤ 24 小时  | ≤ 4 km   | 自驾、全天徒步     |
| 跨日大区域   | ≤ 72 小时  | ≤ 15 km  | 多日旅程           |
| 广域探索     | ≤ 168 小时 | ≤ 40 km  | 长途旅行 / 跨国    |

默认粒度、足迹半径与多边形不透明度在
**设置 → 旅行记录 → 偏好与行为设置 → 战争迷雾与足迹渲染** 调整。

## 图源切换

顶部菜单 **图源切换** 列出全部可用底图，当前项高亮。chips 含义：

- `GOOGLE` / `AMAP` / `TENCENT` / `CARTO` / `ARCGIS` / `OSM` / `TIANDITU` — 底图家族；
- `TILES API` — Google 官方 Map Tiles API（按量计费，需填 Key）；
- `GCJ-02` — 该图源使用国内火星坐标系，带数百米非线性偏移；
- 本地 MBTiles 图源显示为独立条目（chips 为 `MBTILES`）。

内置底图包括 Google 卫星混合 / 纯卫星 / 街道 / 地形、高德街道与卫星、腾讯街道、
CartoDB 暗黑与彩色街区、ArcGIS 全球高清卫星、OpenStreetMap、OpenTopo 等高线地形、
天地图卫星与街道矢量，以及自定义在线瓦片。天地图与 Google 官方图源需要 API Key，
在 **设置 → 旅行记录 → 地图图源与配置 → API 密钥与在线模版** 填写。

> GCJ-02 提示：在此类图源下拾取或微调的照片坐标内建了火星偏移，用于与国内路网对齐；
> 换到 WGS-84 图源（如 ArcGIS / OSM）观察时会看到约数百米偏差，这是坐标系差异，不是 bug。

## 地名搜索与跳转

顶部菜单 **地名搜索与跳转**：输入城市、景点或地名（如「东京铁塔」「故宫」），
按 Enter 或点放大镜搜索；结果列表显示格式化地址、经纬度与服务方 chips，
点一条即平滑飞往该位置。

## 数据统计与瓦片缓存

顶部菜单 **数据统计**：四张卡片显示照片总数、含 GPS 定位、无定位照片、已接入目录数；
下方是最近扫描历史（每次一行：状态 chips + 目录名 + 总数 / 含定位）；
最底部是瓦片本地磁盘缓存占用条（已用 / 配额，超过 90% 变黄）。

浏览过的在线瓦片会自动缓存到本地磁盘，断网后仍能回看；配额与清空入口在
**设置 → 旅行记录 → 地图图源与配置 → 瓦片本地磁盘缓存**。

## MBTiles 离线地图

MBTiles 是打包成单文件的瓦片数据库。把文件加进来就能完全离线当底图用：

1. **设置 → 旅行记录 → 地图图源与配置 → 离线 MBTiles 地图**，点 **添加 MBTiles 文件**，选择 `.mbtiles` 文件。
2. 列表里每行显示可用缩放级别、文件路径、默认缩放；用 **− / +** 调默认缩放，垃圾桶图标移除。
3. 在 **图源切换** 里选用它——条目名为「本地 · 文件名」，chips 显示 `MBTILES`。

本地矢量 MBTiles 首次打开时会在后台自动生成行政区边界 LOD 与市→省归属数据
（进度见后台任务面板），用于在缩小时显示省 / 市级边界与区域名标签。

## 相关命令

```bash
yarj.providers                            # 列出全部图源与当前激活项
yarj.set-active-provider --id arcgis-sat  # 切换底图
yarj.maps                                 # 列出 MBTiles 文件及元数据
yarj.add-map --path ~/maps/Global.mbtiles # 添加离线地图
yarj.cache-stats                          # 瓦片缓存占用
yarj.clear-cache --id google-hybrid       # 清空某个图源的瓦片缓存
```
