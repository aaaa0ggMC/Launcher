# 运动航线

> 最后更新：2026-10-01

把运动手表 / App 导出的 GPX、KML 轨迹（或室内运动 JSON）收进来，画成荧光航线图层，
查看完整的运动数据看板，沿轨迹回放整段行程，还能用轨迹反推出每张照片的拍摄位置。

## 导入轨迹

**设置 → 旅行记录 → 运动航线目录**：

- **航线目录**：添加存放 GPX / KML 的文件夹（可多个，支持上移 / 下移 / 移除）；
  扫描时同名的 `.json` 会作为伴随元数据（心率区间等）一起解析，
  没有对应 GPX 的独立运动 JSON 按室内运动导入。
- **扫描全部目录**：后台扫描所有航线目录，新文件入库、磁盘上已删除的记录自动清理。
- **导入单个 GPX 文件**：一次选一个 `.gpx` / `.kml` 文件立即导入。
- 标题栏 chips 显示「已入库 N 条轨迹」。

导入后航线即出现在地图上（需 **图层** 里打开「运动航线」开关）。

## 运动航线抽屉

顶部菜单 **运动航线** 打开右侧抽屉（宽 420px）：

- **搜索框**：搜航线名称 / 描述 / 运动类型 / 日期；也支持
  `:gps(经度, 纬度, 距离km)` 空间筛选，例如 `:gps(114.4, 30.5, 5km)` 找出穿过该区域的轨迹。
- **类型 chips**：全部 / 骑行 / 跑步 / 健步 / 徒步。
- 有聚焦航线时，右侧出现 **显示全部航线** 取消聚焦。
- 每张航线卡片：图标与名称、距离 / 均速 / 用时 / 日期，次要徽章条显示平均心率、
  卡路里、步数与设备类型（手表 / 手机 / 室内）。卡片右下三个图标（悬停显示名称）：

| 图标   | 作用                                 |
| ------ | ------------------------------------ |
| 灯泡   | 高亮此航线并暗化其余航线（再点取消） |
| 图表   | 查看完整运动数据看板                 |
| 垃圾桶 | 从数据库移除此航线记录               |

点卡片本身会把地图飞到该航线范围。

## 航线详情看板

点图表图标打开「运动详情」弹窗：标题右侧有活动类型 chips（户外骑行 / 户外跑步 /
健步走 / 徒步登山 / 室内运动）、设备 chips，以及 **播放行程**、**地图聚焦**、
**轨迹贴合照片** 三个按钮。下方三个选项卡：

- **总览指标**：总里程大数字、预估消耗千卡；总耗时 / 移动耗时 / 平均时速 / 最高时速 /
  平均心率 / 累计爬升网格；有数据时才出现「运动动力学表现」（平均 / 最佳配速、总步数、
  平均 / 最高步频、平均步幅）、「心率区间分布」五段堆叠条（热身 / 脂肪消耗 / 心肺耐力 /
  无氧耐力 / 极限爆发，各段时长与占比）、「训练负荷与体能恢复」（训练效果 TE、建议恢复时间、
  运动负荷、最大摄氧量）、打卡地点 / 心率传感器 / 海拔剖面卡片，以及随行照片缩略图条。
- **分公里配速 (N)**：每公里一行，条形宽度与该公里均速成正比，附均速与用时。
- **随行实拍照片 (N)**：照片网格，右下角对勾表示该照片带有轨迹坐标；点照片可全屏查看。

## 播放行程

在详情看板点 **播放行程**（「我的探索」进行中需先退出），屏幕底部出现播放控制栏：

- 顶行：航线名、实时速度 / 海拔 / 心率 chips；右侧 **周围时刻照片**（带数量徽标）、
  跟随镜头开关（悬停显示「自动跟随 ↔ 手动自由视角」）、完整路线全貌开关、
  其他航线显隐开关（完全隐藏 → 淡化 → 正常 三态循环）、退出播放。
- 中行：时间轴进度条，左右显示当前时刻与已用时、当前里程 / 总里程与总时长；可拖动跳转。
- 底行：播放 / 暂停、**−5m / −1m / +1m / +5m** 时间微调、**分公里里程** 下拉（直接跳到某公里）、
  右侧 **播放速率** 1x / 5x / 15x / 30x / 60x。
- 按 **空格** 也能播放 / 暂停；播放中拖拽地图会切到手动自由视角。

**周围时刻照片** 抽屉：按时间窗显示当前时刻附近拍的照片，时间窗可选
±1 分钟 / ±3 分钟 / ±5 分钟 / 全部随行；每张照片标注拍摄时间、与当前时刻的差值
（「当前时刻」「+N 秒」）和与轨迹头的距离，点照片全屏查看。

## 轨迹贴合照片（Route Geotagging）

把照片拍摄时间对齐到 GPX 轨迹上，用轨迹点插值出真实位置，给没有 GPS 的照片补坐标。
入口：**足迹构建 → 基于运动轨迹贴合照片**，或详情看板的 **轨迹贴合照片**。

1. **选择目标运动轨迹**（下拉列出各航线的里程与日期）。
2. **相机时钟微调校准**：相机时钟和卫星时间常有几秒到几分钟偏差。系统会自动识别运动记录的
   时区偏移（chips 显示「已自动识别运动记录时区偏移: ±N 小时」），再拖动滑块在 ±120 秒内微调，
   也可点「归零 (0s)」。相机慢于卫星时间就向右拖。
3. **实时对齐预览**：显示成功贴合张数、未匹配张数，并最多列出 5 条预览
   （缩略图、拍摄时间、插值出的经纬度、与原定位的偏差米数或「全新定位补全」）。
4. 满意就点右下角 **启动后台贴合并保存**——任务在后台跑，进度见后台任务面板。
   想重来就点左下角 **重置已贴合记录 (N)** 清掉已贴合的坐标（恢复下一优先级）。

贴合结果优先级最高（见[设置项详解](../设置/配置项.md)的 GPS 优先级），
照片卡片上带对勾标记，搜索语法 `:gps(...)` 也会覆盖这类照片。

## GPS 漂移时空纠正

照片按时间排序后，相邻两张的位移除以用时就是时速。有些照片的 GPS 会突然跳到另一个
国家 / 城市（信号丢失后乱跳），这时用时速合理性把它揪出来，用前后基准点插值修复，
结果写入独立字段，不覆盖原始记录。入口：**足迹构建 → GPS 漂移时空纠正**。

- **分析与纠正原理**卡片显示当前已纠正张数与优先级说明
  （corrected_gps > guess_gps > gps_in_db > exif）。
- **目标图库目录**：多个图库目录时可指定只纠正某一个。
- **最大合理移动时速**：预设陆行 120 / 高铁 350 / 民航常规 800 / 超音速极宽容 1200 km/h，
  也可 60–1500 之间自定；超过即判为离群跳点。
- **最小漂移判定距离**（20–500 km）：只有位移偏差超过它的跳点才纠正，避免误伤同城走动。
- **漂移参考时间窗口**（2–72 小时）：基准点与漂移点之间允许的最大时间跨度。
- **启动后台纠正任务** 跑分析；**取消/重置所有纠正** 一键还原原始坐标。

被纠正的照片在卡片与信息栏里显示「GPS 已纠正」框（偏移距离、速度、原因），
搜索 `:corrected_gps` 可单独筛出。

## 相关命令

```bash
yarj.add-route-root --path ~/Tracks   # 添加航线目录
yarj.import-route-file --path ~/ride.gpx  # 导入单个 GPX
yarj.scan-routes                      # 后台扫描航线目录
yarj.routes --activity cycling        # 查询航线（可按类型/关键词）
yarj.route --id <routeId>             # 单条航线详情
yarj.get-route-photos --routeId <id>  # 某条航线时段内匹配的照片
yarj.preview-geotag --routeId <id> --offset 0  # 预览轨迹贴合效果
yarj.geotag-routes --routeId <id> --offset 0    # 启动后台贴合并保存
yarj.clear-route-geotag               # 清空轨迹贴合坐标
```
