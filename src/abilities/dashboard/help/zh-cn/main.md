# 总览

> 最后更新：2026-10-01

总览把这台机器的关键状态收在一页里：主机信息、CPU、内存、GPU、磁盘、Docker 容器共 7 张卡片，
每 4 秒自动静默刷新一次，卡片位置可以随意拖拽排版并自动记住。
所有数据都来自本机命令（`os`、`df`、`nvidia-smi`、`docker ps`、`pacman`/`flatpak`），不联网、不上传。

> 一句话上手：打开「总览」页即自动加载，点右上角 **刷新** 手动更新；
> 按住卡片标题栏拖动即可换位置，松开手自动保存。

## 能做什么

- 一页看全：主机 / 处理器 / 内存 / GPU / NVIDIA 电源管理 / 磁盘 / 容器 7 张卡片。
- 每 4 秒后台静默轮询，切回页面数据也是新的；某次轮询失败会保留上一次的快照。
- 卡片自由拖拽、缩放，排版自动保存，重开应用不丢失；也可以一键恢复默认排版。
- 监控 CPU 温度与频率、内存 / 交换分区、各挂载点磁盘用量、GPU 利用率与显存。
- 查看 Docker 容器运行状态；直接读取 / 切换 NVIDIA 电源管理参数（需管理员密码，重启生效）。
- 顶栏「复制当前页面为 Markdown」可把当前快照复制成文本，方便贴给他人排查问题。

## 界面速览

| 区域        | 位置         | 说明                                          |
| ----------- | ------------ | --------------------------------------------- |
| 页面标题    | 左上         | 「系统总览」+ 主机名 · 系统 · 已运行时长      |
| 锁定 / 解锁 | 右上角第一个 | 锁形图标按钮，悬停显示 锁定布局 / 解锁布局    |
| 刷新        | 右上角第二个 | 手动立即刷新全部卡片（首次加载走骨架屏）      |
| 卡片网格    | 页面主体     | 7 张卡片，12 列网格，可拖动、可缩放、自动保存 |

7 张卡片从左到右、从上到下默认依次是：

| 卡片            | 展示内容                                                                   |
| --------------- | -------------------------------------------------------------------------- |
| 主机            | 主机名、系统、架构、用户、桌面环境、Shell、运行时长、pacman / flatpak 包数 |
| 处理器          | CPU 型号、使用率圆环、核心数、频率、温度（带颜色）、负载 (1/5/15m)         |
| 内存            | 物理内存进度条与已用 / 总量，交换分区（未启用时显示「未启用交换分区」）    |
| GPU             | 每张显卡：温度、驱动、显存、风扇、功耗、GPU 利用率、显存占用（见下文）     |
| NVIDIA 电源管理 | `NVreg_PreserveVideoMemoryAllocations` 当前值与切换按钮                    |
| 磁盘            | 每个 `/dev/` 挂载点的用量进度条、已用 / 总量、可用空间                     |
| 容器            | Docker 容器运行 / 停止 / 总数统计与逐容器状态列表                          |

## 常见操作

### 拖拽排版与缩放

1. 确认右上角锁形图标处于**解锁**状态（悬停提示「解锁布局 (可拖动调整)」）。
2. 按住卡片标题栏拖动到目标位置——网格是 12 列、每行 48px，松手即落在最近网格点。
3. 拖动卡片边缘 / 角落的手柄可以缩放卡片。
4. 每次移动或缩放后自动保存到 `~/.config/LinuxCockpit/ui-state.json`，无需点「保存」。

> 排版是「浮动」模式：卡片停在你放下的位置，不会被顶回上方空隙。
> 增删卡片暂不支持，卡片集合固定为 7 张。

### 锁定 / 解锁布局

点右上角锁形图标即在两种状态间切换：

- **解锁布局**：可以拖动、缩放卡片（默认）。
- **锁定布局 (可选中复制文字)**：禁止拖动和缩放，方便选中、复制卡片里的文字。

锁定状态会写进全局配置 `config.json` 的 `dashboard.locked`，下次打开仍是锁定态。

### 重置排版

把卡片拖乱后想恢复默认：

1. 打开侧栏「设置」页（或点 app bar 右上角的齿轮图标）。
2. 在左侧分类或顶部搜索框找到「总览 → 总览排版」。
3. 点红色 **重置排版** 按钮。

总览页会立刻恢复默认布局并重新保存。该操作等价于命令 `dashboard.reset-layout`。

### 手动刷新与自动刷新

- **刷新**：立即重新采集全部数据（CPU 使用率需采样约 0.4 秒，按钮会显示加载态）。
- 自动轮询：页面停留期间每 4 秒静默刷新一次，不闪加载条；失败时保留上一次数据。
- 包数量（pacman / flatpak）有 60 秒缓存，不会每次都重新统计。

### 看 GPU 状态

GPU 卡片依赖 `nvidia-smi`。每张显卡显示：型号、温度 chip（超过 80°C 变红）、驱动版本、
显存已用 / 总量（MB）、风扇转速与功耗（该卡不支持的字段自动省略）、
GPU 利用率进度条、显存占用百分比进度条。

- 没有 NVIDIA 显卡或 `nvidia-smi` 不可用时，卡片显示「未检测到 GPU (nvidia-smi 不可用)」。
- 集显 / 独显混合机型同样以 `nvidia-smi` 输出为准。

### 看 Docker 容器

容器卡片顶部三个 chip 分别是 **运行 N**、**停止 N**、**共 N**，下面逐行列出容器名与状态
（绿色播放图标 = 运行，灰色停止图标 = 非运行）。

- 这张卡片是**只读**的，没有启停按钮。
- 想启动 / 停止 / 重启容器，用命令行的 `docker.action`（见「命令行」）。
  该命令会改变系统状态，只有 AI / 远程代理调用时才需要单独授权，本机使用不受影响。
- Docker 未安装或未运行时，卡片显示「Docker 未运行或无容器」。

### 切换 NVIDIA 电源管理

NVIDIA 电源管理卡片显示参数 `NVreg_PreserveVideoMemoryAllocations` 的当前值（0 / 1 / `—`），
右侧按钮显示 **已启用** / **已禁用**。点按钮弹出确认对话框，说明将修改
`/etc/modprobe.d/nvidia-pm-override.conf`（自动备份）、需要管理员密码且重启后生效；
点 **确认** 后系统弹出 polkit 密码框，输入密码完成切换。切换失败时按钮上方提示「切换电源管理失败」。

## 深入阅读

本能力为单页文档，界面即全部内容。可延伸了解：

- 采集在哪失败：所有采集异常（`nvidia-smi`、`docker`、`pacman` 执行失败）都会写进日志，
  打开「日志」能力按 WARN / ERROR 过滤即可定位。
- 依赖降级：`nvidia-smi`、`docker`、`pacman`、`flatpak` 缺失时对应卡片显示占位提示，
  页面本身不会报错中断。

## 命令行

总览的采集与排版都以命令注册，界面只是封装：

```bash
system.stats                          # 采集一次完整系统快照（等价于刷新）
hardware.gpu                          # 只查 GPU 信息 (nvidia-smi)
hardware.pm                           # 读取 NVreg_PreserveVideoMemoryAllocations 当前值
hardware.pm-toggle                    # 切换 0↔1（pkexec，重启生效）
docker.list                           # 列出全部 Docker 容器
docker.action --name <容器名> --action start   # 启动容器，action 也可 stop / restart
dashboard.get-layout                  # 读取已保存的排版
dashboard.set-layout --layout '[...]' # 保存排版（JSON 数组）
dashboard.reset-layout                # 重置为默认排版（所有窗口立即生效）
```

## 常见问题

**卡片拖动没反应？** 先看右上角锁形图标是否为锁定态（橙色），点它解锁后再拖。

**重置排版没反应？** 点 **重置排版** 后，已打开的总览页会立即恢复默认布局并重新保存；
多个窗口共享同一份排版文件，也会一起恢复。如果当时没打开总览页，下次打开即为默认排版。

**GPU 卡片只有「未检测到 GPU」？** 说明 `nvidia-smi` 不在 PATH 或执行失败：
在终端跑 `nvidia-smi` 确认可用后回总览点 **刷新**。

**容器显示不全或状态不更新？** 列表来自 `docker ps -a`，权限不足（当前用户不在 docker 组）时
命令失败，卡片会显示「Docker 未运行或无容器」。

**温度 / 显存 / 风扇字段为空？** 这些依赖系统传感器与显卡支持，读不到时该字段直接省略，
不影响其他数据。
