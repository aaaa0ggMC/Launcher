# 各面板详解

> 最后更新：2026-10-01

这一页把傅里叶变换右侧面板的四个分区——**信息**、**控制**、**矢量**、**示例**——
以及左上角浮动工具栏逐项讲清楚：每个控件的位置、名称和它到底改变什么。
读之前建议先回到 [傅里叶变换](../main.md) 了解基本玩法。

## 心智模型：一根根摆臂接力

- 画面里每一根带箭头的线段就是一根**矢量**（摆臂）：第一根从原点出发，第二根从第一根末端出发，
  依次接力，最后一根的末端就是**笔尖**。
- 每根矢量按自己的周期匀速旋转；笔尖在画布上走过的路就是**轨迹**，也就是还原出来的图形。
- 「图形 = 一组旋转矢量的和」就是离散傅里叶变换（DFT）的可视化：
  轮廓经过 DFT 反算出各次谐波的振幅与频率，分别变成一根矢量的长度与周期。

## 浮动工具栏（画布左上角）

| 按钮        | 名称（悬停） | 作用与细节                                                           |
| ----------- | ------------ | -------------------------------------------------------------------- |
| 播放 / 暂停 | 暂停 / 播放  | 切换模拟运行。运行中显示暂停图标（绿色），暂停后时间停在当前值       |
| 橡皮擦      | 重绘         | 模拟时间归零、清空轨迹，用当前矢量从头画一遍（不改变任何参数）       |
| 准星        | 重置视图     | 恢复默认取景：目标回原点、缩放回默认、3D 方位角回 45° / 仰角回约 31° |
| 靶心        | 跟随笔尖     | 镜头锁定笔尖；开启时画面平移暂时失效（按钮变主题色）                 |
| 方块/立方体 | 3D 视图      | 2D / 3D 切换；3D 下可用右键拖动旋转视角                              |
| 旋转        | 触屏旋转     | 仅 3D 出现：打开后单指拖动旋转视角，不用右键也能绕着看                |

## 信息 分区

只读区，实时显示当前模拟状态（每 250ms 刷新一次）：

| 字段     | 含义                                              |
| -------- | ------------------------------------------------- |
| 状态     | 运行中 / 已暂停                                   |
| FPS      | 当前帧率 / 本次打开以来的最高帧率                 |
| 模拟时间 | 从 0 开始累计的秒数，受「运行速度」缩放           |
| 矢量数   | 当前矢量根数                                      |
| 点数     | 轨迹已画点数 / 轨迹点数上限                       |
| 笔尖     | 笔尖坐标；3D 视图显示 (x, y, z)，2D 只显示 (x, y) |
| 视图     | 2D 或 3D                                          |
| 缩放     | 相对默认取景的倍数，×1.00 为默认                  |

## 控制 分区

### 播放排

顶部三枚按钮：全宽的 **暂停 / 播放**，以及 **重绘**、**重置视图**（与浮动工具栏同名按钮等效）。

### 三个开关

| 开关     | 作用                                                        |
| -------- | ----------------------------------------------------------- |
| 跟随笔尖 | 镜头跟随笔尖移动，适合笔尖跑出画面时跟踪                    |
| 霓虹轨迹 | 轨迹加发光效果（纯视觉，不影响数据）                        |
| 3D 视图  | 切换 2D / 3D；3D 下才能右键旋转，且「覆盖」区域从圆变成曲面 |

### 五个显示勾选框

| 勾选   | 画布上是什么                                   |
| ------ | ---------------------------------------------- |
| 矢量   | 每根摆臂本体（箭头线段）                       |
| 覆盖   | 每根矢量末端各自扫过的区域（2D 是圆，3D 是面） |
| 坐标轴 | X / Y / Z 轴线                                 |
| 轨迹   | 笔尖走过的路径，也就是当前图形                 |
| 末向量 | 从原点直连笔尖的那根线                         |

### 两个滑块

| 滑块         | 范围 / 步进       | 改变什么                                                     |
| ------------ | ----------------- | ------------------------------------------------------------ |
| 运行速度     | 0.05 – 4（0.05）  | 模拟时间的流速。0.05 慢放看细节，4 快进；暂停后拖动不生效    |
| 轨迹点数上限 | 200 – 8000（200） | 轨迹最多保留多少个点，超出丢最旧的。调小省内存，调大尾巴更长 |

## 矢量 分区

可编辑的矢量表，一行一根矢量；列名（悬停表格上方的提示条有完整解释）：

| 列    | 含义                                                                     |
| ----- | ------------------------------------------------------------------------ |
| \|v\| | 摆臂长度；越长，这个谐波在最终图形里占的成分越大                         |
| T_θ   | 绕 X 轴的周期（秒 / 圈）。0 = 这根不上下摆，只在平面里转                 |
| T_φ   | 绕 Z 轴的周期（秒 / 圈）。经典本轮图就是这一列；0 = 静止（当作固定偏移） |
| θ₀    | 初始极角（度）。90 = 从 XY 平面出发，0 / 180 = 从正 / 负 Z 轴出发        |
| φ₀    | 初始方位角（度）。决定第一帧朝哪边起步                                   |

按钮与状态：

- **更新**：把表格内容应用为新的矢量组——时间归零、轨迹清空、重新取景。
- **加载文件**：选择 JSON 文件读入（格式见主页面）。
- 表格上方红字 = 本次操作的错误（加载失败 / 导出失败的具体原因）。
- **添加矢量**：追加一行，默认 长度 50、θ₀ 90、φ₀ 0、T_θ 0、T_φ 1。
- 行尾 × 图标（悬停「删除该矢量」）：删掉这一行。
- 表格为空时显示「暂无矢量，点击添加或加载文件」。
- **导出矢量**：把表格里的矢量 + 当前速度 + 点数上限写成 JSON 保存。

> T_θ = 0 时就是教科书上的经典 2D 矢量叠加图（epicycle）；给某根矢量一个非 0 的 T_θ，
> 它绕 X 轴也转，整条链就会拧出立体形状——「环面」和「随机」3D 就是这么来的。

## 示例 分区

两列预设按钮，点按加载；当前预设高亮。每个预设对应的矢量构成：

| 预设     | 矢量构成                                                              |
| -------- | --------------------------------------------------------------------- |
| 圆形     | 1 根静态零矢量 + 1 根长度 120、T_φ = 1s/圈                            |
| 3D 圆    | 1 根静态零矢量 + 1 根只有 T_θ = 1s/圈的矢量，圆转在 YZ 平面           |
| 环面     | 1 根长 100、T_φ = 1 秒/圈 + 1 根沿 Z 轴、T_θ = 0.25 秒/圈（极向快摆） |
| 利马曲线 | 2 根同向矢量，T_φ 分别为 1 秒/圈 与 2 秒/圈                           |
| 心形线   | 对心形线参数方程采样后做 DFT，取 24 次谐波                            |
| 方形     | 对正方形边采样后做 DFT，取 50 次谐波（角点需要很多项，故有振铃）      |
| 五角星   | 对五角星折线采样后做 DFT，取 45 次谐波                                |
| 爱心     | 对爱心参数方程采样后做 DFT，取 30 次谐波（平滑曲线，丢弃小系数）      |
| 随机     | 每次加载随机生成 10–15 根矢量；3D 模式方向均匀分布在球面上            |
