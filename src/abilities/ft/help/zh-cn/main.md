# 傅里叶变换

> 最后更新：2026-10-01

傅里叶变换是一个教学可视化页面：把一组旋转矢量（epicycle）串成一串，
它们的矢量链末端在空中画出的轨迹，就是用离散傅里叶变换（DFT）还原出来的图形。
你可以切换 2D / 3D 视图、逐项调参、加载预设或自己画一组矢量，直观看到「时域图形 ↔ 频域谐波」的对应关系。

> 一句话上手：打开页面默认加载「圆形」预设并自动播放；
> 在右侧 **示例** 面板点「爱心」或「方形」，看一串矢量如何转出一个复杂图形。

## 能做什么

- 经典本轮图演示：每个矢量按自己的周期旋转，末端画出轨迹（默认「圆形」预设，打开即播）。
- 2D / 3D 双视图：3D 下矢量可以在球面上任意方向旋转，扫出真正的立体图形。
- 9 个内置预设：圆形、3D 圆、环面、利马曲线、心形线、方形、五角星、爱心、随机。
- 手动编辑矢量：改长度、两个旋转周期（T_θ / T_φ）和初始角度（θ₀ / φ₀），即时更新。
- 显示开关：坐标轴、矢量、轨迹、末向量、覆盖区域、霓虹轨迹、跟随笔尖。
- 载入 / 导出矢量 JSON 文件，把自己的图形分享给别人或复现。
- canvas 配色跟随当前主题，切换主题不用重开页面。

## 常见操作

### 基本玩法：调一个旋钮，看波形变化

1. 在 **示例** 面板点一个预设（例如「方形」），图形立即重绘并从零开始播放。
2. 在 **控制** 面板把 **运行速度** 拖慢（0.05–4），观察谐波转动的细节；
   拖快则几秒看完一个周期。
3. 勾掉 **轨迹** 只留矢量，或勾上 **覆盖** 看每根矢量扫过的区域。
4. 点 **重绘** 从零开始，点 **暂停** 停帧观察某一瞬间的矢量角度。
5. 玩乱了就点浮动工具栏的 **重置视图**。

### 2D / 3D 与镜头操作

- **3D 视图**：打开后切换为透视相机，初始方位角 45°、仰角约 31°；矢量带极向周期时
  会转出立体图形（试试「环面」预设）。
- **滚轮**：放大 / 缩小（2D 拉远 / 推近视距，3D 推拉轨道半径；缩放有上下限）。
- **左键拖动**：平移画面（2D / 3D 都可以；开启「跟随笔尖」后平移暂时失效）。
- **右键拖动**：旋转视角（仅 3D；画布上已屏蔽右键菜单）。
- **重置视图**：回到默认取景；「跟随笔尖」打开时镜头跟着笔尖走。

### 用预设

**示例** 面板是两列排布的按钮，点一下即加载；当前生效的预设按钮高亮（主题色），
悬停每个按钮可看到它的说明：

| 预设     | 说明（悬停显示）      | 看什么                                        |
| -------- | --------------------- | --------------------------------------------- |
| 圆形     | 单矢量 · 经典圆周     | 一根矢量转出圆——最简单的默认例子              |
| 3D 圆    | 垂直圆 · 仅极向旋转   | 竖在 YZ 平面上的圆，只在极向转                |
| 环面     | 双周期 · 环面覆盖区域 | 两个周期叠加，末端扫出环面（开「覆盖」+ 3D）  |
| 利马曲线 | 两矢量 · 利马曲线     | 两个不同频率的圆叠加出的心形线近亲            |
| 心形线   | 心形线 · DFT          | 用少量谐波凑出心形线                          |
| 方形     | 方形 · 角点吉布斯振铃 | 转折处 Gibbs 振铃——为什么级数要那么多项       |
| 五角星   | 五角星 · DFT          | 同样是 DFT 还原的折线图形                     |
| 爱心     | 爱心 · 极小矢量数     | 平滑曲线，少量几根矢量就能转出来              |
| 随机     | 随机矢量 · 手写涂鸦   | 每次加载都不同；3D 模式生成真正的 3D 随机矢量 |

首次打开页面默认加载「圆形」。

### 自己改矢量

**矢量** 面板是一张可编辑表格，一行一根矢量，列依次是：

| 列    | 含义                                                           |
| ----- | -------------------------------------------------------------- |
| \|v\| | 矢量长度（摆臂半径）                                           |
| T_θ   | 绕 X 轴的旋转周期（秒 / 圈，极向）；0 = 不转，把圆转出纸面     |
| T_φ   | 绕 Z 轴的旋转周期（秒 / 圈，经典本轮图）；0 = 不转，即静态偏移 |
| θ₀    | 矢量初始位置极角（度，90 = 在 XY 平面）                        |
| φ₀    | 矢量初始位置方位角（度）                                       |

步骤：改数字 → 点 **更新**（清空时间与轨迹，按新矢量重绘）。
点 **添加矢量** 追加一行（默认值 长度 50、θ₀ 90、φ₀ 0、T_θ 0、T_φ 1），
点行尾的 × 图标删除该行。错误（如填了非数字）会在表格上方以红字显示；
表格为空时显示「暂无矢量，点击添加或加载文件」。

### 载入与导出 JSON

- **加载文件**：弹系统文件选择器（只筛 `.json`）→ 读取后立即应用。
  本能力自带 8 个示例文件（源码树位于 `src/abilities/ft/examples/`：
  `circle`、`line`、`limacon`、`cardioid`、`triangle`、`square`、`star`、`heart`），
  可以用它打开试玩；界面不会自动列出它们，需在文件选择器里手动找到。
- **导出矢量**：弹保存对话框（默认文件名 `vectors.json`）→ 写出当前表格里的矢量、
  当前运行速度与轨迹点数上限。
- 文件格式：`{"vectors": [{"x":0,"y":120,"secperRound":1}, ...], "runSpeed":1, "verticesLimit":4096}`；
  也接受裸数组。旧式 `orot` / `orotX` 相位字段仍可读入（自动折算进初始方向）。

## 深入阅读

- [各面板详解](面板/各面板详解.md)：信息 / 控制 / 矢量 / 示例四个分区逐项说明，
  以及每个滑块、开关、列名到底改变什么。
- 概念回顾：矢量链首尾相接，最后一根的末端就是「笔尖」，笔尖走过的路就是轨迹；
  预置图形（方形 / 五角星 / 爱心等）都是用 DFT 从图形轮廓反算出的一组矢量。

## 命令行

页面的预设与文件读写都是命令，界面只是封装：

```bash
ft.presets                                       # 列出全部预设与说明
ft.load --name heart                             # 加载预设（--mode 3d 生成 3D 随机矢量）
ft.load-file --path /abs/vectors.json            # 从 JSON 文件加载矢量
ft.export --path /abs/vectors.json --data '{"vectors":[]}'   # 导出矢量到 JSON
```

## 常见问题

**画布是白的 / 不动？** 切到别的能力页时动画会暂停（时间不前进），回到本页自动继续；
若长时间不动，点一下 **播放** 或 **重绘**。

**轨迹突然变短？** 轨迹点数有上限（默认 4096，可在「控制 → 轨迹点数上限」调到
200–8000），超出后旧的点会被丢掉，这是为了不占太多内存。

**3D 下按右键拖动没反应？** 右键旋转只在 **3D 视图** 打开时生效，先打开 3D。

**跟随笔尖打开了却拖不动画面？** 「跟随笔尖」会把镜头锁在笔尖上并停用平移，
关掉它或先「重置视图」。

**能加自己的预设按钮吗？** 界面上的预设来自命令 `ft.presets`，
新增预设需要进 presets.ts 注册（属代码改动，不在界面能力范围内）。
