# 启动项

> 最后更新：2026-10-01

「启动项」管理 `~/.config/autostart` 目录里的自启动条目（KDE / XDG 标准的 `.desktop` 文件）：
开机时要自动起来的程序一般都把自家 `.desktop` 放在这里。这个页面把它们全部列出来，
一个开关就能启用 / 禁用——禁用不是删文件，只是在文件里写下 `Hidden=true`，随时可以开回来。

> 一句话上手：找到那张卡片，把右边的开关拨到 **已禁用** / **已启用**。

## 能做什么

- 列出 `~/.config/autostart` 下所有 `.desktop` 自启动条目（名称、执行命令、文件名）。
- 一张卡片一个开关，点击即写盘，下次开机按新状态执行。
- 已禁用的卡片半透明显示、状态 chip 变灰，一眼看出谁被关掉了。
- 条目按名称排序，导出 Markdown（侧栏底部「复制当前页面为 Markdown」）带走。

## 界面速览

| 区域     | 位置       | 说明                                                             |
| -------- | ---------- | ---------------------------------------------------------------- |
| 标题行   | 页面最上方 | 「启动项」标题 + 副标题「管理 ~/.config/autostart 中的自启动项」 |
| 加载条   | 标题下方   | 读取时显示进度；失败时显示错误                                   |
| 条目卡片 | 页面主体   | 网格排布：图标、名称 + 状态 chip、执行命令、文件名、开关         |

每张卡片从左到右：状态图标（已启用 = 绿色火箭，已禁用 = 灰色月亮）、**名称**（粗体）加一枚
状态 chip（绿色 **已启用** / 灰色 **已禁用**）、下方两行小字是 **Exec 执行命令**和 **.desktop
文件名**，最右侧是这次的开关。开关在做写盘操作时会转圈。

## 常见操作

### 启用 / 禁用一个启动项

点卡片右侧的开关即可：

- 拨到「已启用」：把该条目的开关打开，下次开机照常自启。
- 拨到「已禁用」：写入 `Hidden=true`，桌面环境开机时跳过它；文件本身还在，随时能开回来。

修改立即写回 `.desktop` 文件，不需要额外保存按钮。

### 新增一个启动项

页面只负责开关，不提供新建。要新增自启动项，把它的 `.desktop` 文件放进
`~/.config/autostart/` 即可，例如：

- 很多应用自带「开机自动启动」选项，勾选后它自己会往这里放文件；
- 或者从 `/usr/share/applications/` 里把对应的 `.desktop` 复制一份过来。

一个最小可用的自启动条目长这样：

```ini
[Desktop Entry]
Name=我的脚本
Exec=/home/you/scripts/hello.sh
Type=Application
```

文件放好后刷新页面（切换到别的能力再回来即可），新条目就会出现在列表里。

### 删除或修改一个启动项

同样要动文件：

- **删除**：把 `~/.config/autostart/` 里对应的 `.desktop` 文件移走或删掉。
- **改命令**：编辑该文件的 `Exec=` 行；改 `Name=` 行改显示名称。
- 不想动文件也可以用页面的开关禁用了事——效果一样，还留得下恢复的余地。

## 命令行

```bash
autostart.list                                        # 列出开机自启动项
autostart.toggle --file "Clash Verge.desktop" --hidden true   # 禁用该条目
autostart.toggle --file "Clash Verge.desktop" --hidden false  # 重新启用
```

`--file` 用卡片上显示的文件名（`.desktop` 结尾）。

## 常见问题

**页面是空的？** `~/.config/autostart` 里没有 `.desktop` 文件时显示「没有自启动项」
（提示：该目录中没有 .desktop 文件）。装个带开机启动选项的软件，或自己放一个文件进去就有了。

**为什么比我装的软件少？** 这里只列**用户级**自启动目录 `~/.config/autostart`；
系统级 `/etc/xdg/autostart` 不归这个页面管。

**禁用和删除有什么区别？** 禁用只是在 `.desktop` 里写 `Hidden=true`，文件还在、开关还在，
一键恢复；删除是连文件一起没，恢复要重新放回文件。

**开关拨过去没变化？** 写盘失败时列表不会更新，错误会记到日志里。常见原因是该文件被别的程序
占用或权限有问题——可以先用编辑器改 `Hidden=` 行，再刷新页面。

**切到别的能力再回来会怎样？** 这个页面不缓存，每次进来都重新读一次目录，正好能看到别处刚放进去的新条目。
