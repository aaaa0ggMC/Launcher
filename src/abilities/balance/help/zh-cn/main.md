# 余额中心

> 最后更新：2026-10-01

余额中心把你在各家 AI 平台上的账户余额、每月账单与订阅配额集中到一页，定时自动刷新，
异常也会在卡片上标出来。所有密钥都只保存在本机（机器绑定加密），不会上传到任何第三方。

> 一句话上手：点右上角 **添加平台** → 选平台类型 → 填入 API Key → **保存**，
> 卡片就会自动查询并显示余额。

## 能做什么

- 一眼看到各平台余额：人民币 / 美元 / Credits 分开汇总。
- 监控用量与配额：OpenAI 当月账单、Codex 5 小时与本周配额、订阅到期时间。
- 免 Key 平台（OpenAI / 小米 MiMo / 智谱 / Google AI Studio 等）走网页登录，凭 Profile 容器共享会话。
- 定时自动轮询，异常平台一键定位；每条平台卡片可单独刷新。

## 界面速览

| 区域       | 位置       | 说明                                                     |
| ---------- | ---------- | -------------------------------------------------------- |
| 工具栏     | 页面顶部   | 全部刷新、添加平台、Profile 账户管理、导入旧配置         |
| 汇总卡片   | 工具栏下方 | 人民币总额、美元总额、Credits、平台健康状态              |
| 搜索与筛选 | 汇总下方   | 按名称 / 币种 / Profile 搜索，按 全部 / 正常 / 异常 过滤 |
| 平台卡片   | 页面主体   | 每个平台一张卡，含余额、状态、延迟与快捷操作             |

平台卡片底部一排图标从左到右依次是：打开控制台、查看原始数据、编辑、删除、刷新。
鼠标悬停可以看到每个按钮的名称。

## 常见操作

### 添加或编辑平台

点 **添加平台**（或卡片上的编辑图标）。在弹窗里选择 **平台类型**，名称与图标会自动填好，
然后填入 **API 密钥** 并点 **测试连通性** 确认能查通，最后 **保存**。

- 同类平台可以配置多个（例如两个 DeepSeek 账号），用 **显示名称** 区分。
- **接口地址 / Base URL** 只在自建或中转服务时才需要填。
- 编辑弹窗属于隐私禁区，AI 无法读取或代填其中的密钥。

### 刷新余额

- **全部刷新**：刷新当前所有已启用平台。
- 卡片右下角的刷新图标：只刷新这一张卡片。
- 开启自动轮询后，停留在页面时也会按间隔自动刷新（见「设置 → 余额设置」）。

### 打开控制台与查看原始数据

- **打开控制台** 会打开对应平台的官方账单页，方便充值或查看明细。
- **查看原始数据** 展开该平台的原始 JSON 响应，用于排查异常或核对字段。

### 登录授权（免 Key 平台）

部分平台（OpenAI、小米 MiMo、智谱 BigModel、Google AI Studio、阶跃星辰）用网页登录即可，
不必提供 API Key。卡片报错时会出现 **登录授权** 按钮，点击后在弹出的窗口里完成登录，
回到卡片点刷新即可。详见 [平台类型 → 网页登录](平台类型/网页登录.md)。

### 导入旧配置

如果你之前用旧版本或其他工具存过平台配置，点 **导入旧配置** 尝试自动迁移。

## 隐私与安全

- 余额、赠送券、已用 / 总额度、原始响应都标记为 **个人** 隐私区，AI 快照与截图会脱敏。
- 平台登录账号（邮箱等）标记为 **敏感**，默认脱敏，需要时可申请查看。
- API Key 属于 **凭据**，以本机机器 ID 派生的 AES-256-GCM 加密后落盘，只写不回显。

## 命令行

余额中心的每一步都能在 CLI 里执行，界面只是这些命令的封装：

```bash
balance.list                       # 列出所有平台及其最近一次结果
balance.check --id <平台id>        # 查询单个平台余额
balance.config.get --reveal false  # 读取配置（--reveal true 才含明文密钥）
balance.config.upsert --platform '{"id":"deepseek","type":"deepseek","apiKey":"sk-..."}'
balance.config.remove --id <平台id>
balance.refresh                    # 全部刷新
```

## 常见问题

**刷新一直失败？** 先在编辑弹窗里点 **测试连通性**，它会显示具体错误；
若是网页登录类平台，先完成登录授权，再确认该平台未被禁用。

**余额数字对不上？** 平台接口口径可能包含或排除赠送券。展开 **查看原始数据**
可以看到接口返回的原始字段。

**换机器后额度读不出来？** 密钥与本机机器 ID 绑定，迁移到新机器需要重新填写密钥。
