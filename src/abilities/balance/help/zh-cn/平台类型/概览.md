# 平台类型与凭据方式

> 最后更新：2026-10-01

余额中心按「凭据方式」把平台分成三类。选对类型，才能正确查询余额。

| 类型               | 代表平台                                                            | 需要什么                   | 查询方式                      |
| ------------------ | ------------------------------------------------------------------- | -------------------------- | ----------------------------- |
| API Key            | DeepSeek、OpenRouter、PPIO、Tavily、OpenAI(API)                     | 平台签发的密钥             | 官方余额 / 账单接口           |
| 网页登录（免 Key） | OpenAI 网页端、小米 MiMo、智谱 BigModel、Google AI Studio、阶跃星辰 | 浏览器会话（Profile 容器） | 复用登录态访问网页接口        |
| 订阅配额           | Codex (ChatGPT)、Claude Code                                        | 订阅凭据 / 令牌            | 配额接口，显示 5 小时与周窗口 |

## 通用字段

- **显示名称**：卡片标题，便于区分同类多个账号，例如「DeepSeek 主力」。
- **卡片图标**：支持 `gi:<名称>`（内建单色图标）、`default/<名称>/padding`（图标库）、
  `emoji/<表情>` 或 `file/<本地路径>`；留空时按平台类型给默认值。
- **接口地址 / Base URL**：仅自建或中转服务需要；官方直连留空即可。
- **启用此平台**：关闭后不参与自动刷新，但仍保留配置。

## API Key 类平台

把平台控制台里的密钥粘贴进 **API 密钥** 即可，例如 DeepSeek 的 `sk-...`。
密钥以本机机器 ID 派生的 AES-256-GCM 加密保存，编辑时只写不回显。

## 订阅配额类平台

### Codex (ChatGPT)

支持两种填法：

1. **导入本机凭据**：点 **导入 ~/.codex/auth.json**，自动读取本机已登录的 Codex。
2. **手动 / 粘贴 JSON**：把 `auth.json` 内容整体粘到 Access Token 输入框，
   界面会自动解包出 `access_token`、`account_id`、`refresh_token`。

卡片会显示 **5 小时配额**、**周配额**、点数余额、快速重置次数与订阅到期时间。
填入 Refresh Token 后，令牌过期可自动续期。

### Claude Code

与 Codex 类似，按订阅配额展示剩余额度与重置时间。
