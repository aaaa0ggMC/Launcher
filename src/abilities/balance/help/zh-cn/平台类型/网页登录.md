# 网页登录与 Profile

> 最后更新：2026-10-01

免 Key 平台不查 API 密钥，而是复用浏览器登录态。余额中心用 **Profile** 容器来
隔离和保存这些登录数据。

## 什么是 Profile

Profile 是一个隔离的浏览器数据容器（Cookie / localStorage / 会话）。同一个
Profile 里的登录态由其中的各平台共享，不同 Profile 之间互不干扰。

- 一个 Profile 可以登录多家平台（OpenAI、Google、小米、智谱……）。
- 想区分「个人账号」与「工作账号」时，各建一个 Profile。
- 在 **Profile 账户管理** 页面可以新建、编辑、检测登录状态。

## 授权流程

1. 在平台卡片上点 **登录授权**（卡片正常时也可从卡片操作进入）。
2. 弹出的登录窗口会加载该平台官方登录页。
3. 完成登录后关闭窗口，回到卡片点 **刷新**，状态应变为「正常」。
4. 若卡片仍报错，到 **Profile 账户管理** 里点 **检测状态** 确认该 Profile 已登录。

> 登录窗口里的账号密码属于凭据，AI 无法读取，也不会出现在截图或 AI 快照里。

## 多账号建议

- 每个账号建一个独立 Profile，并在添加平台时选择对应 **使用 Profile 容器**。
- 同一 Profile 可被多张卡片共用，减少重复登录。
- 删除 Profile 会解绑相关卡片并清除其登录数据，请谨慎操作。

## 相关命令

```bash
balance.profiles.list
balance.profiles.upsert --name "个人主账号"
balance.profiles.check --id <profileId>
balance.profiles.login --id <profileId> --provider google
```
