# 歌词页

> 最后更新：2026-10-01

「歌词」是 AI DJ 的第二个侧栏页面：全页显示当前播放歌曲的歌词，支持**卡拉 OK 逐字高亮**和
**滚动跟随**两种呈现方式。它跟随 AI DJ 的播放后端工作——外部播放器 (MPRIS) 模式和内置播放器模式下都能用。

页面颜色一律跟随应用主题，不可单独配置；能配置的只有呈现方式与排版
（**设置 → AIDJ Lyrics → 歌词页配置**）。

> 一句话上手：在 AI DJ 里开始播放后打开 **歌词** 页，当前行会自动高亮并滚到屏幕居中；
> 想要逐字唱 K 效果，确认 **设置 → AIDJ Lyrics → 歌词页配置 → 卡拉OK 逐字高亮** 是打开状态。

## 界面速览

| 区域     | 位置                     | 说明                                                                                        |
| -------- | ------------------------ | ------------------------------------------------------------------------------------------- |
| 头部     | 页面顶部（可在设置里关） | 封面、曲名、状态芯片、歌词来源芯片、歌手 · 专辑、播放器名、播放器下拉、播放控制按钮、进度条 |
| 歌词主体 | 页面中部                 | 滚动跟随模式显示全部歌词并把当前行居中；固定窗口模式只显示当前行上下若干行                  |
| MV 画面  | 全页覆盖                 | 播放 `.mp4` / `.mkv` / `.webm` 且未开启仅音频模式时，无声视频铺满页面，歌词变成底部字幕     |
| 沉浸背景 | 全页铺底                 | 开启沉浸模式且有封面时，用模糊暗化的封面作背景（停止播放时自动进入）                        |

头部一排图标按钮从左到右：**播放器** 下拉（仅外部播放器模式）→ 上一首 → 播放 / 暂停（主按钮）
→ 下一首 → 停止 → **桌面歌词**（开关，打开时高亮）。进度条右侧显示 `当前时间 / 总时长`。

曲名旁边的来源芯片显示当前歌词类型：**YRC**（网易云逐字歌词，可做真·逐字高亮）或 **LRC**
（普通歌词，高亮按行推进）。

## 常见操作

### 切换播放器（外部播放器模式）

头部 **播放器** 下拉默认是 **当前激活**（自动跟随当前活跃播放器），也可以指定某一路 MPRIS 播放器。
内置播放器模式下没有这个下拉——歌词直接跟着内置播放器走。

### 打开桌面歌词浮窗

点击头部的 **桌面歌词** 图标按钮（或 AI DJ 页面菜单 → **桌面歌词**），会为当前绑定的播放器打开一个
无边框、透明、置顶的桌面歌词窗，再点一次关闭。窗口可以直接拖动挪位置，**右键 → 锁定** 后鼠标穿透。
它的字体、字号、颜色、窗口位置在 **设置 → AI DJ → 桌面歌词显示** 里配，和本页面共用同一批歌词数据但配置互相独立。

### 调歌词时序

歌词整体偏快或偏慢时，改 **设置 → AIDJ Lyrics → 歌词页配置 → 排版 → 位置偏移 (ms)**：
正值让歌词**提前**显示，负值延后（范围 −1000 到 1000）。播放位置本身每 600ms 从后端拉一次，
页面内部会做平滑插值，所以进度条和高亮不会一跳一跳。

### 看 MV

播放 mp4 / mkv / webm 文件时，如果 **设置 → AI DJ → 播放偏好 → 仅音频模式 (Audio Only)** 是关着的，
页面会自动切到 MV 模式：静音视频与音频同步播放（声音仍由播放器出），歌词变成底部两行字幕
（当前行 + 下一行）。播放中鼠标移到画面上部会唤出控制条，3 秒不动或鼠标移出画面即自动隐藏；停止播放后回到普通歌词视图，
若这首歌没有歌词，会显示一张带播放按钮的封面预览卡。只想听歌就在设置里打开 **仅音频模式**。

## 设置项

都在 **设置 → AIDJ Lyrics → 歌词页配置**（改完自动保存，右上角 **恢复默认** 可一键还原）：

| 设置                                                                                                                                                        | 作用                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **歌词滚动跟随**                                                                                                                                            | 开：显示全部歌词，当前行自动滚到垂直居中；关：固定窗口，只显示当前行上下若干行         |
| **卡拉OK 逐字高亮**                                                                                                                                         | 当前行按 LRC 内联时间戳逐字填充（有 YRC 歌词时是真正的逐字，否则按到下一行的时间推进） |
| **淡化非当前行**                                                                                                                                            | 非当前行变淡                                                                           |
| **显示头部**                                                                                                                                                | 显示歌曲信息 / 播放控制 / 进度条                                                       |
| **沉浸模式**                                                                                                                                                | 有封面时用模糊暗化的封面叠加背景，替代你设置的窗口背景                                 |
| **当前行上方行数 / 下方行数**                                                                                                                               | 固定窗口模式下当前行上下各显示几行（0–8）                                              |
| 排版：字体、当前行字号 (18–46)、候选行字号 (13–28)、当前行字重 (500–900)、候选行字重 (400–700)、行高 (1.0–2.0)、行间距 (4–24)、字间距 (−2–8)、位置偏移 (ms) | 只影响排版，颜色永远跟随主题                                                           |

歌词页配置单独存放在 `~/.config/LinuxCockpit/aidj-lyrics/config.json`，与 AI DJ 主配置互不影响。

## 没有歌词怎么办

- 页面显示「暂无播放」：AI DJ 还没开始放歌，去 AI DJ 页点一首。
- 页面显示「暂无歌词」：这首歌在曲库里没有对应歌词。用 AI DJ 页面菜单 → **更新 MetaData**
  同步元数据（会抓 LRC / YRC 歌词），或在 **设置 → AI DJ → 歌词搜索目录** 里加上放 `.lrc` 文件的目录。

## 隐私与安全

歌词页与桌面歌词窗只显示当前曲目、歌词和封面，不涉及凭据：查询歌词、切歌、开关桌面歌词窗这些命令
没有声明为 AI 禁区，agent 可以调用；但它看不到 API 密钥，也拿不到 B 站账号概况、听歌统计这些
个人隐私数据（已脱敏）。涉及登录、导入凭据、签署免责声明的操作则只能由你本人在设置里完成。

## 命令行

```bash
aidj.lyrics                        # 当前播放状态 + 对应歌词（含逐字歌词）
aidj.lyrics-player                 # 歌词页绑定的播放器与可用列表（web 模式返回空列表）
aidj.lyrics-select-player --name org.mpris.MediaPlayer2.vlc   # 指定播放器（__auto__ = 自动跟随）
aidj.lyrics-state                  # 当前播放器的桌面歌词窗是否已打开
aidj.lyrics-toggle                 # 打开 / 关闭当前播放器的桌面歌词窗
aidj.lyrics-page-config            # 读取歌词页显示配置
aidj.lyrics-page-save --config '{"karaoke":false,"scroll_follow":false}'   # 保存歌词页配置
```

## 常见问题

**切到别的页面再回来，歌词页像重置了？** 歌词页没有开 keep-alive，离开即销毁，回来会重新加载
（AI DJ 主页和播放器页不会，它们的播放状态保留）。

**高亮不动 / 歌词串行？** 先试 **位置偏移 (ms)** 微调；如果来源芯片显示 **LRC** 而不是 **YRC**，
说明这首歌没有逐字歌词，只能按行高亮——跑一次 **更新 MetaData** 有机会补上。

**MV 画面黑屏？** 确认播放的是视频格式、且没有打开 **仅音频模式**；视频出错时页面会自动重载一次源，
若文件编码不被内置解码支持，可能一直黑屏——此时在 **设置 → AI DJ → 播放偏好** 里打开
**仅音频模式 (Audio Only)**，即可回到普通歌词视图。
