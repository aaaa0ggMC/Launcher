# AI DJ

> 最后更新：2026-10-03

AI DJ 把你的本地曲库交给一个「电台主播」式的 AI：你用自然语言点歌，它从曲库里挑歌、排序、写好串场词，
再把歌单推给播放器。选歌由一个 Agent 完成：它不逐首翻曲库，而是看标签云、按标签批量筛选、调用子 Agent 挑歌，
最后固定跑一个排序环节定顺序、写开场白——怎么分工、怎么设置见
[AI 循环（工作原理）](AI循环/工作原理.md)。
同一个文件夹在侧栏注册了三个页面，共用这一份帮助：

- **AI DJ**（本页）：聊天点歌 + 后台自动轮播。
- **歌词**：全页歌词显示，支持卡拉 OK 逐字高亮与滚动跟随。
- **播放器**：内置播放器页面（淡入淡出 / EQ / 倍速 / 频谱 / 局域网遥控）。

歌单元数据、会话记录、播放频率、听歌时长都保存在本机 `~/.config/LinuxCockpit/aidj/` 下，
主配置是 `~/.config/LinuxCockpit/aidj/config.json`。

> 一句话上手：打开 **AI DJ** 页面 → 点顶部中央的把手打开页面菜单 → 先去
> **设置 → AI DJ** 填好 API 地址 / API 密钥 / 音乐目录 → 回到输入框打「来点轻松的中文歌」→
> 点 **发送**，AI 回一段串场词和一张歌单，点 **播放全部** 就开始播。

## 能做什么

- Agent 选歌：AI 看标签云、按标签批量保留 / 剔除，调用子 Agent 挑歌，还内置了 4 套「范式」应对
  「从某首歌 / 某句歌词开始」「来点某个歌手」等常见说法；判断交给 AI，合法性由代码保证。
  详见 [AI 循环（工作原理）](AI循环/工作原理.md)。
- 自然语言点歌：说心情、场景、语种，AI 从**你自己的曲库**里挑歌并排序，不会幻觉出不存在的歌。
- 斜杠命令直达曲库：`/random`、`/pr`、`/explore`、`/ftop`、`/analyse`、`/filter`、`/persist`，不用麻烦 AI。
- 只聊天：不想听歌时说「不听歌，我们聊聊…」，AI 直接回答，这一轮不出歌单。
- 联网搜索（可选）：开启后 AI 能查歌手、歌曲、作品、新闻等事实来理解你的请求，但歌曲仍只从曲库里选。
- Tokens 明细：状态栏 **Tokens** 实时累加，鼠标悬停看输入 / 缓存命中 / 输出，以及按 Agent 的拆分。
  怎么看缓存命中率见 [AI 循环（模型与用量）](AI循环/模型与用量.md)。
- 标签整理：把情绪 / 风格 / 语言 / 响度里同质化的标签合并成规范词表，并把不符合的歌曲清洗干净，
  结果写进新的元数据槽位、一键切换。见 [标签整理](曲库/标签整理.md)。
- 持久模式：把当前对话分支到后台持续生成、持续推送，关掉页面也在跑，随时回后台面板继续聊。
- 元数据同步：自动补全每首歌的语言 / 情绪 / 风格 / 响度 / 乐评，AI 选歌时能用上。
- 播放控制：下一首 / 上一首 / 播放暂停 / 停止 / 音量，支持外部 MPRIS 播放器（vlc、mpv 等）与内置播放器两种后端。
- 听歌统计：播放频率、每日 / 每月 / 每年听歌时长热力图，都可一键回放。

## 界面速览

| 区域     | 位置         | 说明                                                                                                                                         |
| -------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 顶栏     | 页面最上方   | 当前曲名（过长省略）、播放状态芯片、AI API 状态芯片、播放器下拉                                                                              |
| 对话区   | 页面中部     | 消息流（You / AI DJ / System），AI 回复按 Markdown 渲染，可向上滚动加载历史                                                                  |
| 歌单卡片 | AI 回复下方  | **播放全部**、**推送到后台**，加一张带封面、可拖拽排序的歌曲网格                                                                             |
| 输入区   | 页面底部     | 状态栏芯片、多行输入框、**发送** / **停止**、**展开** / **收起**                                                                             |
| 页面菜单 | 顶部中央把手 | 下拉菜单：新建会话、从此刻开始、会话记录、模型细则、歌曲频率、元数据槽位、Bilibili 视频下载、听歌时长统计、标签整理、更新 MetaData、桌面歌词 |

顶栏右侧的播放器下拉只在**外部播放器 (MPRIS / DBus)** 模式出现，默认选项是 **当前激活**
（自动跟随当前活跃播放器），也可以在下拉里指定某一台。切到内置播放器后端后这个下拉会消失。

输入框上方的一排小芯片是实时状态：**Tokens**（累计 token，**鼠标悬停**看输入 / 缓存 / 输出明细与按 Agent 拆分）、
**Context / Completion**（本次请求输入 / 输出）、**Tracks**（曲库曲目数，加载中显示 `…`）、**Memory**（已播记忆，点击清空）、
**Volbal**（响度平衡，点击在 off → lufs → linear 之间循环）、**RecordFreq**（播放频率记录开关）、
**Listen**（听歌时长统计开关）、**Backgrounds**（运行中的后台任务数）。芯片显示与顺序可在 **设置 → AI DJ → 状态栏指示器** 里改
（数值是显示顺序，0 = 隐藏）。

## 常见操作

### 第一次使用：填配置

1. 打开侧栏的 **设置** 页 → 分类 **AI DJ** → 条目 **AI DJ 配置**。
2. **API 配置**：填 **API 地址**（OpenAI 兼容端点，形如 `http://localhost:1145/v1`）和 **API 密钥**。
   密钥**只写不回显**——设置里不显示原文，保存后显示「已设置（加密保存，不回显）— 输入新值即替换」，
   旁边可以 **清除已保存的密钥**。密钥加密后才写进 `config.json`，只在内存里解密，AI 读不到也改不了。
3. **AI 模型**：这一区块已改成**模型细则**（也可以从 AI DJ 页面菜单直接点 **模型细则** 打开）。
   除 **默认模型**（文本模式、标题生成，以及没单独设置的 Agent 都用它）外，还能分别给 LoopAgent、LibAgent、
   DreamAgent、RankAgent、VocabAgent、SanitizeAgent、元数据模型指定模型；每个 Agent 下拉的第一项是
   **跟随默认**，选它或清除即跟随默认模型，也可以直接手输列表里没有的模型名。修改即时保存，下一批生效——
   所以聊天页和持续模式面板里**不再有模型下拉**。
4. **音乐库与播放器**：在 **搜索目录** 里逐个 **添加** 音乐目录（递归扫描），需要桌面歌词就再加 **歌词搜索目录**（`.lrc`）。
5. **联网搜索（Tavily）**（可选）：打开 **允许 AI 联网搜索**，填 **Tavily API Key**，再调
   **结果数**（默认 5，最多 10）和 **搜索深度**（基础 / 深入）。开关打开且填了 Key 才对 AI 可用。
6. 歌词抓取走网易云：默认用外部服务（**NCM API 地址**，默认 `http://localhost:3000`，即
   [NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi)）；想用进程内直连，先在
   **网易云内置直连授权** 里点 **签署免责并启用**。

改完即时生效，配置落在 `~/.config/LinuxCockpit/aidj/config.json`。

### 和 AI DJ 对话

在底部输入框写需求（例如「来点轻松的中文歌」「从"辽阔的森林"开始」「来点周杰伦」），点 **发送**（或按 **Shift+Enter**）。

AI 回复上方会出现一张 **workflow 卡片**，每一批一张：标题栏显示所用范式、状态
（运行中 · 第 n 轮 / RankAgent 排序中 / 结果）、本批 tokens 与耗时；结束后自动折叠成一行摘要，
例如「5 轮 · 7 次调用 · 候选 16 → 入选 8 · 剔除 8」。点开卡片看时间线——哪个 Agent、调了什么工具、
做了什么（「标签过滤 3223 → 2636 首」「歌词检索 “辽阔的森林” → 2 首」），某一行再点开还能看原始参数与结果。

等待期间的「思考中」气泡显示的是**当前阶段**（如「LoopAgent 思考中 · 第 5 轮」「LoopAgent · 标签过滤…」
「DreamAgent 扩展…」「RankAgent 排序中…」），不再是字符数（文本模式仍显示字符数）。完成后变成串场词 + 一张歌单卡片。
这批歌具体是怎么选出来的，看卡片就够了；想了解背后的分工见
[AI 循环（工作原理）](AI循环/工作原理.md)。

不想听歌时说「不听歌，聊聊…」或问点与选歌无关的问题：这一轮不出歌单，AI 直接回答，
卡片摘要形如「仅对话 · 2 轮 · 4 次调用」。

只有串场词没有歌单时，会在下方附一条「AI 未生成歌曲列表」的系统提示——多半是曲库里没有匹配的歌。

生成过程中想中断，点红色的 **停止**，输入框会还原你刚才写的内容。

### 用斜杠命令直接操作曲库

输入框里打 `/` 会弹出命令提示浮窗：**↑ / ↓** 选择、**Tab** 补全、**Esc** 关掉。可用的命令：

| 命令                                            | 作用                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------- |
| `/random <number>`                              | 随机挑 N 首（优先没播过的），直接作为 AI 推送计入上下文             |
| `/pr <number>`                                  | AI 从随机候选里精选成一份连贯歌单                                   |
| `/explore <number>`                             | 找没听过 / 播放最少的歌                                             |
| `/ftop <N>` / `/ftop -<N>` / `/ftop <A> <B>`    | 播放次数最多 / 最少 / 指定区间的歌                                  |
| `/analyse <language\|emotion\|genre\|loudness>` | 以系统消息形式给出元数据分布统计                                    |
| `/filter <表达式>`                              | 按布尔表达式过滤曲库（标题 / 歌词 / 全文 + `[字段:值]` 元数据筛选） |
| `/persist <消息>`                               | 把当前对话分支成持久会话，在后台持续生成并推送                      |
| `/persist-stop`                                 | 停止运行中的持久会话                                                |

`/filter` 示例：`/filter [language:粤语] and ("周杰伦") or [emotion:孤独]`。默认搜标题，
加 `--compare=lyrics|all` 可搜歌词；中文默认开启简繁模糊、英文忽略大小写。

### 播放与推送歌单

- 歌单卡片左上方点 **播放全部**：把整张歌单发给当前播放器。
- 点歌曲网格里的**封面**：只播这一首。
- **推送到后台**（仅外部播放器模式）：开一个连续播放后台任务，在当前播放器上按队列播完，
  详情见 [曲库与元数据](曲库/元数据与统计.md)与[内置播放器](播放器/内置播放器.md)。
- 内置播放器模式下没有「推送到后台」，**播放全部** 会把歌单追加进内置播放器队列，当前歌曲不中断。

当目标播放器上已经有连续播放任务时，**播放全部** 会先弹「覆盖播放列表？」确认框，
确认后才 **覆盖并播放**——两个来源同时切歌会打架，一般不推荐。

### 会话记录：搜索、置顶、改名、删除

页面菜单 → **会话记录**：

- 顶部有返回箭头、刷新图标按钮、**搜索会话…** 输入框（按标题 / 首条提示词 / 最近消息内容过滤）和会话计数芯片。
- 列表按「今天 / 昨天 / 具体日期」分组，置顶会话排在最前；每条显示消息条数。
- 在会话上**右键**可：**置顶 / 取消置顶**、**自动生成标题**（跑一个后台任务让 AI 起名）、
  **设置标题**（弹窗里改名）、**删除**（红色，删除后不可恢复）。

点一条会话即载入；历史很长时会先显示解析进度条再载入。
页面对话里右键任意消息，可以 **复制** / **CopyRaw**（AI 消息的原文）/ **回退到此处** /
**从此处分支 (Fork)**（把对话从这条消息处复制成新会话并切过去）。
workflow 卡片会随会话一起保存下来（单独一种记录行），重新打开会话卡片还在。

### 持久模式：后台自动轮播

1. 先正常聊几轮，或直接用 **从此刻开始**（见下）。
2. 输入 `/persist 继续放，节奏快点` 回车，或点页面菜单的 **从此刻开始**（外部播放器模式）。
3. 当前对话会被复制成一个 `(Copy)` 分支会话，后台任务开始持续生成歌单并推给播放器；
   **AI DJ 主页的聊天保持原样不受影响**。
4. 打开侧栏底部的**后台任务**面板，找到这条任务：`chat` 视图里可以继续发消息、切换发送目标播放器、
   右键回退 / 复制；`continuous` 视图里能看到当前播放 / 下一首 / 待播队列，并能拖拽排序、切换播放器、
   调音量、重置已播记忆。后台面板和聊天页一样显示 workflow 卡片，tokens 也是实时累加的。
5. 持续会话里说「不听歌，我们聊聊…」会**暂停自动续播**，聊天里提示
   「⏸ 这一轮只聊天，自动续播已暂停；发消息即可继续」；下一条消息又要听歌就自动恢复（「▶ 已恢复自动续播」）。
6. 输入 `/persist-stop` 或在面板里点停止即可结束。

内置播放器模式下持久会话同样可用（歌单推给内置播放器队列）；但**连续播放任务**（歌单卡片上的
**推送到后台**）只在外部播放器模式下提供，内置模式下该按钮不显示。

### 更新 MetaData 与曲库体检

- 页面菜单 → **更新 MetaData**：启动「AIDJ 元数据同步」后台任务，扫描曲库里缺元数据的新歌，
  逐首抓歌词并让 AI 提取语言 / 情绪 / 风格 / 响度 / 乐评。已经在跑时会直接打开后台面板。
  完成后会弹提示「元数据同步完成：N」或「没有写入新的元数据」。
- 页面菜单 → **元数据槽位**：把元数据分成多个集合（`AnimeOST`、`JPop-2024`……），
  用复选框按「整个槽位 / 单曲」控制哪些生效，header 上的「生效: N 首」实时刷新。
  **设为写入** 指定以后同步写入哪个槽位，**设为B站默认** 指定 B 站下载的默认写入槽位。
  整理标签也会写入新的槽位，见 [标签整理](曲库/标签整理.md)。
- 页面菜单 → **歌曲频率**：按播放次数排序的曲库列表，点封面即发送到播放器；顶部图标切换升 / 降序。
- 页面菜单 → **听歌时长统计**：热度图看每天 24 小时 / 每月每天 / 每年每月的听歌分钟数，
  支持按 `YYYY-MM` **跳转**、**回到当前**，鼠标悬停格子看时长与覆盖率。
- 页面菜单 → **模型细则**：打开模型细则面板（每个 Agent 用哪个模型，改完下一批生效）。
- 页面菜单 → **标签整理**：打开整页的标签整理视图，把同质化标签合并成规范词表并清洗歌曲。

### Bilibili 视频下载

页面菜单 → **Bilibili 视频下载**：粘贴 BV / AV 号或视频链接（空格、逗号、换行分隔），
点 **解析视频**（或 **Ctrl+Enter**），多 P 视频会自动拆成多条；勾选 **跳过已下载**、
**仅音频 (m4a)** / **视频流 (mp4)**，选好 **元数据写入槽位**，点 **确认下载 (N 项)** 起后台任务。
使用前需要在 **设置 → AI DJ → Bilibili 视频导入与扩展** 里签署免责声明并登录（支持扫码 / 导入 Cookie）。

### 桌面歌词浮窗

页面菜单 → **桌面歌词**（已打开时显示 **关闭桌面歌词** 并带勾选标记）：为当前绑定的播放器
打开一个无边框、透明、置顶、不抢焦点的桌面歌词窗（每台播放器一个独立窗口）。
窗口默认可以直接拖动挪位置，**右键 → 锁定** 后变为鼠标穿透（点不到它）；想开屏即锁定，
在 **设置 → AI DJ → 桌面歌词显示** 里打开 **打开即锁定**。
字体、字号、颜色、窗口位置等都在 **设置 → AI DJ → 桌面歌词显示** 里调。

## 平台与依赖

AI DJ 的核心（聊天、曲库、元数据、统计）跨平台可用，播放相关的系统依赖分两种后端：

- **外部播放器 (MPRIS / DBus)**：仅 Linux 可用，需要会话 DBus 和一个支持 MPRIS 的播放器
  （vlc、mpv 等）。非 Linux 平台强制使用内置播放器；播放器断开时按 **设置 → AI DJ → 连续播放 → 重连时长（分钟）**
  的策略重试或结束。
- **内置播放器**：任何平台可用，不依赖外部程序，但连续播放任务与部分 EQ / 音量命令只在该模式下注册。
- **ffmpeg / ffprobe**：响度分析（动态音量平衡）用它测 LUFS / RMS。缺失时不会报错，只是不做音量平衡。
- **OpenAI 兼容端点**：没有可用端点就无法生成歌单，顶栏 API 芯片会显示 **离线**。
- **NeteaseCloudMusicApi**：元数据同步的默认歌词来源；未运行时要切到内置直连（需签署免责声明）。
- AI DJ 的持久轮播 / 对话 / 元数据同步都跑在后台任务上，依赖「后台任务」能力；该能力被移除时 AI DJ 不会加载。

## 隐私与安全

- **API 密钥**与 **Tavily Key** 属于凭据：只写不回显，加密保存在 `config.json` 里
  （`enc:v2:` 前缀，用 Cockpit 的加密模块，只在内存里解密），AI 无法读取，也不能通过命令改写。
- 开启联网搜索后，**AI 生成的搜索词会发送到 Tavily**；歌曲仍然只从你的本地曲库里选，
  网页内容只被当作参考资料。
- workflow 记录保存在会话历史里（重新打开会话卡片还在），但**不进入 AI 的记忆**——下一批开始时它看不到上一批的过程。
- **B 站账号概况**（uid / 昵称 / 头像）与**听歌统计**标记为个人隐私区，AI 快照与截图会脱敏。
- 扫码登录、导入凭据、签署 / 撤销免责声明只能由你本人在界面上完成，AI 无法代为调用。
- 内置播放器的**局域网遥控**会对外开放端口，AI 启动它需要单独授权。

## 命令行

界面上的每一步都有对应命令，CLI 里同样可跑：

```bash
aidj.generate --prompt "来点轻松的中文歌"      # AI 生成歌单
aidj.random --count 10                        # 随机 10 首，计入上下文
aidj.curate --count 10                        # AI 从随机候选里精选
aidj.filter --query '[emotion:孤独] and ("周杰伦")'   # 表达式过滤曲库
aidj.analyse --field language                 # 元数据分布
aidj.search --q 周杰伦                        # 曲库检索（相似度 ≥ 80）
aidj.status                                   # 播放状态 + 曲库 / 记忆 / 响度平衡
aidj.next | aidj.prev | aidj.toggle | aidj.stop   # 播放控制
aidj.volume --set 0.6                         # 设置音量（0-1）
aidj.start-persistent --prompt "从此刻开始"     # 启动持久模式（仅外部播放器模式）
aidj.chat --task <id> --text "换点摇滚"        # 给运行中的持久会话发消息
aidj.metadata-sync                            # 后台任务：同步缺失元数据
aidj.sessions.list                            # 列出会话
aidj.freq                                     # 播放频率列表
aidj.player-mode --set web                    # 切换播放后端（dbus|web）
aidj.lyrics-page-save --config '{"scroll_follow":false}'   # 保存歌词页配置
aidj.loop-preview --task <持续会话任务id>       # 预览下一批的指令 / 提示 / 工具 / 范式与各 Agent 模型（不调用 AI）
aidj.loop-preview --task <id> --system true     # 连系统提示一起预览
aidj.tags-cloud                               # 标签云（当前写入槽位：主曲库 + B 站）
aidj.vocab-draft                              # 查看标签整理的规范词表草稿（--set <json> 保存修改）
aidj.vocab-drafts                             # 历史草稿列表
aidj.vocab-draft-restore --version <n>        # 恢复某份历史草稿
aidj.sanitize-estimate                        # 标签整理预估（直接映射 / 需 SanitizeAgent 的歌曲数）
aidj.sanitize-runs                            # 标签整理记录
aidj.sanitize-switch --run <id> --use sanitized   # 使用整理后的元数据（--use original 切回）
```

标签整理的两个耗时节点是后台作业，用 `background.job --name aidj.vocab-propose`（生成规范词表）
和 `background.job --name aidj.sanitize`（执行整理）触发，界面入口见 [标签整理](曲库/标签整理.md)。

## 常见问题

**顶栏 API 芯片显示「离线」？** 说明 AI 端点连不上：检查 **设置 → AI DJ → API 地址 / API 密钥**，
端点是否真的提供 `/models`（部分服务不提供也不影响对话）。修好后芯片会在 15 秒内自动变绿。

**播放没反应，提示 DBus 未连接？** 外部播放器模式需要一个在会话 DBus 上运行的 MPRIS 播放器
（vlc、mpv 等）。顶栏下拉里确认播放器选对了；或者 **设置 → AI DJ → 播放后端** 切到**内置播放器**。

**侧栏里找不到「播放器」页？** 该页面只在播放后端 = 内置播放器时出现，Linux 默认是外部播放器模式，所以是隐藏的。

**想给某个 Agent 换模型？** 聊天页里已经没有模型下拉了：改用页面菜单的 **模型细则**
（或 **设置 → AI DJ → AI 模型**），每个 Agent 都能单独指定，选 **跟随默认** 即恢复跟随默认模型，改完下一批生效。

**Tokens 一直在涨，缓存命中率却不高？** 这通常是正常的：RankAgent 的输入每批都不同、子 Agent 读新过滤出的候选池
第一次也命中不了。判断方法见 [AI 循环（模型与用量）](AI循环/模型与用量.md)。

**AI 出的歌单和之前重复？** 已播记忆（状态栏 **Memory**）里的歌不会再进候选（钉住的起点除外）；记忆有上限
（持续模式默认最近 100 首），更早播过的歌会重新变得可选。点 **Memory** 芯片清空记忆会让已播的歌**全部**重新可选——想减少重复就不要清空。
自主续播时同一批里同歌手还受 **每批同歌手上限** 约束。

**响度平衡开了但音量没变化？** 需要本机有 `ffprobe`（ffmpeg）测响度；另外基准音量是在你
松手调音量的那一刻校准的，之后每首歌围绕它微调。
