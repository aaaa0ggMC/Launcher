# 内置播放器

> 最后更新：2026-10-01

「播放器」是 AI DJ 的第三个侧栏页面，只在播放后端 = **内置播放器** 时出现——它是一个不依赖
vlc / mpv 等外部程序的 HTML5 播放器，跨平台可用，附带淡入淡出、十段均衡器、倍速、AB 循环、
睡眠定时、频谱和局域网遥控。

> 一句话上手：页面顶部中央的把手 → **局域网遥控** → **启动遥控服务器**，
> 用手机浏览器打开给出的地址就能遥控；切歌淡入淡出和 EQ 都在同一个菜单里。

## 这个页面什么时候才看得到

内置播放器页面与当前播放后端绑定：

- Linux 默认使用**外部播放器 (MPRIS / DBus)**，此时「播放器」页**不出现在侧栏**。
- 在 **设置 → AI DJ → 音乐库与播放器 → 播放后端** 里选 **内置播放器**（或执行
  `aidj.player-mode --set web`），侧栏立刻出现「播放器」条目；切回「外部播放器」则再次隐藏。
- 非 Linux 平台（Windows / macOS）没有会话 DBus，**只能**用内置播放器，因此这个页面默认可见。

切换后端会停掉正在运行的连续播放 / 持久会话，正在下载、同步元数据之类的数据类后台任务不受影响。
设置页也明确提示「内置播放器为实验性后端」。

## 界面速览

| 区域       | 位置         | 说明                                                                 |
| ---------- | ------------ | -------------------------------------------------------------------- |
| 页面菜单   | 顶部中央把手 | 播放队列、倍速、睡眠定时、均衡器、频谱、局域网遥控、播放后端（只读） |
| 封面与曲名 | 页面中上部   | 封面图（无封面时显示音符占位）、曲名（过长省略）、播放状态芯片       |
| 进度条     | 页面中部     | 左侧已播时间、可拖动进度滑块、右侧总时长；松手才真正跳转             |
| 播放控制   | 进度条下方   | 上一首 / 播放暂停（大按钮）/ 下一首 / 停止                           |
| 频谱条     | 底部上方     | 开启后显示 48 根频柱，颜色跟随主题                                   |
| 底部工具栏 | 页面最底部   | 响度平衡芯片、淡入淡出芯片、A / B 循环按钮、音量按钮                 |

页面菜单里的 **播放后端** 一栏只是显示当前模式（内置播放器 / 外部播放器 (MPRIS)），不能在这里切换。

## 常见操作

### 调整播放队列

把手菜单 → **播放队列**：列出内置播放器队列，正在播放的那首高亮，右上角显示总曲目数；
队列非空时右上角出现红色垃圾桶图标按钮，点击 **清空队列**（停止播放并移除全部曲目）。
空队列显示「队列为空」。

### 倍速与静音快进

把手菜单 → **倍速**：一排 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x 快捷按钮（当前值高亮），
下面还有 **自定义倍速** 输入框，填任意正数后点 **应用**（回车同样生效）。
大于 16 的倍速是静音快进，用来快速定位。默认倍速在 **设置 → 播放器 → 音频处理 → 默认倍速** 里设。

### 睡眠定时

把手菜单 → **睡眠定时**：15 / 30 / 45 / 60 / 90 / 120 分钟按钮，设置后菜单项右侧显示
「剩余 mm:ss」，随时可以点 **取消定时**。

### 均衡器（EQ）

把手菜单 → **均衡器**：

- 每个预设一行：左侧是曲线缩略图，右侧名称（内置预设有本地化名称，如 平直 / 流行 / 摇滚 / 古典 / 人声，
  没有译名的显示内置名），点一行即应用，右侧铅笔按钮 **编辑**，用户预设还有红色垃圾桶 **删除**（内置不可删）。
- 右上角 **+**（悬停显示 **新建 EQ**）打开编辑器。
- 编辑器：直接在曲线上**拖动控制点**改增益，下面 **整体偏移** 滑块一次平移所有频段，
  右上角可改名称，**取消** / **保存**。拖动是实时预览（不落盘）；取消时自动恢复编辑器打开前
  正在生效的那条曲线，**保存** 后写入并应用。
- 频段是固定的 10 段（31Hz–16kHz），最大增益范围在 **设置 → 播放器 → 音频处理 → EQ 最大范围 (±dB)**
  里调整（12–60，默认 20）；**重置预设** 只把内置预设恢复出厂，你的自定义预设保留。

### 频谱

把手菜单 → **频谱**：一个开关，打开后页面底部出现 48 根频柱的频谱条
（内置播放器模式且正在播放时才有内容；其他后端下开关是禁用的）。
是否默认显示在 **设置 → 播放器 → 显示与遥控 → 频谱条默认显示** 里配。

### 曲间淡入淡出（Crossfade）

底部工具栏左二的 **淡入淡出** 芯片：点一下切换开 / 关，开启时切歌会先淡出再淡入。
时长在 **设置 → 播放器 → 曲间过渡 → 淡入淡出时长** 里调（0.5–8 秒）。
该芯片在内置播放器模式之外是禁用的。

### 响度平衡（Volbal）

底部工具栏最左的芯片，点击在 **off → LUFS → RMS** 之间循环，开启时芯片高亮。
它基于 ffprobe 测得的每首歌唱度，围绕一个「基准音量」自动微调播放器音量；
**调完音量松手的那一刻会把当前音量设为新的基准**，所以建议先把音量调到舒服再放手。
没有安装 ffmpeg（ffprobe）时不会报错，只是不做平衡。

### AB 循环

底部工具栏右侧两个圆形按钮 **A** 和 **B**：在当前位置点 **A** 设起点，点 **B** 设终点，
两点之间循环播放；再点已亮起的那个按钮即清除循环。同样只在内置播放器模式可用。

### 音量

底部工具栏最右的音量按钮：点开弹出滑块，拖动实时生效，**松手时重新校准响度基准**。
音量为 0 时图标变成静音样式。

### 局域网遥控（Web Remote）

把手菜单 → **局域网遥控**：

1. 点 **启动遥控服务器**（变成 **停止遥控服务器** 即关闭），菜单项上会出现端口号芯片。
2. 菜单里给出一个 `http://localhost:<端口>` 链接，后台任务日志里还会打印
   `http://<局域网IP>:<端口>` 形式的地址。
3. 用手机或同局域网任意设备的浏览器打开该地址，就能看当前歌曲 / 封面 / 进度并控制播放
   （播放暂停、上下首、停止、跳转、音量、倍速）。
4. 端口在 **设置 → 播放器 → 显示与遥控 → 局域网遥控端口** 里改（0 = 禁用，默认 17320）；
   改端口后需要重启遥控服务器生效。

遥控服务器是一个后台任务，也可以在后台任务面板里直接停止。

## 隐私与安全

- 局域网遥控是**对外开放端口**的服务，AI 启动它需要单独授权；手机遥控页只能看歌曲与控制播放，
  不涉及你的凭据。
- 遥控页面不加密、无鉴权，只适合在可信的局域网里用；不需要时点 **停止遥控服务器**。

## 命令行

```bash
aidj.player-mode --set web                  # 切到内置播放器（页面随即出现在侧栏）
aidj.player-state                           # 统一播放状态（内置模式下含队列 / 倍速 / AB 点）
aidj.player-crossfade --enabled true --seconds 3   # 查询或设置淡入淡出
aidj.player-rate --set 1.25                 # 倍速
aidj.player-abloop --a 30 --b 60            # 设置 AB 循环（--off true 清除）
aidj.player-sleep --minutes 30              # 睡眠定时
aidj.player-volbal --enabled true --method lufs    # 响度平衡
aidj.player-rebase --base 0.6               # 把当前音量设为新的响度基准
aidj.eq-list                                # 列出 EQ 预设与当前激活项
aidj.eq-active --id vocal                   # 应用某个 EQ
aidj.eq-save --name "我的低音" --gains "[6,5,4,2,0,0,0,0,0,0]"   # 新建 EQ
aidj.web-remote-status                      # 遥控服务器状态与端口
aidj.web-remote-start                       # 启动遥控服务器
aidj.web-remote-stop                        # 停止遥控服务器
```

## 常见问题

**「播放器」页不在侧栏？** 当前是外部播放器 (MPRIS) 模式，去 **设置 → AI DJ → 播放后端** 切成内置播放器。

**EQ / 倍速 / AB 循环按钮是灰的？** 这些是内置播放器专属能力，切回外部播放器模式后自动禁用。
外部播放器模式下「淡入淡出」芯片同样禁用（由外部播放器自己决定）。

**切了播放后端，正在放的歌断了？** 切换会停掉运行中的连续播放 / 持久会话，这是预期行为；
下载、元数据同步这类后台任务不受影响。

**手机上打不开遥控地址？** 确认手机和电脑在同一局域网，用的是后台任务日志里打印的
局域网 IP（不是 localhost），以及端口没被防火墙拦下。
