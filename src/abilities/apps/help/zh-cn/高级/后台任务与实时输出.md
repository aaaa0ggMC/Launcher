# 后台任务与实时输出

> 最后更新：2026-10-01

这一页讲「启动之后会发生什么」：普通启动、终端启动、后台任务、root 提权、实时输出窗口，
以及附加操作的多步命令。这些开关都在 **添加应用 / 编辑** 弹窗里。

## 四种运行方式

| 开关（编辑弹窗）          | 行为                                                                 |
| ------------------------- | -------------------------------------------------------------------- |
| 都不选（默认）            | 前台 detached 启动，卡片立即返回，程序独立运行                       |
| **终端中运行**            | 用系统终端打开（默认 `konsole --hold -e`，可在全局配置里改）         |
| **后台任务**              | 不开窗口，进程交给框架托管，进全局后台任务面板（优先级高于终端开关） |
| **以 root 运行 (pkexec)** | 先过 polkit 授权，再以 root 执行（提权只走 pkexec + helper 脚本）    |

多个开关可以叠加，比如「终端 + root」。但 **后台任务会接管输出管道**，此时终端开关被忽略。

## 后台任务

勾了 **后台任务** 的条目（或某个附加操作）启动后：

- 进程以管道方式收集标准输出 / 错误，**不会**随页面关闭而消失。
- 侧栏底部（托盘图标，有运行时显示数字徽标）点开**后台任务**面板，就能看到这条任务：
  实时控制台滚动、CPU / 内存 / 显存占用、**stdin 输入框**、Ctrl+C 信号、**终止** 与 **强制停止**。
- 在应用页点这类按钮后，页面会**自动帮你打开**后台任务面板，直接看输出。
- 任务依附于本程序：退出 Cockpit 时统一清理，不会留孤儿进程；退出前有任务在跑会先弹确认。

适合常驻的服务类程序（服务器、守护脚本、需要持续看日志的任务）。

## root 提权

勾了 **以 root 运行 (pkexec)** 后，启动时会弹出系统授权框要求输密码（pkexec/polkit 机制）：

- 授权一次后约 5 分钟内再启动其它提权条目不重复弹（前提是安装过本项目自带的 polkit 规则）。
- 取消授权或提权失败：该次启动中止，原程序不受任何影响。
- 所有提权都经由 pkexec 调用固定 helper 脚本完成，不会开一个交互式 root shell。

普通应用不要勾这个开关——只有确实需要操作系统级资源的条目才需要。

## 实时输出窗口

编辑弹窗的「实时输出 Transformer」区可以给条目配一段 JS 构造函数 + 打开 **启用实时弹窗** 开关：

- 之后每次启动（且启动成功返回了可监视的进程）就会弹出实时输出窗口（约 80% 宽的模态）。
- 窗口标题是应用名，带 `pid` chip 与状态 chip（**运行中** / **已退出 (退出码)**，退出码非 0 时变红）。
- 右上角一排图标按钮（悬停显示名称）：**组件视图** / **原始输出**、**自动滚动**、**清空**、**关闭**。
- 没有配 transformer 时窗口按纯文本逐行显示；**原始输出**视图带 ANSI 上色，stderr 行标红。
- 启动到弹窗打开之间的输出有缓冲，不会丢。

进阶用法（构造函数的 `onNewLine(e, ui)` 与组件工厂 `NewText` / `NewTitle` / `NewAlign` /
`NewBar` / `NewStatus` / `NewTable`）见编辑弹窗里该输入框的提示文本，这里不展开。

## 多步附加操作

编辑弹窗的**附加操作**每一行最下方有个**多步命令**文本框：每行一条命令，依次执行。

- 中间步骤**无头执行并等待完成**，任一失败立即中止，提示「步骤 N 失败」。
- 只有**最后一步**是「启动」语义：尊重它自己的 终端 / 后台 / root 开关。
- 适合「先拉代码 → 再构建 → 最后起服务」这类固定流程，一次点击跑完。
