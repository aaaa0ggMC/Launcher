# 应用

> 最后更新：2026-10-01

「应用」把你散在各个目录里的项目、脚本和小工具收拢成一张**应用注册表**：一个目录扫出一批应用，
卡片式一点启动，还能给每个应用挂「停止 / 重启 / 重建」这样的附加按钮。注册表就是每个搜索根目录下的
`apps.json`——**手工编辑完全欢迎**，扫描器只补充、不覆盖你写的内容。

> 一句话上手：点页面右上角 **添加目录** 选一个放项目的目录 → **添加应用** 填名称和命令 →
> 在卡片上点 **启动**。

## 能做什么

- 搜索目录下登记过的每个应用一张卡片：搜索、按标签筛选、一键启动。
- 每个应用除 **启动** 外还能挂多个**附加操作**按钮（开始 / 停止 / 重建……），按钮颜色越深越危险。
- 三种运行方式任选：普通前台、**终端中运行**、**后台任务**（输出进全局后台任务面板）。
- 中 / 高风险应用启动前弹确认框，可勾选「知道了，以后不再提醒」。
- 侧栏顶部搜索框直接启动应用，右键菜单选附加操作，不必打开本页。
- 注册表可随时导出 Markdown（侧栏底部「复制当前页面为 Markdown」按钮）。

## 界面速览

| 区域           | 位置            | 说明                                                             |
| -------------- | --------------- | ---------------------------------------------------------------- |
| 标题行         | 页面最上方      | 「应用注册表」标题与副标题；右侧 **添加目录**、**添加应用** 按钮 |
| 搜索框         | 标题行下方左侧  | 按名称 / 别名 / 描述 / ID 搜索（不区分大小写）                   |
| 标签 chips     | 搜索框右侧      | **全部** + 各个标签，点选筛选，再点一次取消                      |
| 显示缺失条目   | 标签 chips 下方 | 复选框；勾选后连「目录已不存在」的条目一起显示                   |
| 搜索目录 chips | 标签行下方      | 已添加的根目录，点 × 立即移除；没有目录时显示提示 chip           |
| 应用卡片       | 页面主体        | 网格排布，一张卡片一个应用；底部是操作按钮                       |

每张卡片从上到下：**图标**（40px 圆角头像）、**名称**（高风险时旁边有个盾牌图标，悬停显示
「高风险操作，操作前需确认」）、**缺失** chip（源文件已不在时）、**描述**（没有描述就显示路径）、
**标签** chips（手工标签与扫描自动标签合并去重）。

卡片底部一排按钮：左侧是文字按钮 **编辑**（铅笔图标）；右侧是 **启动**（播放图标）和该应用的
各个**附加操作**按钮（各自带图标和名称）。按钮颜色编码风险：低危绿色、中危橙色、高危红色实心。
源文件缺失时整张卡片半透明，启动类按钮全部禁用。

## 常见操作

### 添加搜索目录

1. 点页面右上角 **添加目录**。
2. 弹窗里输入**绝对路径**（占位符示例 `/home/you/Apps`），或点输入框里的文件夹图标用系统对话框选择。
3. 点 **添加**。

目录下的 `apps.json` 就是该目录的注册表。也可以到 **设置 → 应用 → 搜索目录** 里集中管理：
上移 / 下移调整搜索顺序（顺序会影响搜索结果的排序先后）、移除、继续添加。已添加的目录以 chip
形式列在页面搜索框下方，点 × 随时移除。

### 添加或编辑应用

- **添加应用**：填**名称**、**ID**（留空按路径 / 名称自动生成）、**目录/脚本路径**（相对存储目录或
  绝对路径，可点文件夹图标选择）、**描述**、**图标**、**执行类型**、**风险等级**、**命令**，
  以及**终端中运行 / 后台任务 / 创建目录**开关。展开「多语言 / Multi-language」还能为每种界面语言
  分别填名称和描述。
- **编辑**：点卡片左下角 **编辑**。除上述字段外还能改**别名**（CLI 快捷名）、**标签**、
  **工作目录**、**风险备注**、**以 root 运行 (pkexec)**，可以增删**附加操作**行，以及配置
  **实时输出 Transformer**。
- 编辑弹窗左下角是红色 **删除**——直接从 `apps.json` 移除，不进回收站。

### 启动应用

点卡片上的 **启动**，或点任意一个附加操作按钮。流程完全一致：

1. 中 / 高风险时先弹确认框（见下节）。
2. 通过后立即启动，卡片不会等待程序退出。
3. 配了实时输出的应用会弹出输出窗口；后台任务则自动打开全局后台任务面板。

启动行为由条目的几个开关决定：**终端中运行**会开一个系统终端窗口；**后台任务**不开窗口、
改为框架托管（见[高级 → 后台任务与实时输出](高级/后台任务与实时输出.md)）；
**以 root (pkexec)** 会弹授权框提权。

### 启动前确认

风险等级为**中 / 高**的应用（或风险更高的附加操作）启动前会弹确认框：

- 标题为「确认启动『×××』？」，警告区显示扫描**检测**到的风险说明与你在编辑里写的**备注**。
- 中部是「即将启动『×××』」加一枚风险 chip。
- 勾选 **知道了，以后不再提醒** 后点 **启动**，该条目标记为已确认，以后直接启动不再询问；
  点 **取消** 放弃。

想重新收到某个条目的确认，需要把 `apps.json` 里该条目的 `security.acknowledged` 改回 `false`
（编辑弹窗不再显示这个勾选状态）。全局还有一个启动确认开关：**设置 → 外观 → 启动** 里的
「所有启动前都需确认」。

### 从侧栏搜索框快速启动

侧栏顶部搜索框（占位提示「搜索能力 / 应用 / 工具」）里输入应用名 / 别名 / 标签，
「快速启动」分组里会出现对应条目：

- **左键**点击结果：直接启动该应用（与卡片 **启动** 按钮同一流程）。
- **右键**点击结果：弹出菜单——第一项是应用主启动，下面依次列出它的每个附加操作
  （名称就是卡片上的按钮名），点哪项跑哪项。

### 后台运行是什么

条目的**后台任务**开关打开后，启动不再开终端，而是把进程交给框架的**后台任务**服务托管：
标准输出被管道收集，出现在侧栏底部的**后台任务**面板里——可以看实时控制台、CPU / 内存 / 显存
占用，能向程序 stdin 发消息、发 Ctrl+C 信号、强制停止。任务**依附于本程序**，退出时统一清理。
配了后台任务的按钮点下去，页面会自动帮你打开后台任务面板。详见
[高级 → 后台任务与实时输出](高级/后台任务与实时输出.md)。

### 使用频次统计

- 每**启动一次应用**（卡片上的启动 / 附加操作按钮、侧栏快速启动、命令行启动都算），就在
  `~/.config/LinuxCockpit/apps.csv` 里记一条 `app:<搜索根目录>:<条目路径>`；每**点开一次侧栏条目**记一条以能力 id 为键的计数。
- 侧栏排序规则在 **设置 → 外观 → 侧边栏** 里切换：**字母序 / 使用频次 / 最近使用 / 自定义排序**，
  其中「使用频次 / 最近使用」读的就是这份统计。
- 同一设置项里有 **清空使用记录** 按钮，一键把所有计数归零，立即生效。

## 隐私与安全

- 从 AI / 远程端启动应用、增删改注册表条目需要相应的执行 / 控制权限，授权由你自己在弹出的窗口里决定。
- 风险确认弹窗只能由你本人操作，AI 无法代你点「启动」。

## 命令行

应用页的每一步都是注册命令，在内置 CLI REPL 里可直接调用（`--flag value` 传参）：

```bash
apps.list                                              # 列出所有搜索目录下的应用
apps.get --root ~/Apps --id bili-viewer                # 读取单个条目
apps.config                                            # 读取 Apps 能力配置（搜索目录等）
apps.update --root ~/Apps --id bili-viewer --patch '{"name":"x"}'   # 更新/创建条目
apps.delete --root ~/Apps --id start-rdp               # 删除条目
apps.add-root --path /home/you/Apps                    # 添加搜索目录
apps.remove-root --path /home/you/Apps                 # 移除搜索目录
apps.move-root --path /home/you/Apps --dir 1           # 调整搜索目录顺序（-1 上移 / 1 下移）
apps.create --root ~/Apps --id myapp --patch '{"name":"My App","exec":{"type":"custom","command":["run.sh"]}}' --mkdir true
apps.rescan --root /home/you/Apps                      # 重扫目录生成草稿并合并
launch.run --root ~/Apps --id bili-viewer              # 启动应用
launch.action --root ~/Apps --id new-api --action stop # 运行应用的附加操作
```

CLI 里还有一组按别名 / 标签解析的快捷词：

```bash
list / ls                  # 列出全部应用（别名或 ID + 名称）
info <别名>                # 查看应用详情（名称/别名/路径/类型/风险/标签/操作）
launch <别名> [操作]       # 启动应用或它的一个附加操作
<别名>                     # 裸别名直接启动（匹配 别名/ID/标签，忽略大小写）
<别名> <操作>              # 直接执行附加操作，如 new-api stop
```

## 常见问题

**新建了项目文件夹，页面上却没有？** 目录监视只负责「文件变了即时刷新」，不会自动为新项目生成条目。
点 **添加应用** 手动登记，或执行 `apps.rescan --root <目录>` 让扫描器补一遍草稿。

**启动失败，提示「工作目录不存在」？** 条目的路径指向的目录被删掉或挪走了。勾上
**显示缺失条目** 找到那张半透明卡片，用 **编辑** 修正路径，或直接删除。

**搜索框输入标签名搜不到？** 搜索框匹配的是名称 / 别名 / 描述 / ID；标签请用搜索框右侧的
标签 chips 筛选。多个关键词按空格分隔，是「并且」的关系。

**按钮是灰的？** 源文件缺失时启动类按钮全部禁用（卡片半透明、带 **缺失** chip）。把文件放回原位置
或修正路径后即可恢复。

**切到别的能力再回来，搜索词没了？** 这个页面不缓存（keepAlive: false），每次进来都是全新状态。
